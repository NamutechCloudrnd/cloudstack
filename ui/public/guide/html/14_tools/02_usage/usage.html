사용량 (Usage)

사용량(Usage) 기능은 클라우드 자원의 사용 이력을 관리하는 도구로, 시간 단위 사용량 확인 및 관리 목적의 다운로드가 가능하다.

사용량 화면

상단 상태 패널

사용량 상태 패널

번호 항목 설명
1 서버(Server) 현재 사용량 서버 상태 및 카운트 표시
2 마지막 하트비트 (Last heartbeat) 사용량 서버의 마지막 Heartbeat 시간
3 마지막 성공한 작업 (Last successful job) 사용량 수집의 마지막 성공 시간

검색 및 필터

사용량 검색/필터 항목

번호 항목 설명
1 도메인(Domain) 도메인별 필터링 (ROOT 등)
2 계정(Account) 선택한 계정 필터링
3 사용 유형(Usage type) 가상머신, 네트워크, 스토리지 등 자원 유형 선택
4 리소스 ID (Resource ID) 사용량 집계 자원 ID 검색
5 시작일 / 종료일 (Start date / End date) 사용량 집계 기간 필터
6 하위 도메인의 사용 기록 가져오기 (Fetch usage records for child domains) 하위 도메인 사용량 기록 포함 여부

화면에 제공되는 작업 버튼은 사용 기록 표시 / CSV 다운로드 / 삭제 이다. 화면 우측 상단에는 사용량 기록 생성 및 사용량 기록 삭제 아이콘이 배치되어 있다.

사용량 목록 조회 결과

사용량 목록

번호 항목 설명
1 계정(Account) 도메인별 필터링 (ROOT 등)
2 도메인(Domain) 특정 계정 필터링
3 사용 유형(Usage type) 가상머신, 네트워크, 스토리지 등 자원 유형 선택
4 리소스 ID (Resource ID) 사용량 집계 자원 ID 검색
5 시작일 및 시간 (Start date and time) 사용량 집계 시작 날짜 및 시간
6 종료일 및 시간 (End date and time) 사용량 집계 종료 날짜 및 시간
7 원시 사용량 (시간 단위) (Raw usage (in hours)) 시간 단위로 계산된 사용량
8 설명(Description) 사용 유형 설명
9 보기(View) 상세 정보 버튼

화면에 제공되는 작업 버튼은 사용 기록 표시 / CSV 다운로드 / 삭제 이다. 화면 우측 상단에는 사용량 기록 생성 및 사용량 기록 삭제 아이콘이 배치되어 있다.

주요 기능

  • 사용량 기록 생성: 예약된 작업이 미실행된 경우 수동으로 특정 시간 범위의 사용량을 수집한다.
  • 사용량 기록 삭제: 저장된 사용량 기록을 영구 제거한다.
