데이터 볼륨 가져오기 (Import Data Volumes)

데이터 볼륨 가져오기 기능은 외부에 있는 관리되지 않는 볼륨을 관리형 데이터 볼륨으로 전환하거나 반대로 관리 볼륨을 관리되지 않는 볼륨으로 전환하는 기능이다.

사전 요건

  • 저장소 풀은 Up 상태여야 한다.
  • KVM 만 지원한다.

사용 절차

  1. 스토리지 Pool 선택: 화면 상단에서 Zone 과 스토리지 풀을 선택하여 비관리 볼륨을 조회한다.

  2. 관리되지 않는 볼륨 선택: namuVIRT 에 의해 제어를 받지 않는 볼륨을 표시하며, 파일명·형식·크기·가상 크기 정보를 확인 후 선택한다.

  3. 볼륨 가져오기 (비관리 → 관리): 우측 하단의 ‘볼륨 가져오기’ 버튼을 클릭하고 다음 항목을 입력/선택한다.

볼륨 가져오기 입력 항목

번호 항목 설명
1 이름(Name) 가져올 볼륨의 식별자 (자동 표시)
2 계정 유형 (Account type) 볼륨 소속 계정 지정 (도메인/프로젝트)
3 디스크 오퍼링 (Disk Offering) 볼륨에 할당할 오퍼링 선택
  1. 관리되지 않는 인스턴스 (관리 → 비관리): 가상머신과 연결되지 않은 볼륨을 선택한 뒤 ‘비관리 인스턴스’ 버튼을 클릭하여 관리 상태를 해제한다.
