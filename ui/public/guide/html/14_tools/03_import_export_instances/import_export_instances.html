인스턴스 가져오기-내보내기 (Import-Export Instances)

인스턴스 가져오기-내보내기 기능은 기존 VMware 또는 namuVIRT 클러스터에서 인스턴스를 가져오거나 내보낼 수 있는 기능이다. 관리 해제된 인스턴스는 실행 상태를 유지하며 하이퍼바이저에 영향을 주지 않는다.


기능 흐름

  1. 소스 하이퍼바이저 선택 (VMware 또는 KVM)
  2. 동작 옵션 선택
  3. 목적지 설정 (Zone, Pod, 클러스터)
  4. 인스턴스 선택 및 가져오기

소스별 옵션

번호 항목 설명
1 VMware 기존 인스턴스 관리 / 관리 해제, 기존 인스턴스를 KVM 으로 마이그레이션
2 KVM 기존 인스턴스 관리 / 관리 해제, 원격 KVM 호스트에서 인스턴스 가져오기, 로컬 저장소에서 QCOW2 이미지 가져오기, 공유 저장소에서 QCOW2 이미지 가져오기

인스턴스 가져오기 설정

인스턴스 가져오기 입력 항목

번호 항목 설명
1 이름 표시 (Display name) 가져올 인스턴스의 표시 이름 (필수)
2 호스트 이름 (Host name) 인스턴스의 호스트명
3 도메인 아이디 (Domain) 인스턴스가 속한 도메인 지정
4 프로젝트(Project) 특정 프로젝트에 포함시킬 수 있음
5 템플릿(Template) OS 템플릿 선택 (필수, 기존 템플릿 선택)
6 컴퓨트 오퍼링 (Compute Offering) CPU / 메모리 사양 선택 (목록에서 단일 선택)
7 마이그레이션 허용 (Migrate allowed) 다른 호스트/풀로 마이그레이션 가능 여부 (토글)
8 강제(Force) MAC 주소 중복 시에도 가져오기 수행 (토글)

관리되지 않는 인스턴스들

관리 중인 인스턴스를 다시 외부 관리 상태로 되돌리는 작업을 수행한다.
