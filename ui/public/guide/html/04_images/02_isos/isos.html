ISOs

namuVIRT에서 ISO 이미지를 등록하고 관리하는 기능으로 ISO VM Root Disk로 사용되는 템플릿과 달리 인스턴스에 CD-ROM 형태로 연결되는 설치 또는 보조 미디어로 사용된다.

ISO 는 운영체제 설치, 드라이버 설치, 도구 제공, 쿠버네티스 바이너리 제공 등 다양한 목적으로 활용할 수 있다. 등록된 ISO 는 상태가 Ready 일 때 인스턴스에 연결하거나 관련 기능에서 사용할 수 있다 .

ISO 생성

ISO 는 URL 기반의 등록과 직접 등록하는 방식으로 제공한다.

항목 설명
URL ISO 파일이 위치한 HTTP/HTTPS URL 입력
이름 등록할 ISO 이름 입력
설명 ISO 용도 또는 OS 정보 입력
직접 다운로드 Management Server를 경유하지 않고 Host/SSVM이 URL에서 직접 다운로드할지 여부 선택
도메인 아이디 ISO를 등록할 도메인 선택
Zone ISO를 등록할 Zone 선택

OS 유형 템플릿의 운영체제 유형

템플릿의 타입

ISO 상세

ISO 상세 화면에서는 선택한 ISO 이미지의 기본 정보, 등록 상태, OS 유형, Zone 별 상태, 이벤트 이력 등을 확인할 수 있다.
