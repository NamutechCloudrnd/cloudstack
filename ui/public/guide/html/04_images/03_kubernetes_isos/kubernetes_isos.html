Kubernetes ISOs

Kubernetes ISO 메뉴에서는 Kubernetes 클러스터 생성에 필요한 Kubernetes 바이너리 ISO와 지원 버전 정보를 등록하고 관리하는 기능이다. 일반 ISO가 VM 부팅 또는 보조 미디어 관리를 위한 메뉴라면 Kubernetes ISO 메뉴는 Kubernetes 클러스터 생성 기능에서 사용할 Kubernetes 버전별 바이너리 ISO를 관리하는 데 목적이 있다.

Kubernetes ISO 목록

등록된 Kubernetes 지원 버전 목록을 조회할 수 있다.

Kubernetes ISO 생성

Kubernetes 클러스터 생성에 사용할 지원 버전과 바이너리 ISO 정보를 등록한다.

Kubernetes ISO 등록은 URL 입력과 직접 등록 방식을 제공한다.

항목 설명
시맨틱 버전 Kubernetes 버전 입력
이름 Kubernetes 지원 버전 이름 입력
Zone Kubernetes ISO를 등록할 Zone 선택
URL Kubernetes 바이너리 ISO 파일이 위치한 URL(HTTP/HTTPS) 입력
체크섬 ISO 파일 무결성 검증 값 입력
최소 CPU 코어 해당 Kubernetes 버전을 사용하기 위한 최소 CPU 코어 수 입력
최소 메모리(MB) 해당 Kubernetes 버전을 사용하기 위한 최소 메모리 용량 입력
직접 다운로드 ISO 다운로드 방식을 직접 다운로드로 처리할지 여부 선택
Arch Kubernetes ISO CPU 아키텍처 선택

Kubernetes ISO 의 생성은 URL 기반 뿐 아니라

Kubernetes ISO 상세

상세 화면에서는 선택한 Kubernetes 지원 버전의 상세 정보와 연결된 ISO 를 확인할 수 있다.

상세 화면에서는 상태를 활성화/비활성화 하는 기능을 제공하며, 상세 페이지에서 삭제 또한 가능하다.
