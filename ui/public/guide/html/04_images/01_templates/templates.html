템플릿

인스턴스 생성에 사용할 OS 이미지 템플릿을 관리하는 기능이다. 템플릿은 VM의 루트 디스크가 될 기본 이미지이며, 인스턴스 생성 시 운영체제, 부팅 방식, 하이퍼 바이저, 디스크 형식 등의 기준이 된다.

템플릿은 일반적으로 Ubuntu, Debian, Rocky Linux, Windows 등 OS 가 설치된 이미지로 구성되며, 사용자는 등록된 템플릿을 선택하여 새로운 인스턴스를 생성할 수 있다.

또한 운영 표준에 맞는 패키지, 보안 설정, 에이전트, 애플리케이션 등을 미리 구성한 Golden 이미지 형태로 등록하여 배포할 수 있다.

템플릿 목록

템플릿 목록에서 등록된 템플릿들을 확인 가능하다.

템플릿 생성

템플릿 등록은 외부 URL을 이용해서 이미지를 가져오거나 직접 업로드 하여 등록할 수 있다. 등록된 템플릿은 이후 인스턴스 생성, Auto Scaling 그룹, 쿠버네티스 클러스터 생성 등에서 사용할 수 있다.

항목 설명
URL 템플릿 이미지 파일이 위치한 HTTP/HTTPS URL 입력
이름 등록할 템플릿 이름 입력
설명 템플릿 용도 또는 OS 정보 입력
Zone 템플릿을 등록할 Zone 선택
도메인 아이디 템플릿을 등록할 도메인 선택
Hypervisor 템플릿이 사용할 Hypervisor 선택
형식 템플릿 이미지 형식으로 QCOW2, RAW, OVA 같은 이미지 형식
OS 유형 템플릿의 운영체제 유형

템플릿의 타입

  • USER, VNF, SYSTEM, BUILTIN, ROUTING

사용자 데이터 적용 정책

로컬 업로드 방식은 외부 URL 을 준비하지 않고 템플릿 파일을 직접 등록할 때 사용한다. 파일 업로드 후에도 템플릿이 실제로 사용가능 상태가 되기까지는 업로드, 저장소 복사, 상태 검증 시간이 필요할 수 있다.

템플릿 상세

템플릿 상세 화면에서는 선택한 템플릿의 기본 정보, 이미지 속성, 설정 값 등을 확인할 수 있다. 또한 템플릿 정보를 편집하거나, 공유 기능 권한 설정, 템플릿 다운로드 등이 가능하다.
