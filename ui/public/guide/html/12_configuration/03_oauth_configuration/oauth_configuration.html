OAuth 설정

Oauth 구성 기능은 외부 인증 사용자인 GitHub 또는 Google 계정을 이용하여 namuVIRT에 로그인할 수 있도록 설정하는 기능이다.

관리자는 포털에서 OAuth 제공자를 등록할 수 있으며, 사용자는 로그인 화면에서 등록된 OAuth 제공자를 선택하여 인증할 수 있다.

OAuth 설정 목록

OAuth 설정 목록 화면에서 등록된 OAuth 제공자 정보를 확인할 수 있다.

관리자는 OAuth 목록 화면에서 OAuth 제공자를 등록할 수 있다.

OAuth 설정 등록

OAuth 제공자를 등록하려면 OAuth 제공자 목록에서 OAUth 등록 버튼을 눌러 등록할 수 있다.

항목 설명
제공자 OAuth 제공자 (github, google)
설명 OAuth 설정을 구분할 수 있는 설명 입력
공급자 클라이언트 ID OAuth 제공자에서 발급받은 Client ID 를 입력
리다이렉션 URI OAuth 제공자에 등록한 Redirect URI 입력
비밀키 OAuth 제공자에서 발급받은 Client Secret 입력
