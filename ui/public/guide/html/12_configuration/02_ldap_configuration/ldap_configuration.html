LDAP 설정

LDAP는 외부 디렉터리 서버와 연동하여 사용자 계정 인증을 처리하기 위한 기능이다.
namuVIRT에서 LDAP를 등록하면 내부 계정만 사용하는 방식이 아니라, 기업 또는 기관에서 운영 중인 LDAP/Active Directory 기반 계정을 활용하여 로그인 및 사용자 인증을 구성할 수 있다.

LDAP 목록

LDAP 메뉴에서는 등록된 서버 목록을 조회할 수 있다.

LDAP 등록

LDAP 등록 화면에서는 namuVIRT와 연동할 LDAP 서버 정보를 입력한다.

LDAP 서버주소, 포트, 도메인을 설정하여 외부 디렉터리와 연결한다.

항목 설명
호스트 LDAP 서버의 IP 주소 또는 FQDN 입력
포트 LDAP 접속 포트 입력
도메인 LDAP인증을 적용할 namuVIRT 도메인 선택
