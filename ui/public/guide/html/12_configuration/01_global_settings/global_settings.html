글로벌 설정

글로벌 설정은 namuVIRT 전체 환경에 적용되는 전역 구성 영역이다. 관리자는 이 메뉴에서 인증, 컴퓨트, 스토리지, 네트워크 하이퍼 바이저, Management Server, System VM , 인프라 사용량 수집 등 namuVIRT 의 주요 동작 방식을 설정할 수 있다.

글로벌 설정에서 변경한 값은 전체 운영에 영향을 줄 수 있으므로, 변경 전에는 설정 적용 범위와 재시작 필요 여부를 확인해야 한다. 일부 설정은 즉시 반영되지만, 일부 설정은 Management Server 재시작, Agent 재연결, System VM 재기동 또는 재 생성이 필요로 할 수 있다.

글로벌 설정 분류

  • Access : namuVIRT 의 사용자 접근, 계정 권한, 인증 연동, 프로젝트 초대 정책, 계정/도메인/프로젝트 단위 리소스 제한을 관리하는 글로벌 설정 분류이다. 관리자는 이 영역에서 계정, 도메인, 프로필 별 기본 사용한도를 설정하고, LDAP 또는 SAML 같은 외부 인증 시스템과 연동이 가능하다.

💡 Info: Access 설정은 크게 Account Domain, Project LDAP, SAML 항목으로 구성 된다.

분류 설명
Account

계정 단위의 접근 정책과 기본 리소스 사용한도를 설정

  • 계정이 사용할 수 있는 CPU, GPU, 메모리, 백업 스토리지, Object Storage, Primary/Secondary Storage, 네트워크, Public IP, 프로젝트, VM, 볼륨, 스냅샷, 템플릿, VPC 등의 최대값을 정의

  • 삭제된 계정의 정리 주기 설정

  • VM 이 실행중인 하이퍼바이저의 호스트명 노출 여부를 설정
Domain

도메인 단위 접근 정책, 설정 상속, 내부 DNS 도메인 suffix, 리소스 사용한도를 설정

  • 태그 기반 오퍼링 생성 허용 여부

  • 동일 도메인 내 계정 조회 권한 및 상위 도메인 설정의 하위 도메인 상속 설정

  • 도메인 단위로 CPU, GPU, 메모리, 스토리지, 네트워크, Public IP, VM, 볼륨 스냅샷, 템플릿 VPC 등의 최대값을 정의
Project

프로젝트 단위 리소스 사용 한도와 프로젝트 초대 메일 발송 정책 설정

  • 프로젝트 단위로 CPU, GPU, 메모리, 스토리지, 네트워크, Public IP, VM, 볼륨 스냅샷, 템플릿, VPC 등 기본 최대값 정의

  • 프로젝트 초대 확인 필요 여부, 초대 만료 시간 등 초대를 위한 설정과 메일 발송을 위한 설정 가능

  • 바인드 계정, 바인드 비밀번호, 사용자명, 이메일, 이름, 성, 속성

  • 사용자/그룹 Object Storage

  • 그룹 멤버십 속성

  • 중첩 그룹 조회 여부

  • 검색 그룹 조건
SAML

  • SAML 플러그인 활성화 여부

  • idP 메타데이터 URL, 기본 idP, SAML 응답 서명 검증

  • 인증 재요청 여부

  • 비밀번호 인증 요구 여부,

  • SSO/SLO URL

  • Service Provider 식별자

  • 조직, 연락처, 사용자 식별 속성, 세션 키 Path 등
  • Compute : namuVIRT 에서 VM, 쿠버네티스, High Availability와 관련된 전역 동작을 관리하기 위한 글로벌 설정이다. 이 영역에서 VM 배포 형식, 호스트 선택 정책, 리소스 Overprovisioning, VM 수집 통계, Disk/네트워크 제한, System VM 동작, 쿠버네티스 Service 사용 여부, HA 복구 정책 등을 설정할 수 있다.

Compute 항목은 크게 Virtual Machine, 쿠버네티스, High Availability 항목으로 구성된다.
