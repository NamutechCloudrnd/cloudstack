하이퍼바이저 기능

하이퍼바이저별 기능 제한 및 기본 동작을 설정하는 기능이다. 각 하이퍼바이저(KVM, VMware, XenServer 등)에 대해 VM 생성 및 운영 시 적용되는 옵션을 관리할 수 있다.

하이퍼바이저별 운영 정책을 통일하여 클러스터의 안정성을 확보하고 VM 리소스를 제한할 수 있다.

화면 구성은 다음과 같다.

  • Hypervisor: 하이퍼바이저 종류

  • Hypervisor version: 하이퍼바이저 유형별로 지원되는 버전

  • Max guest limit: 해당 하이퍼바이저에서 호스트당 생성 가능한 최대 가상머신 수

  • Max hosts per Cluster: 하나의 클러스터에 등록할 수 있는 최대 호스트 수
