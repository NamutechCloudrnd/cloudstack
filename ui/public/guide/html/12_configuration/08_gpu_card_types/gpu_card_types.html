GPU 카드 유형

GPU 장치 정보를 등록하고 관리하는 기능이다. GPU 자원을 사용하는 VM 생성을 위해 GPU 카드 유형을 정의할 수 있다. 등록된 GPU 카드 유형은 컴퓨트 오퍼링 생성 시 선택 기준으로 사용된다.

추가 버튼을 클릭하여 GPU 카드 유형을 등록할 수 있으며, 필요한 정보들은 다음과 같다.

  • 이름: GPU 카드 표기 이름

  • 장치 ID: GPU 카드 ID (1 ~ 9999)

  • 장치 이름: GPU 카드 이름

  • Vendor ID: 제조사 ID (1 ~ 9999)

  • Vendor 이름: 제조사 이름

  • Video Ram: 가상머신에 할당할 비디오 메모리 사이즈 (MB)
