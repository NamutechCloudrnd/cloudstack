계정

계정은 namuVIRT 클라우드 리소스를 관리하고 사용하는 기본 단위이다. 각 계정은 가상 머신, 스토리지, 네트워크 등 리소스를 소유하고 관리할 수 있으며, 리소스 사용에 대한 과금도 계정 단위로 이루어진다. 계정 내에는 여러 사용자를 생성하고, 리소스에 대한 구성을 제한할 수 있다. 계정은 조직이나 개인이 리소스를 효율적으로 관리하고 협업하며 시스템을 안전하게 운영할 수 있도록 지원한다.

목록 조회

계정 목록을 확인하는 화면이다. 생성된 계정 목록을 확인하거나 계정 추가 버튼을 클릭하여 계정을 추가할 수 있다.

계정 추가

계정 추가 버튼을 클릭하여 계정 추가 팝업을 호출한다.

계정 추가를 위한 항목을 입력한다.

  • 역할: 역할을 선택한다.

  • 사용자 이름: 사용자 이름을 입력한다.

  • 비밀번호: 비밀번호를 입력한다.

  • 비밀번호 확인 입력: 동일한 비밀번호를 다시 입력한다.

  • 이메일: 이메일을 입력한다.

  • 이름: 이름을 입력한다.

  • 성: 성을 입력한다.

  • 도메인 아이디: 도메인 아이디를 선택한다.

  • 확인 버튼을 클릭하여 계정을 추가한다.

계정 편집

해당 계정 정보를 편집한다.

  • 계정 편집 버튼을 클릭하여 편집 화면을 호출한다.

  • 수정할 항목을 입력한다.

  • 확인 버튼을 클릭하여 계정을 업데이트한다.

리소스 수 업데이트

해당 계정이 사용 가능한 리소스 수를 업데이트한다.

  • 리소스 수 업데이트 버튼을 클릭하여 편집 화면을 호출한다.

  • 확인 버튼을 클릭하여 리소스 수를 업데이트한다.

계정 비활성화

💡 Warning: 해당 계정의 모든 사용자가 클라우드 리소스에 접근할 수 없게 된다. 실행 중인 모든 가상머신은 바로 종료된다.

해당 계정을 비활성화한다.

  • 계정 비활성화 버튼을 클릭하여 계정 비활성화 화면을 호출한다.

  • 확인 버튼을 클릭하여 계정을 비활성화한다.

계정 활성화

해당 계정을 활성화한다.

  • 계정 활성화 버튼을 클릭하여 계정 활성화 화면을 호출한다.

  • 확인 버튼을 클릭하여 계정을 활성화한다.

계정 잠금

💡 Warning: 해당 계정의 모든 사용자가 클라우드 리소스를 관리할 수 없게 된다. 그 후에도 기존 Zone 리소스에는 접근할 수 있다.

해당 계정을 잠금 설정한다.

  • 계정 잠금 버튼을 클릭하여 계정 잠금 화면을 호출한다.

  • 확인 버튼을 클릭하여 계정을 잠금 설정한다.

인증서 추가

인증서를 추가한다.

  • 인증서 추가 버튼을 클릭하여 인증서 추가 화면을 호출한다.

  • 확인 버튼을 클릭하여 계정에 인증서를 추가한다.

계정 삭제

해당 계정을 삭제한다.

  • 계정 삭제 버튼을 클릭하여 계정 삭제 화면을 호출한다.

  • 확인 버튼을 클릭하여 계정을 삭제한다.

상세 탭

계정에 대한 상세정보를 조회하는 화면이다. 해당 계정의 이름, 아이디, 역할, 역할 유형, 도메인, API 키 액세스, 전체 IP 주소, VM 합계, 볼륨, 생성일 등의 정보를 확인할 수 있다.

제한 탭

해당 계정에 할당된 자원의 제한 정보를 조회하는 화면이다.

구성 제한 탭

해당 계정에 리소스를 할당하는 기능이다. 해당 기능을 통해 계정에서 사용 가능한 자원의 최대값을 설정할 수 있다.

  • 자원 할당 수를 확인하거나 변경한다.

  • 보내기 버튼을 클릭하여 구성 제한을 변경한다.

인증서 탭

계정에 추가된 인증서 정보를 조회하는 화면이다.

설정 탭

계정에서 사용하는 설정을 조회 및 관리하는 화면이다. 해당 계정 설정 정보를 편집하고 초기값으로 원복할 수 있다.

이벤트 탭

계정에 관련된 이벤트 정보를 확인할 수 있는 화면이다. 계정에서 발생한 다양한 액션과 변경 사항을 쉽게 파악할 수 있다.
