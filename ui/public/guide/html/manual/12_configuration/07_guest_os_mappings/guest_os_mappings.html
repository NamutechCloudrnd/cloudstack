게스트 OS 매핑

namuVIRT의 게스트 OS 정보와 실제 하이퍼바이저의 정보의 연결을 설정하는 기능이다. 게스트 OS와 특정 하이퍼바이저의 호환성을 확보하여 가상머신 생성 시 인식 오류를 방지할 수 있다.

namuVIRT에서 기본으로 제공하는 매핑 목록이 존재하며, 추가 버튼을 클릭하여 직접 매핑을 정의할 수 있다. 매핑 생성 시 필요한 정보들은 다음과 같다.

  • OS 유형: namuVIRT에 등록된 게스트 OS

  • 하이퍼바이저: 매핑할 하이퍼바이저 유형 (XenServer, KVM, VMWare 지원)

  • 하이퍼바이저 버전: 매핑할 하이퍼바이저의 버전 (‘default’ 입력 시 기본 버전으로 설정)

  • 하이퍼바이저 매핑 이름: 선택한 하이퍼바이저에서 사용하는 실제 OS 이름

  • OS 이름 확인 옵션: 위에서 작성한 OS 이름 검증 활성화 (VMware, XenServer 지원, 기본 버전 미지원)

  • 강제 옵션: 동일한 사용자 정의 매핑이 존재할 경우, 기존 매핑 덮어쓰기 활성화

상세 페이지에서 해당 게스트 OS 매핑을 수정 및 삭제할 수 있다.
