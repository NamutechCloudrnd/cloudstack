Webhooks

Webhooks 기능은 이벤트에 대한 실시간 알림을 외부 시스템과 연동하여 자동화된 워크플로우를 구축할 수 있도록 지원한다.

기능 사양

Webhooks 기능 사양

번호 항목 설명
1 전송 방식 HTTP POST
2 범위 (Scope) Local / Domain / Global
3 보안 SSL 검증, HMAC SHA256 시그니처 인증
4 헤더 Event ID, User-Agent 를 포함한 커스텀 헤더
5 신뢰성 전송 재시도, 타임아웃 설정, 전송 이력 추적

Webhook 생성

Webhooks 생성 입력 항목

번호 항목 설명
1 이름(Name) Webhook 명 (필수)
2 설명(Description) Webhook 의 용도 및 설명
3 범위(Scope) - 로컬(소유 계정 이벤트)
- 도메인(해당 도메인 이벤트)
- Global(모든 이벤트)
일반 사용자는 로컬만 가능
4 도메인 아이디(Domain) 선택 사항, Webhook 적용 도메인 지정
5 페이로드 URL (Payload URL) 이벤트 발생 시 알림을 전송할 URL (필수)
6 비밀 키(Secret key) 선택 사항, HTTP POST 요청 서명용 비밀 키
7 활성화(Enabled) Webhook 활성화 여부
