가상 라우터

가상 라우터(Virtual Router)는 시스템 가상 머신(System VM)의 한 유형으로, namuVIRT에서 가장 빈번하게 사용되는 서비스 제공자 중 하나이다. 가상 라우터는 라우팅, NAT, DHCP, VPN, 방화벽 등 게스트 네트워크에 필요한 핵심 네트워크 서비스를 제공한다.

최종 사용자는 가상 라우터에 직접 접근할 수 없다. 사용자는 가상 라우터에 ping을 보내거나 포트 포워딩 설정과 같은 작업을 수행할 수 있지만, 가상 라우터에 대한 SSH 접근 권한은 가지지 않는다. 관리자 역시 가상 라우터에 직접 로그인하는 방법은 제공되지 않는다.

가상 라우터의 특성 일부는 연결된 시스템 서비스 오퍼링(System Service Offering)에 의해 결정된다. 단일 게스트 네트워크 내의 모든 가상 라우터는 동일한 시스템 서비스 오퍼링을 사용한다. 커스텀 시스템 서비스 오퍼링을 생성하고 적용함으로써 가상 라우터의 성능을 업그레이드할 수 있다.

목록 조회

가상 라우터 목록을 확인하는 화면이다. 생성된 가상 라우터 목록을 확인할 수 있다.

상세 탭

가상 라우터에 대한 상세 정보를 조회하는 화면이다. 해당 가상 라우터의 이름, 아이디, 버전, 소프트웨어 버전, 업그레이드 필요 여부, 네트워크 이름, Public IP 주소, 게스트 IP 주소, 로컬 연결 IP 주소, 컴퓨트 오퍼링, 네트워크 도메인, Redundant 라우터 여부, Redundant 상태, 호스트, 계정, Zone, 생성일, 제어 영역 상태 등의 정보를 확인할 수 있다.

참고: 상세 탭에서 해당 가상 라우터의 버전과 업그레이드 필요 여부를 확인할 수 있다. 관리 서버 업그레이드 중 namuVIRT는 작업 수행 전에 가상 라우터가 최신 버전인지 확인한다. 가상 라우터가 최신 버전이 아닌 경우 업그레이드 전까지 추가 작업이 수행되지 않으며, 이전 버전의 가상 라우터 서비스는 계속 사용 가능한다.

메트릭 탭

가상 라우터에 대한 메트릭 정보를 조회하는 화면이다. 해당 가상 라우터의 CPU, 메모리, 디스크, 네트워크 등의 사용량 정보를 확인할 수 있다.

💡 Info: 가상 라우터에서 네트워크 사용량 통계를 수집하려면 전역 설정 파라미터 router.stats.interval을 설정한다. 가상 라우터를 통한 네트워크 사용량 통계를 수집하지 않을 경우 해당 값을 0으로 설정한다.

NIC 탭

가상 라우터에 연결된 네트워크를 조회하는 화면이다. 해당 가상 라우터 NIC의 장치 ID, 네트워크 이름, MAC 주소, IP 주소, 넷마스크 등의 정보를 확인할 수 있다.

헬스 체크 탭

가상 라우터에 대한 상태 조회 및 헬스 체크 결과를 확인할 수 있다. 해당 가상 라우터의 체크 이름, 유형, 성공 여부, 마지막 업데이트 시간, 상세 정보 등을 확인할 수 있다.

namuVIRT는 가상 라우터에 대해 기본(Basic) 및 고급(Advanced) 두 가지 범주의 헬스 체크를 제공하며, 각 범주는 별도의 실행 주기를 가진다.

기본(Basic) 헬스 체크 항목:

체크 항목 설명
서비스 체크 SSH(sshd), DNS(dnsmasq), 웹서버(apache2), 로드밸런서(haproxy) 등 데몬 서비스의 실행 여부를 확인한다. 서비스가 중단된 경우 자동으로 재시작을 시도한다.
디스크 공간 체크 가상 라우터의 디스크 여유 공간이 임계값(router.health.checks.free.disk.space.threshold, 기본값 100MB) 이상인지 확인한다.
CPU 사용량 체크 CPU 사용률이 설정된 임계값(router.health.checks.max.cpu.usage.threshold) 이하인지 확인한다.
메모리 사용량 체크 메모리 사용률이 설정된 임계값(router.health.checks.max.memory.usage.threshold) 이하인지 확인한다.
라우터 버전 체크 가상 라우터의 템플릿 및 스크립트 버전이 관리 서버의 버전과 일치하는지 확인한다.
게이트웨이 연결 체크 관리 서버에서 전달한 게이트웨이 IP에 대한 ping 성공 여부를 확인한다.

고급(Advanced) 헬스 체크 항목:

체크 항목 설명
DNS 구성 체크 가상 라우터의 /etc/hosts 내용이 관리 서버 DB의 인스턴스 레코드와 일치하는지 확인한다.
DHCP 구성 체크 가상 라우터의 /etc/dhcphosts.txt 내용이 관리 서버 DB의 인스턴스 레코드와 일치하는지 확인한다.
HAProxy 구성 체크 가상 라우터의 /etc/haproxy/haproxy.cfg가 관리 서버 DB의 로드밸런싱 규칙과 일치하는지 확인한다.
iptables 규칙 체크 iptables 포트 포워딩 설정이 관리 서버 DB의 레코드와 일치하는지 확인한다.

헬스 체크 관련 주요 전역 설정 파라미터:

파라미터 기본값 설명
router.health.checks.enabled true 헬스 체크 기능 활성화 여부
router.health.checks.basic.interval 3분 기본 헬스 체크 실행 주기(분). 0으로 설정 시 비활성화
router.health.checks.advanced.interval 10분 고급 헬스 체크 실행 주기(분). 0으로 설정 시 비활성화
router.health.checks.failures.to.recreate.vr (없음) 가상 라우터 재생성을 유발하는 헬스 체크 실패 항목 지정

서비스 모니터링 활성화: 전역 파라미터 network.router.enableservicemonitoring을 활성화하면 서비스 모니터링 도구가 동작한다. 기본값은 false(비활성화)이며, 활성화 시 관리 서버와 라우터를 재시작해야 한다. 모니터링은 Isolated Networks, Shared Networks(Advanced/Basic Zone), VPC를 지원하며, XenServer, VMware, KVM 하이퍼바이저에서 지원된다.

Health Check 결과 가져오기

헬스 체크 결과를 즉시 요청하는 기능이다.

Health Check 결과 가져오기 버튼을 클릭하여 화면을 호출한 뒤 확인 버튼을 클릭한다.

참고: 즉시 체크 요청은 관리 서버가 라우터에 최신 데이터를 전달하고, 기본 및 고급 체크를 모두 실행한 후 결과를 가져오는 작업이므로 비용이 큰 작업이다.

볼륨 탭

가상 라우터에 연결된 볼륨을 조회하는 화면이다. 해당 가상 라우터의 볼륨에 대한 이름, 상태, 유형, 크기, 스토리지 등의 정보를 확인할 수 있다.

이벤트 탭

가상 라우터에 관련된 이벤트 정보를 확인할 수 있는 화면이다. 가상 라우터에서 발생한 다양한 액션과 변경 사항을 파악할 수 있다.

코멘트 탭

가상 라우터에 관련된 코멘트를 확인할 수 있는 화면이다.

콘솔 보기

가상 라우터의 콘솔에 접근하는 기능이다.

콘솔 보기 버튼을 클릭하여 가상 라우터 콘솔 화면을 호출한다.

참고: namuVIRT에서 관리자가 가상 라우터에 직접 로그인하는 메커니즘은 제공되지 않는다.

클립보드에 콘솔 URL 복사

가상 라우터의 콘솔에 접근할 수 있는 URL을 클립보드에 복사한다.

라우터 정지/시작

가상 라우터를 정지/시작한다.

라우터 정지/시작 버튼을 클릭하여 정지/시작 화면을 호출한 뒤 확인 버튼을 클릭한다.

라우터 재시작

가상 라우터를 재시작한다.

라우터 재시작 버튼을 클릭하여 재시작 화면을 호출한 뒤 확인 버튼을 클릭한다.

주의: 관리자가 가상 라우터를 재시작하면 최종 사용자의 공용 네트워크 접근 및 기타 서비스가 일시적으로 중단된다.

중요: 하이퍼바이저 콘솔에서 가상 라우터를 재시작하면 모든 iptables 규칙이 삭제된다. 이 문제를 방지하려면 반드시 namuVirt UI에서 라우터를 정지한 후 시작해야 한다.

시스템 VM 패치

시스템 VM을 패치하여 가상 라우터의 버전을 변경할 수 있다.

시스템 VM 패치 버튼을 클릭하여 시스템 VM 패치 화면을 호출한 뒤 확인 버튼을 클릭한다.

최신 템플릿을 사용하도록 라우터 업그레이드

가상 라우터를 최신 시스템 VM 템플릿으로 업그레이드한다.

namuVIRT관리자는 가상 라우터 업그레이드 순서를 제어할 수 있다. 순서는 클러스터, Pod, Zone 등의 인프라 계층 또는 테넌트, 도메인 등의 관리 계층을 기준으로 지정할 수 있다. 업그레이드는 가능한 한 많은 작업을 병렬로 수행하여 속도를 높이다.

주의: 업그레이드 전체 기간 동안 사용자는 새로운 서비스를 시작하거나 기존 서비스를 변경할 수 없다.

최신 템플릿을 사용하도록 라우터 업그레이드 버튼을 클릭하여 라우터 업그레이드 화면을 호출한 뒤 확인 버튼을 클릭한다.

가상 라우터 마이그레이션

가상 라우터를 다른 호스트로 마이그레이션한다.

시스템 VM은 동일한 클러스터 내의 호스트 간에만 마이그레이션할 수 있다. VMware의 경우 동일한 Pod 내의 다른 클러스터 호스트로도 마이그레이션이 가능한다.

가상 라우터 마이그레이션 버튼을 클릭하여 마이그레이션 화면을 호출한다. 대상 호스트를 선택한 후 확인 버튼을 클릭한다.

진단 실행

가상 라우터에서 네트워크 진단 명령(ping, traceroute, arping)을 원격으로 실행할 수 있다.

진단 실행 버튼을 클릭하여 진단 실행 화면을 호출한다. 진단 유형과 대상 주소를 입력한 후 확인 버튼을 클릭한다.

참고: Extra Args 파라미터를 통해 각 명령의 추가 옵션을 지정할 수 있다. 단, 영문자와 숫자 이외의 특수 문자(메타 문자)는 허용되지 않으며, -와 .만 예외적으로 허용된다. 허용되지 않는 문자가 입력되면 명령이 즉시 종료된다.

진단 데이터 import

가상 라우터에서 진단 데이터 파일 묶음을 가져온다. 파일은 압축되며, 다운로드할 수 있는 URL이 반환된다.

진단 데이터 import 버튼을 클릭하여 진단 가져오기 화면을 호출한 뒤 확인 버튼을 클릭한다.

가상 라우터에서 기본으로 수집되는 진단 파일 목록은 전역 설정 diagnostics.data.router.defaults로 구성할 수 있으며, 기본 수집 항목은 다음과 같다.

  • iptables, ipaddr, iproute

  • /etc/cloudstack-release

  • /etc/dnsmasq.conf, /etc/dhcphosts.txt, /etc/dhcpopts.txt

  • /etc/dnsmasq.d/cloud.conf, /etc/dnsmasq-resolv.conf

  • /var/lib/misc/dnsmasq.leases, /var/log/dnsmasq.log

  • /etc/hosts, /etc/resolv.conf

  • /etc/haproxy/haproxy.cfg, /var/log/haproxy.log

  • /etc/ipsec.d/l2tp.conf

  • /var/log/cloud.log, /var/log/routerServiceMonitor.log, /var/log/daemon.log

진단 데이터 관련 주요 전역 설정:

파라미터 기본값 설명
diagnostics.data.retrieval.timeout 1800초 시스템 VM 스크립트 실행 전체 타임아웃(초)
diagnostics.data.disable.threshold 0.95 (95%) 2차 스토리지 사용률이 이 값 이하일 때만 파일 수집 허용
diagnostics.data.max.file.age 86400초 (1일) 파일이 스토리지에 유지되는 최대 시간
diagnostics.data.gc.enable true 오래된 진단 파일을 자동으로 삭제하는 GC 작업 활성화 여부
diagnostics.data.gc.interval 86400초 (1일) GC 작업 실행 주기(초)

라우터 파기

해당 가상 라우터를 삭제한다.

참고: 가상 라우터를 삭제하더라도 해당 네트워크가 활성화 상태이면 namuVirt가 자동으로 새 가상 라우터를 생성한다.

주의: 네트워크에 가상 라우터가 하나만 존재할 때는 삭제를 주의해야 한다. 단일 라우터를 삭제하고 재생성하려면 cleanup=true 파라미터와 함께 네트워크 재시작을 사용해야 한다.

라우터 파기 버튼을 클릭하여 삭제 화면을 호출한 뒤 확인 버튼을 클릭한다.
