Affinity 그룹

Affinity 그룹은 인스턴스이 배치 위치를 제어하기 위한 정책그룹이다. 인스턴스 생성 시 Affinity 그룹을 지정하면, 해당 인스턴스가 어떤 Host에 배치될지 또는 다른 인스턴스와 같은 Host에 배치될지 여부를 정책으로 제어할 수 있다.

일반 인스턴스, Auto Scaling 그룹, 쿠버네티스 노드처럼 VM이 생성되는 환경에서 Affinity 그룹을 활용하면 서비스 특성에 맞는 배치 전략을 적용할 수 있다.

Affinity 그룹 생성

Affinity 그룹 생성을 통해 인스턴스 배치 정책에 사용할 그룹을 생성할 수 있다.

항목 설명
이름 생성할 Affinity 그룹 이름
설명 Affinity 그룹 용도 또는 운영 목적 입력
유형 인스턴스 배치 정책 유형 선택

Affinity 그룹 생성 시 선택할 수 있는 유형은 다음과 같다.

유형 설명
Host anti-affinity (Strict) 같은 그룹의 인스턴스를 반드시 서로 다른 Host에 배치
Host affinity (Strict) 같은 그룹의 인스턴스를 반드시 같은 Host에 배치
Host anti-affinity (Non-Strict) 가능하면 서로 다른 Host에 배치하되, 불가능하면 다른 Host 배치를 강제하지 않음
Host affinity (Non-Strict) 가능하면 같은 Host에 배치하되, 불가능하면 같은 Host 배치를 강제하지 않음

Strict 유형은 조건을 반드시 만족해야 하므로, 조건을 만족할 수 있는 Host가 없으면 인스턴스 생성 또는 시작이 실패할 수 있다. Non-Strict 유형은 배치 정책을 우선 적용하지만, 조건을 만족할 수 없는 경우에도 인스턴스 생성이 가능하도록 유연하게 동작한다.

운영 환경에서는 고가용성이 필요한 서비스는 host anti-affinity를 주로 사용하고, 특정 Host와 함께 배치해야 하는 특수한 워크로드는 host affinity를 사용할 수 있다.
