인스턴스 그룹

인스턴스 그룹은 여러 인스턴스를 논리적으로 묶어 관리하기 위한 기능으로, 동일 서비스, 동일 업무, 동일 운영 목적을 가진 VM을 그룹단위로 분류할 때 사용된다.

가상 머신 그룹은 인스턴스의 실행 위치나 리소스 배치 정책을 직접 제어하는 기능은 아니며, 운영 관리와 분류를 위한 논리적 그룹에 가깝다. 예를 들어 웹 서버 그룹, DB 서버 그룹 처럼 용도별로 인스턴스를 구분할 때 활용 가능하다.

인스턴스 그룹 목록

인스턴스 Groups 메뉴에서는 생성된 인스턴스 그룹 목록을 조회하고 관리할 수 있으며, 새 가상머신 그룹 생성과 삭제가 가능하다.

인스턴스 그룹 생성

가상머신 그룹을 생성한 후에는 인스턴스 생성 또는 인스턴스 편집 시 해당 그룹을 지정할 수 있다.

인스턴스 그룹 상세

인스턴스 그룹 상세 화면에서는 선택한 인스턴스 그룹의 기본 정보와 소유 정보를 확인할 수 있으며, 상세 화면에서는 그룹 이름, ID, 계정 등을 조회할 수 있다.
