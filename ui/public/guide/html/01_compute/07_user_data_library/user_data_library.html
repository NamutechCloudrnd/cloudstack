사용자 데이터

사용자 데이터 라이브러리는 인스턴스 생성 시 VM에 전달할 사용자 데이터를 미리 등록하고 관리하는 기능이다. 사용자 데이터는 VM 최초 부팅 시 초기 설정, 패키지 설치, 서비스 실행, 설정 파일 생성 등 자동화 작업에 활용할 수 있다.

사용자 데이터는 일반 인스턴스 생성 뿐 아니라 Auto Scaling 그룹,쿠버네티스 노드 생성 등 자동으로 VM이 생성되는 환경에서도사용할 수 있다. 이를 통해 Scale-Up 또는 클러스터 노드 생성 시 동일한 초기화 스크립트와 설정을 반복 적용할 수 있다.

사용자 데이터 목록

등록된 사용자 데이터 목록을 조회할 수 있다.

사용자 데이터 생성

사용자 데이터 등록 화면에서는 인스턴스에 전달할 사용자 데이터 내용을 등록할 수 있다.

항목 설명
이름 등록할 사용자 데이터 이름 입력
사용자 데이터 VM에 전달할 사용자 데이터 내용 입력
Base64 인코딩됨 입력한 사용자 데이터가 Base64로 인코딩되어 있는지 여부 선택
사용자 데이터 매개변수 사용자 데이터 내부에서 사용할 변수 목록 입력
도메인 아이디 사용자 데이터를 등록할 도메인 선택

사용자 데이터는 일반 텍스트 또는 Base64로 인코딩된 값으로 입력할 수 있다. 일반적으로 cloud-init 스크립트, shell script, 초기 설정 값 등을 등록하여 VM 생성 시 자동 실행되도록 구성한다.

사용자 데이터 상세

상세 조회화면에서는 선택한 사용자 데이터 의 기본 정보와 등록된 내용을 확인할 수 있다.
