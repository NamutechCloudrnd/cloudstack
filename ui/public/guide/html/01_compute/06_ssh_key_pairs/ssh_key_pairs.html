SSH Key Pairs

SSH Key Pair 는 인스턴스에 SSH 로 접속할 때 사용하는 인증 키정보이다. 사용자는 SSH Key Pair를 생성하거나 기존 Public Key를 등록한 뒤, 인스턴스 생성 시 해당 Key Pair를 선택하여 VM에 접속할 수 있다.

SSH Key Pair는 일반적으로 Linux 계열 인스턴스 접속에 사용되며, 비밀번호 방식보다 보안성이 높은 인증 방식이다. namuVIRt에서는 SSH Key Pair를 생성하면 Public Key 는 플랫폼에 등록되고, Private Key는 사용자가 직접 다운로드하거나 복사하여 보관해야 한다.

SSH Key Pairs 목록

등록된 SSH Key Pair 의 목록을 조회할 수 있다.

SSH Key Pairs 생성

SSH Key Pair 를 생성하거나 이미 보유한 Public Key를 등록할 수 있다.

항목 설명
이름 생성 또는 등록할 Key Pair의 이름 입력
공개 키 기존 public key 를 등록할 경우 입력
도메인 아이디 SSH Key Pair를 등록할 도메인 선택

공개키를 입력하지 않으면 namuVIRT가 새 SSH Key Pair를 생성한다. 이 경우 생성 완료 후 표시되는 Private Key를 클립보드로 복사하거나 다운로드하여 별도로 보관해야 한다.

Private Key는 최초 생성 시점에서만 확인할 수 있으며, namuVIRT는 Private Key를 보관하지 않는다. 따라서 생성 직후 반드시 안전한 위치에 저장해야 한다.
