인스턴스

namuVIRT의 인스턴스 는 사용자가 생성하고 운영하는 가상머신을 관리할 수 있습니다. 관리자는 인스턴스의 생성, 시작, 정지, 재시작, 삭제, 복구, 콘솔 접속, 리소스 변경, 마이그레이션 등 VM 운영에 필요한 작업을 수행할 수 있다.

인스턴스 는 namuVIRT 의 Compute 영역에서 가장 기본이 되는 리소스로 사용자는 Service Offering, Disk Offering, 템플릿 또는 ISO, Network, SSH Key, Affinity 그룹 등 조건을 선택하여 VM 을 생성할 수 있습니다. 생성된 인스턴스 는 Hypervisor Host 위에서 실행되며, 설정된 네트워크와 스토리지 정책에 따라 IP, Volume, 스냅샷, Security 그룹, Public IP 등의 리소스와 연동된다.

인스턴스 목록

인스턴스 메뉴에서는 namuVIRT 환경에 생성된 가상 머신 목록을 조회하고, 각 인스턴스 의 상태와 주요 구성정보를 확인할 수 있습니다. 인스턴스 목록에서는 사용자가 운영 중인 VM 을 한눈에 확인하기 위한 화면으로, VM의 전원 상태, Zone, Host, IP 주소 등의 정보를 기준으로 인스턴스를 관리할 수 있다.

또한 인스턴스 목록에서는 검색 기능을 이용해서 VM 을 조회할 수 있다.

인스턴스 추가

사용자는 namuVIRT 의 인스턴스 생성 마법사를 통해 소유 계정, 배포 인프라, 부팅 이미지, Offering, SSH Key 등 VM 생성에 필요한 항목을 단계별로 선택할 수 있다. 인스턴스 추가 과정에서 먼저 소유자 유형(계정, 프로젝트), 도메인, 소유자 정보를 지정하고, VM 이 배포되기 위한 Zone, Pod, Cluster, Host 등 인프라 위치를 지정합니다. 이후 템플릿, ISO, Volume, 스냅샷 중 하나를 부팅 소스로 지정하고, CPU/Memory 사양과 Disk 구성을 지정하여 VM 을 생성한다.

  1. 소유자 할당

인스턴스 생성시 가상머신의 소유자를 지정하는 단계입니다. 관리자는 이 단계에서 생성되는 인스턴스 를 어떤 도메인, 계정 또는 프로젝트에 할당할지 선택할 수 있다.

가상머신은 선택한 소유자 기준으로 생성되며, 생성 이후 해당 계정 또는 프로젝트의 리소스로 관리된다. 따라서 인스턴스 사용 권한, 리소스 사용량, 과금, Usage 집계, 프로젝트 소속 여부 등이 이 단계에서 선택한 값에 따라 결정된다.

일반 사용자는 보통 자신의 계정으로만 인스턴스 를 생성하지만, 관리자는 운영 목적에 따라 특정 계정이나 프로젝트를 지정하여 인스턴스 를 생성할 수 있다.

  1. 배포 인프라 선택

인스턴스를 배포할 인프라 위치를 선택하는 단계입니다. 이 단계에서는 가상머신이 어느 Zone, Pod, Cluster, Host 에 배포될지 지정할 수 있다.

Zone은 일반적으로 하나의 데이터센터 또는 물리적으로 분리된 인프라 영역으로 여러 Zone을 구성하면 장애 영역을 분리할 수 있어 클라우드의 안정성과 가용성을 높일 수 있다.

인스턴스를 배포할 Host 선택

  1. 이미지 선택

인스턴스 생성 시 VM 의 부팅 소스로 사용할 이미지를 선택하는 단계입니다. 사용자는 템플릿, ISO, Volume, 스냅샷 중 하나를 선택하여 인스턴스를 생성할 수 있다.

항목 설명
유형

인스턴스 생성에 사용할 부팅 소스 유형 선택

  • 템플릿 / ISO / Volume / 스냅샷 선택 가능

선택된 유형에 따라 인스턴스 생성을 위한 제공 방식이 달라짐

  • 템플릿 : 사전에 등록된 OS 이미지 기반으로 인스턴스 생성

  • ISO : ISO 이미지 선택하여 인스턴스 생성

  • Volume : 기존 Volume 를 부팅 Disk로 사용하여 인스턴스 생성

  • 스냅샷 : 스냅샷 을 기반으로 인스턴스 생성
  1. 컴퓨트 오퍼링

인스턴스 생성 시 VM에 할당할 CPU와 메모리 사양을 선택하는 단계입니다. 컴퓨트 오퍼링은 VM의 기본 성능을 결정하는 항목으로, 선택한 오퍼링에 따라 인스턴스 에 지공되는 vCPU 개수, CPU 속도, 메모리 크기등이 달라진다.

컴퓨트 오퍼링은 인스턴스 생성 후 성능과 리소스 사용량에 직접적인 영향을 주므로 운영 목적에 맞게 CPU와 메모리 용량을 확인한 후 선택한다.

항목 설명
컴퓨트 오퍼링 인스턴스에 적용할 CPU/메모리 사양 선택
Override root disk offering

Root Disk Offering을 별도로 지정할지 여부 선택

  • 비활성화 : 템플릿 또는 Compute Offering의 기본 Root Disk 구성 적용

  • 활성화 : Disk Offering 목록에서 Root Disk 크기와 성능 정책 별도 선택
  1. 데이터 Disk

인스턴스 생성 시 Root Disk에 적용할 Disk Offering 또는 사용자 지정 Disk 크기를 선택하는 단계이다. 이 단계는 선택한 이미지 또는 컴퓨트 오퍼링과 별도로 Root Disk 용량을 지정해야 할 때 사용한다.

항목 설명
디스크 크기

Root Disk에 적용할 Disk Offering 선택

  • 사전에 정의된 Disk Offering 를 선택

  • Custom : 사용자가 직접 디스크 크기를 입력

Custom Disk 크기를 사용할 경우 운영 정책에서 허용하는 최소/최대 디스크 크기 범위 내에서 값을 입력해야 한다. 디스크 크기는 인스턴스 생성 후 스토리지 사용량에 직접 반영되므로, OS 및 서비스 운영에 필요한 용량을 고려하여 설정한다.

  1. 네트워크

인스턴스에 연결할 네트워크를 선택하는 단계로 하나 이상의 네트워크를 선택할 수 있으며, 필요한 경우 이 단계에서 새로운 네트워크를 생성할 수도 있다.

선택한 네트워크는 인스턴스의 NIC 로 연결되며, 네트워크 유형에 따라 IP 할당 방식, VPC 연결 여부, 외부 통신 방식, 보안 정책 등이 달라질 수 있다.

항목 설명
네트워크 인스턴스에 연결할 네트워크를 선택하며, 새로운 네트워크 생성이 가능
IP / MAC 주소 필요한 경우 인스턴스에 할당할 IP 주소 또는 MAC 주소 직접 지정 가능

일반적으로 기본 네트워크를 선택하면 자동으로 IP가 할당된다. 특히 IP나 MAC 주소가 필요한 경우 하단 입력 영역에서 값을 직접 지정할 수 있다.

  1. SSH Key

인스턴스에 접속할 때 사용할 SSH Key Pair를 선택하는 단계로 선택한 SSH 키는 인스턴스 생성 시 VM 에 등록되며, 사용자는 해당 키의 Private Key를 이용해 VM에 SSH 접속을 할 수 있다.

SSH 키를 선택하지 않아도 인스턴스 생성은 가능하지만, Linux 계열 VM에 SSH로 접속해야 하는 경우에는 사전에 등록된 SSH Key Pair를 선택하는것을 권장한다.

  1. 백업

인스턴스 생성 시 해당 VM에 적용할 백업 오퍼링과 백업 일정을 선택하는 단계로 백업 오퍼링을 선택하면 인스턴스에 대한 자동 백업 또는 예약 백업을 구성하여 장애나 데이터 손실 상황에 대비할 수 있다.

백업 오퍼링과 백업 일정을 설정하면 인스턴스 생성 후 지정된 정책에 따라 백업이 수행된다. 운영 환경에서는 서비스 중요도와 데이터 보존 정책에 맞는 백업 오퍼링을 선택하는 것이 좋다.

  1. 확장 모드(고급 설정)

인스턴스 생성 시 고급 옵션을 설정하는 단계로 고급 설정 표시를 활성화하면 부팅 방식, 동적 스케일링, Affinity 그룹, NIC 및 I/O 관련 세부 옵션을 지정할 수 있다.

사용자 데이터는 Cloud-Init 등 초기 설정 자동화에 활용 가능하며, 저장된 사용자 데이터를 선택하거나 직접 입력할 수 있다. Affinity 그룹은 VM 배치 정책에 영향을 주며, 특정 VM들을 같은 Host에 배치하거나 서로 다른 Host에 분산 배치해야 할 때 사용한다.

  1. 상세

인스턴스 상세

인스턴스 상세 화면에서는 선택한 가상머신의 기본 정보, 리소스 구성, 네트워크, 볼륨, 스냅샷, 백업, 이벤트 등 운영에 필요한 세부 정보를 확인할 수 있다. 좌측 영역에서는 인스턴스의 주요 상태와 구성 정보를 확인 할 수 있으며, 우측 상세 영역에서는 항목별 탭을 통해 세부 정보를 관리할 수 있다.

또한, 상단 메뉴에서 인스턴스 이름과 OS 유형 등 변경 가능한 편집 기능과 시작, 정지, 재시작, 스냅샷 등 VM을 컨트롤하기 위한 기능을 제공한다.

인스턴스 수정

인스턴스 편집은 생성된 가상머신의 기본 정보와 일부 운영 설정을 변경하는 기능이다. 편집 화면에서는 인스턴스 이름, 표시 이름, OS 유형, 동적 스케일링 여부, 그룹, 사용자 데이터, 삭제 보호 설정등을 수정할 수 있다.

또한 인스턴스 상세 화면의 설정 탭에서는 가상머신에 적용할 수 있는 세부 설정값을 추가, 수정, 삭제할 수 있다. 이 설정은 VM의 키보드, NIC, CPU, Video, TPM, I/O 등 고급 동작을 제어할 때 사용한다.

인스턴스 삭제

인스턴스 의 삭제는 인스턴스 목록 또는 상세 조회의 삭제버튼을 이용하여 삭제할 수 있다.
