VM 스냅샷

VM 스냅샷은 인스턴스 의 특정 시점 상태를 보관하는 기능으로 운영자는 VM 스냅샷을 이용하여 OS 패치, 애플리케이션 배포, 설정 변경 등 주요 작업을 수행하기 전에 현재 VM 상태를 저장할 수 있다.

VM 스냅샷 은 일반 Volume 스냅샷 과 달리 인스턴스 단위로 생성되며, VM의 디스크 상태를 기준으로 복구 지점을 제공한다. 설정에 따라 VM 메모리 상태까지 포함할 수 있으므로, 장애 발생 시 작업 전 상태로 되돌리는 용도로 활용할 수 있다.

VM 스냅샷은 다음과 같은 상황에서 사용한다.

  • OS 패치 또는 업데이트 전 복구 지점 생성

  • 애플리케이션 설치 또는 설정 변경 전 상태 보관

  • 장애 발생 시 이전 VM 상태로 복원

  • 테스트 작업 수행 전 운영 안정성 확보

VM 스냅샷 메뉴에서는 생성된 목록을 조회하고, 스냅샷의 상태, 유형, 생성일, 계정, 도메인 등을 확인할 수 있다. 또한 인스턴스 상세 화면에서 VM 스냅샷을 생성하거나, 생성된 스냅샷 기준으로 복원 및 삭제 작업을 수행할 수 있다.

운영 시에는 VM 스냅샷 을 장기 백업 용도로 사용하기 보다는, 변경 작업 전후의 단기 복구지점으로 사용하는 것이 적절하다. 장기간 데이터 보호가 필요한 경우에는 Backup 또는 Volume 스냅샷 정책과 함께 운영하는 것이 좋다.

VM 스냅샷 목록

VM 스냅샷 목록에서는 인스턴스 에서 생성한 스냅샷 의 목록을 확인할 수 있다.

VM 스냅샷 목록에서 특정 스냅샷 을 선택하면 상세 정보를 확인하거나, 필요에 따라 복원 또는 삭제 작업을 수행할 수 있다.

VM 스냅샷 생성

인스턴스 스냅샷 은 인스턴스 상세에서 버튼(스냅샷 버튼)을 이용하여 생성할 수 있다.

항목 설명
이름 생성할 VM 스냅샷 이름 입력
설명 스냅샷 용도나 작업 내용을 설명하는 메모 입력
스냅샷 메모리 VM Memory 상태까지 스냅샷에 포함할지 여부 선택
VM 정지 스냅샷 생성 전 VM 을 정지할지 여부 선택

운영 환경에서는 OS 패치, 애플리케이션 배포, 주요 설정 변경 전 VM 스냅샷을 생성해 두면 장애 발생 시 이전 상태로 복구하는데 활용 가능하다.

VM 스냅샷 상세

VM 스냅샷 상세 화면에서는 선택한 스냅샷의 상태, 연결된 인스턴스, 소유 계정, 생성일 등 상세 정보를 확인할 수 있다. 좌측 요약 영역에서는 스냅샷 의 핵심 정보를 빠르게 확인할 수 있으며, 우측 탭에서는 상세 정보, 이벤트, 코멘트를 조회할 수 있다.

아래는 우측 탭에 대한 설명이다.

항목 설명
상세 스냅샷의 이름, ID, 유형 등 상세정보 조회
이벤트 스냅샷 생성, 오류, 삭제 등 관련 이벤트 이력
코멘트 스냅샷 운영 메모 또는 코멘트 관리

VM 스냅샷 삭제

VM 스냅샷의 삭제는 VM 스냅샷 목록 또는 상세 조회의 삭제버튼을 이용하여 삭제할 수 있다.
