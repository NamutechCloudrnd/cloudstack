확장 기능 (Extensions)

확장(Extensions) 기능은 namuVIRT 가 호출할 수 있는 특정 작업을 구현하는 외부 바이너리(모든 프로그래밍 언어로 작성 가능)로 정의되며, 운영자가 NamuVIRT 외부에서 리소스의 수명 주기 작업을 관리할 수 있도록 지원한다. 예를 들어 타사 시스템에서 VM 을 프로비저닝하거나 외부 자동화 파이프라인을 실행할 수 있다. 확장 기능은 API 와 UI 를 통해 관리되며, 구성, 리소스 매핑 및 액션 실행 등의 기능을 제공한다.

확장 기능 목록

확장 기능 목록은 namuVIRT 에 등록된 확장 기능의 전체 목록을 조회하는 화면이다. 관리자는 확장 기능의 상태, 유형, 실행 경로 및 가용성 정보를 확인할 수 있으며, 확장 활성화 및 상세 화면 진입 기능을 제공한다.

확장 기능 목록

번호 항목 설명
1 이름(Name) 확장 기능명
2 상태(State) 확장 기능 현재 상태, 활성화 (Enabled) / 비활성화 (Disabled)로 구분.
3 유형(Type) 확장 기능 유형, 현재 Orchestrator 타입 지원.
4 경로(Path) 확장 실행 시 호출되는 바이너리 또는 스크립트 경로
ex) /usr/share/cloudstackmanagement/extensions/<extensions_name>
5 가용성(Availability) 확장 실행 파일 준비 상태, Ready / Not Ready 로 구분. 파일이 없거나, 접근할 수 없거나, 관리 서버마다 경로가 다른 경우 ’Not Ready’로 표시
6 생성일(Created) 확장 기능 생성 날짜 및 시간

확장 생성 (Create Extension)

확장 생성(Create Extension) 기능은 namuVIRT 에서 사용할 외부 확장 기능을 등록하는 기능이다. 관리자는 실행 파일 경로, 유형, 설정 정보 및 확장 옵션 등을 입력하여 새로운 확장 기능을 생성할 수 있다.

확장 생성 입력 항목

번호 항목 설명
1 이름(Name) 확장 기능 명 (필수)
2 설명(Description) 확장 기능의 용도 및 설명
3 경로(Path) 확장 실행 파일 또는 스크립트 상대 경로
실행 파일은
- 클라우드 사용자 및 그룹의 소유
- 실행 권한 필요
4 유형(Type) 확장 기능 유형, 현재 Orchestrator 타입 지원.
5 인스턴스 준비 필요 (Instance Preparation Required) VM 배포 전 사전 준비 (Prepare) 작업 수행 여부 지정
활성화 시 인스턴스 VNC 암호, MAC 주소, 세부 정보 및 NIC 의 IPv4 / IPv6 주소와 같은 제한된 필드 업데이트 가능.
6 구성 세부 정보 (Configuration Details) 확장 생성 시 사용할 Key-Value 형태의 설정 정보, 확장 프로그램, 클러스터 매핑, 호스트, 템플릿, 서비스 제공, 인스턴스 등 다양한 수준에서 지정 가능.
7 예약된 리소스 세부 정보 (Reserved Resource Details) 확장 기능이 사용하는 예약 리소스 관련 세부 정보 설정.
리소스 예약 및 오케스트레이션 처리 시 사용되는 확장 메타데이터 저장 영역으로 활용
8 활성화(Enabled) 확장 기능 활성화 여부

확장 상세 (Extensions Detail)

확장 상세 화면은 선택한 확장의 구성 정보, 리소스 연결 상태, 커스텀 액션 및 이벤트 내역 등을 조회 및 관리하는 화면이다.

확장 상세 정보

확장 상세 화면 좌측에는 확장 기능의 상태(State), 아이디(ID), 생성일(Created), 보기 가상머신(View Instances), 보기 템플릿(View Templates)과 우측 탭 메뉴 내 상세(Details), 리소스(Resources), 커스텀 액션(Custom Actions), 이벤트(Events)로 구성되어 있으며 다음과 같다.

확장 상세 정보 목록

번호 항목 설명
1 상태(State) 확장 기능 현재 상태
활성화 (Enabled) / 비활성화 (Disabled)로 구분.
2 아이디(ID) 확장 기능 고유 식별자 표시
3 생성일(Created) 확장 기능 생성 날짜 및 시간
4 보기 가상머신 (View Instances) 해당 확장 기능을 사용하는 가상머신 목록 조회
5 보기 템플릿 (View Templates) 해당 확장과 연결된 템플릿 목록 조회

상세 (Details)

확장 상세 화면 우측에 위치한 상세(Details) 탭은 확장 기능의 기본 설정 및 실행 정보를 조회하는 영역이며 다음과 같다.

상세 목록

번호 항목 설명
1 이름(Name) 확장 기능 명 (필수)
2 설명(Description) 확장 기능의 용도 및 설명
3 아이디(ID) 확장 기능 고유 식별자 표시
4 유형(Type) 확장 기능 유형
5 구성 세부 정보 (Configuration Details) 확장 생성 시 사용할 Key-Value 형태의 설정 정보
6 경로(Path) 확장 실행 시 호출되는 바이너리 또는 스크립트 경로
ex) /usr/share/cloudstack-management/extensions/<extensions_name>
7 경로 준비됨 (Path Ready) 실행 파일 준비 상태를 표시 (true / false)
8 사용자 정의 (User defined) 사용자 생성 확장 여부를 표시 (true / false)
9 인스턴스 준비 필요 (Requires Prepare Instance) 인스턴스 사전 준비 기능 활성화 여부를 표시 (true / false)
10 생성일(Created) 확장 기능 생성 날짜 및 시간

리소스 (Resource)

확장 상세 화면 우측에 위치한 리소스(Resource) 탭은 확장 기능과 연결된 리소스 정보를 관리하는 영역이며 다음과 같다.

리소스 목록

번호 항목 설명
1 이름(Name) 리소스 명 (필수)
2 유형(Type) 리소스 유형
3 생성일 (Created) 리소스 생성 날짜 및 시간
4 작업(Actions) 리소스 수행 작업 (수정 / 활성화 여부 / 삭제)

사용자 지정 작업 (Custom Actions)

확장 상세 화면 우측에 위치한 사용자 지정 작업(Custom Actions)은 기본 작업 외에 사용자가 직접 작업을 정의할 수 있는 기능이며 활성화된 모든 사용자 지정 작업은 실행 중에 정의된 유형의 리소스 또는 제공된 리소스에 대해 실행 작업 보기 또는 runCustomAction API 를 사용하여 트리거 할 수 있다. 관리자는 UI 또는 API 를 통해 새로운 작업을 등록할 수 있고 다음과 같다.

사용자 지정 작업 목록

번호 항목 설명
1 이름(Name) 사용자 지정 작업 명 (필수)
2 상태(State) 사용자 지정 작업 현재 상태, 활성화 (Enabled) / 비활성화 (Disabled)로 구분
3 리소스 유형 (Resource type) 사용자 지정 작업 리소스 유형
4 생성일(Created) 사용자 지정 작업 생성 날짜 및 시간
5 작업(Actions) 사용자 지정 수행 작업 (수정 / 활성화 여부 / 삭제)

사용자 지정 작업 입력 항목

번호 항목 설명
1 이름(Name) 사용자 지정 작업 명 (필수)
2 설명(Description) 사용자 지정 작업의 용도 및 설명
3 허용된 역할 유형 (Allowed Role Types) 사용자 지정 작업 실행 가능 권한, 여러 그룹 지정 가능.
(Admin / Resource Admin / Domain Admin / User)
4 매개변수 (Parameters) 사용자 지정 작업 실행 시 사용할 Key-Value 형태의 입력 매개변수
(Type: Boolean / Date / Number / String)
5 성공 메시지 (Success message) 사용자 지정 작업 성공 시 반환 메시지 설정
6 오류 메시지 (Error message) 사용자 지정 작업 실패 시 반환 메시지 설정
7 구성 세부 정보 (Configuration Details) 사용자 지정 작업 수행 시 사용할 설정 정보
8 시간초과(Timeout) 사용자 지정 작업 수행 제한 시간
9 활성화(Enabled) 사용자 지정 작업 활성화 여부

이벤트 (Events)

이벤트(Events) 탭은 확장 기능에서 수행된 작업 이력 및 상태 정보를 조회하는 영역이며 레벨(Level), 유형(Type), 상태(State), 사용자 이름(Username), 다음과 같다.

이벤트 목록

번호 항목 설명
1 레벨(Level) 이벤트 심각도
(INFO – 정상 작업 / WARN – 경고 / ERROR – 실패/오류)
2 유형(Type) 이벤트 유형
3 상태(State) 이벤트 진행상태
4 사용자 이름 (Username) 작업 실행 사용자
5 계정(Account) 리소스 소유 계정
6 도메인(Domain) 소속 도메인
7 생성일(Created) 이벤트 생성 날짜 및 시간
