게스트 네트워크

게스트 네트워크는 동일한 Zone 내의 가상머신 간 통신 및 외부 네트워크와의 연결을 관리하는 핵심 기능이다.

가상머신용 네트워크의 주요 기능은 가상 라우터(Virtual Router)를 통해 제공된다. 가상 라우터는 호스트에서 실행되는 특수한 가상머신이다.

목록 조회

게스트 네트워크 목록을 확인하는 화면이다. 생성된 네트워크 목록을 확인하거나 네트워크 추가 버튼을 클릭하여 새 네트워크를 생성할 수 있다.

가상머신용 네트워크 추가

게스트용 네트워크 생성 용도에 따라 Isolated, L2, Shared를 선택하여 생성한다. 네트워크 추가 버튼을 클릭하여 새 네트워크 생성 화면을 호출한다.

Isolated 네트워크 생성

Isolated 네트워크는 계정 단위로 격리된 독립 네트워크이다. 특정 계정에 할당된 네트워크는 강한 격리성을 제공하며, 가상 라우터가 DHCP, NAT, 방화벽 등의 네트워크 서비스를 담당한다. Advanced Networking을 사용하는 Zone에서는 최초 설치 이후 언제든지 게스트 트래픽을 위한 추가 네트워크를 생성할 수 있다. 네트워크별로 DNS 접미사를 지정하여 도메인 이름을 커스터마이징할 수도 있다.

Advanced Zone에서 Isolated 네트워크를 생성하려면 아래 절차를 따른다.

  1. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  2. 네트워크 추가 버튼을 클릭한다.

  3. 아래 항목을 입력한다.

항목 설명

네트워크 오퍼링 관리자가 여러 네트워크 오퍼링을 구성한 경우, 사용할 오퍼링을 선택한다.

L2 네트워크 생성

L2 네트워크는 Layer 2(데이터 링크 계층) 기반으로 동작하는 네트워크이다. 여러 가상머신이 동일한 물리 네트워크를 공유하며 연결될 수 있도록 한다.

L2 네트워크를 생성하려면 아래 절차를 따른다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 탭을 클릭한다.

  4. 네트워크 추가 아이콘을 클릭한다.

  5. L2 탭을 선택한다.

  6. 아래 항목을 입력한다.

항목 설명
이름 네트워크 이름을 입력한다.
설명 네트워크에 대한 설명을 입력한다.
Zone Zone을 선택한다.
소유자 유형 계정 또는 프로젝트 중 선택한다.
도메인 도메인을 선택한다.
계정/프로젝트 소유자 유형에 따라 계정/프로젝트를 선택한다.

VLAN/VNI VLAN 또는 VNI 값을 입력한다.
  1. 확인 버튼을 클릭하여 L2 네트워크를 생성한다.

Shared 네트워크 생성

Shared 네트워크는 여러 사용자 및 가상머신이 동일한 VLAN을 공유하는 네트워크 유형이다. 소수의 통합된 네트워크가 필요할 때 적절한다.

Shared 네트워크를 생성하려면 아래 절차를 따른다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 탭을 클릭한다.

  4. 네트워크 추가 아이콘을 클릭한다.

  5. Shared 탭을 선택한다.

  6. 아래 항목을 입력한다.

항목 설명
이름 네트워크 이름을 입력한다. 사용자에게 표시된다.
설명 네트워크에 대한 짧은 설명을 입력한다.
Zone 네트워크가 적용될 Zone을 선택한다.
물리 네트워크 이 네트워크가 속할 물리 네트워크 ID를 선택한다.

범위 도메인(Domain), 계정(Account), 프로젝트(Project), 전체(All) 중 선택한다.
네트워크 오퍼링 사용할 네트워크 오퍼링을 선택한다.

CIDR 게스트 네트워크 서브넷을 정의하는 네트워크 프리픽스이다.
서비스용 네트워크의 라우터에 대한 IPv4 주소 게스트 네트워크를 관리할 가상라우터의 IPv4/IPv6 주소이다.
네트워크 도메인 게스트 가상머신 네트워크에 특별한 도메인 이름을 부여할 경우 DNS 접미사를 입력한다.
  1. 확인 버튼을 클릭하여 Shared 네트워크를 생성한다.

네트워크 업데이트 (Isolated)

Isolated 네트워크의 이름, 설명, 네트워크 오퍼링, CIDR, 네트워크 도메인 등의 정보를 수정할 수 있다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 보기를 선택한다.

  4. 수정할 네트워크를 선택한다.

  5. 네트워크 업데이트 버튼을 클릭한다.

  6. 수정할 항목을 입력한다.

  1. 확인 버튼을 클릭하여 업데이트한다.

네트워크 재시작 (Isolated)

Isolated 네트워크의 가상 라우터를 재시작한다. 재시작 시 해당 네트워크에서 제공하는 모든 서비스가 일시 중단된다. 정리(Clean up) 옵션을 활성화하면 기존 가상 라우터가 삭제되고 새 가상 라우터가 프로비저닝된다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 보기를 선택한다.

  4. 재시작할 네트워크를 선택한다.

  5. 네트워크 재시작 버튼을 클릭한다.

  6. 확인 버튼을 클릭하여 가상 라우터를 재시작한다.

네트워크 삭제 (Isolated)

Isolated 네트워크를 삭제한다.

주의: 네트워크를 삭제하기 전에 연결된 모든 가상머신을 먼저 제거해야 한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 보기를 선택한다.

  4. 삭제할 네트워크를 선택한다.

  5. 상세 탭에서 네트워크 삭제 버튼을 클릭한다. 또는 목록 조희의 삭제 버튼을 사용할 수도 있다.

  6. 확인 버튼을 클릭하여 네트워크를 삭제한다.

상세 탭 (Isolated)

Isolated 네트워크에 대한 상세 정보를 조회하는 화면이다. 해당 네트워크의 이름, 아이디, 유형, 트래픽 유형, CIDR, 넷마스크, 게이트웨이, 영구적 여부, 재시작 필요 여부, Redundant 라우터, 네트워크 도메인, 기본 송신 정책, Zone, 계정, 도메인, DNS1, Public 인터페이스 MTU, Private 인터페이스 MTU 등의 정보를 확인할 수 있다.

송신 규칙 탭 (Isolated)

Isolated 네트워크의 송신 규칙을 조회 및 관리하는 화면이다. Source CIDR, 목적지 CIDR, 프로토콜, 시작 포트, 종료 포트 등의 정보를 확인할 수 있다.

Public IP 주소 탭 (Isolated)

Isolated 네트워크의 Public IP 주소를 조회 및 관리하는 화면이다. IP 주소, 상태, VM, 네트워크 등의 정보를 확인할 수 있다. IP 주소를 클릭하면 해당 Public IP 주소 상세 화면에서 Static NAT으로 가상머신에 IP를 제공할 수 있다.

새 IP 주소 가져오기

Isolated 네트워크에 Public IP 주소를 추가한다.

Public IP 주소 일괄 해제

일괄 해제할 Public IP를 체크하고 IP 주소 해제 버튼을 클릭하여 Public IP 주소를 일괄 해제한다.

가상 라우터 탭 (Isolated)

Isolated 네트워크에 대한 가상 라우터를 조회하는 화면이다. 해당 네트워크의 가상 라우터 이름, 상태, IP, 버전, 실행 중인 호스트 등의 정보를 확인할 수 있다.

네트워크 권한 탭 (Isolated)

Isolated 네트워크의 네트워크 권한을 조회 및 관리하는 화면이다. 해당 네트워크의 도메인, 계정, 프로젝트 등의 정보를 확인할 수 있다.

추가 네트워크는 모든 계정에서 사용 가능하도록 하거나 특정 계정에만 할당할 수 있다. 모든 계정에서 사용 가능한 네트워크는 Zone 전체 네트워크로, Zone에 접근 권한이 있는 모든 사용자가 해당 네트워크에 접근하는 가상머신을 생성할 수 있다. 특정 계정에 할당된 네트워크는 강한 격리성을 제공한다.

네트워크 삭제 버튼을 클릭하여 삭제 화면을 호출하고, 확인 버튼을 클릭하여 삭제한다.

상세 탭 (L2)

L2 네트워크에 대한 상세 정보를 조회하는 화면이다. 해당 네트워크의 이름, 아이디, 유형, 트래픽 유형, 영구적 여부, 재시작 필요 여부, Redundant 라우터, Zone, 계정, 도메인, DNS1 등의 정보를 확인할 수 있다.

네트워크 권한 탭 (L2)

L2 네트워크의 네트워크 권한을 조회 및 관리하는 화면이다.

네트워크 권한 추가

계정 또는 프로젝트를 선택하고 확인 버튼을 클릭하여 권한을 추가한다.

네트워크 권한 삭제

네트워크 권한 삭제 버튼을 클릭하여 권한을 삭제한다.

네트워크 권한 재설정

확인 버튼을 클릭하여 네트워크 권한을 재설정한다.

이벤트 탭 (L2)

L2 네트워크에 관련된 이벤트 정보를 확인하는 화면이다.

코멘트 탭 (L2)

L2 네트워크에 관련된 코멘트 정보를 조회 및 관리하는 화면이다.

네트워크 업데이트 (Shared)

Shared 네트워크의 정보를 업데이트한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 게스트 네트워크 보기를 선택한다.

  4. 수정할 네트워크를 선택한다.

  5. 네트워크 업데이트 버튼을 클릭한다.

  6. 수정할 항목을 입력한다.

  7. 확인 버튼을 클릭하여 업데이트한다.

네트워크 재시작 (Shared)

Shared 네트워크의 가상 라우터를 재시작한다. 재시작 시 해당 네트워크에서 제공하는 모든 서비스가 일시 중단된다. 정리(Clean up) 옵션을 활성화하면 기존 가상 라우터가 삭제되고 새 가상 라우터가 프로비저닝된다.

네트워크 재시작 버튼을 클릭한 후 확인 버튼을 클릭하여 가상 라우터를 재시작한다.

네트워크 삭제 (Shared)

Shared 네트워크를 삭제한다.

주의: 네트워크를 삭제하기 전에 연결된 모든 가상머신을 먼저 제거해야 한다.

네트워크 삭제 버튼을 클릭하여 삭제 화면을 호출하고, 확인 버튼을 클릭하여 삭제한다.

상세 탭 (Shared)

Shared 네트워크에 대한 상세 정보를 조회하는 화면이다. 해당 네트워크의 이름, 아이디, 유형, 트래픽 유형, CIDR, 넷마스크, 게이트웨이, 영구적 여부, 재시작 필요 여부, Redundant 라우터, Zone, 도메인, DNS1, Public 인터페이스 MTU 등의 정보를 확인할 수 있다.

IP Addresses 탭 (Shared)

Shared 네트워크의 IP Addresses를 조회 및 관리하는 화면이다. IP 주소, 상태, VM, 네트워크 등의 정보를 확인할 수 있다.

Public IP 주소 일괄 해제

일괄 해제할 Public IP를 체크하고 Public IP 주소 일괄 해제 버튼을 클릭하여 Public IP 주소를 일괄 해제한다.

가상 라우터 탭 (Shared)

Shared 네트워크에 대한 가상 라우터를 조회하는 화면이다. 해당 네트워크의 가상 라우터 이름, 상태, IP, 버전, 실행 중인 호스트 등의 정보를 확인할 수 있다.

게스트 IP 주소 범위 탭 (Shared)

Shared 네트워크의 게스트 IP 주소 범위를 조회 및 관리하는 화면이다. IPv4 시작/종료 IP, IPv6 시작/종료 IP, 게이트웨이, 넷마스크 등의 정보를 확인할 수 있다.

Advanced Zone에서는 네트워크가 정의될 때 IP 주소 범위 또는 CIDR이 네트워크에 할당된다. 가상 라우터는 DHCP 서버로 동작하며 CIDR을 기반으로 게스트 가상머신에 IP 주소를 할당한다.

항목 설명
게이트웨이 게이트웨이를 입력한다.
넷마스크 넷마스크를 입력한다.
IPv4 시작 IP IP 범위의 시작 IP를 입력한다.
IPv4 종료 IP IP 범위의 종료 IP를 입력한다.

확인 버튼을 클릭하여 게스트 IP 주소 범위를 추가한다.

IP 주소 범위 편집

편집 버튼을 클릭하여 IP 범위 업데이트 화면을 호출하고, 수정할 항목을 입력한 후 확인 버튼을 클릭한다.

IP 주소 범위 삭제

IP 주소 범위 삭제 버튼을 클릭하고, 예 버튼을 클릭하여 IP 범위를 삭제한다.

이벤트 탭 (Shared)

Shared 네트워크에 관련된 이벤트 정보를 확인하는 화면이다.

코멘트 탭 (Shared)

Shared 네트워크에 관련된 코멘트 정보를 조회 및 관리하는 화면이다.

가상머신의 네트워크 재구성

가상머신을 네트워크 간에 이동하거나 가상머신의 네트워크를 재구성할 수 있다. 가상머신을 네트워크에서 제거하고 새 네트워크에 추가하거나, 가상머신의 기본 네트워크를 변경할 수 있다.

NIC에 네트워크 추가

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 가상머신을 선택한다.

  3. 작업할 가상머신을 선택한다.

  4. NIC 탭을 클릭한다.

  5. VM에 네트워크 추가를 클릭한다.

  6. 드롭다운 목록에서 추가할 네트워크를 선택한다.

  7. 새 NIC이 추가되며, NIC 페이지에서 다음 정보를 확인할 수 있다.

    • ID, 네트워크 이름, 유형, IP 주소, 게이트웨이, 넷마스크, 기본 여부, CIDR(IPv6)

NIC에서 네트워크 제거

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 가상머신을 선택한다.

  3. 작업할 가상머신을 선택한다.

  4. NIC 탭을 클릭한다.

  5. 제거할 NIC을 찾는다.

  6. NIC 제거 버튼을 클릭한다.

  7. 예를 클릭하여 확인한다.

기본 네트워크 변경

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 가상머신을 선택한다.

  3. 작업할 가상머신을 선택한다.

  4. NIC 탭을 클릭한다.

  5. 기본 네트워크로 설정할 NIC을 찾는다.

  6. 기본 NIC 설정 버튼을 클릭한다.

  7. 예를 클릭하여 확인한다.

용어사전

용어 설명
VNI VXLAN(Virtual Extensible LAN)에서 사용하는 개념으로, 물리적인 네트워크를 넘어 여러 데이터센터나 네트워크 구간을 가상화하는 기술에 사용된다. VXLAN은 대규모 데이터센터나 클라우드 환경에서 여러 가상 네트워크를 확장하고 관리하는 데 사용된다.
Public IP 외부 접근 허용 목적으로 VM이나 로드 밸런서, 방화벽 등 외부에서 접근해야 하는 리소스에 할당된다. 클라우드 내의 VM이 외부 인터넷과 통신할 수 있게 하기 위해 사용된다.
Source CIDR 가상 네트워크가 수신할 출발지 네트워크의 IP 범위를 정의한다.
목적지 CIDR 가상 네트워크가 송신할 목적지 네트워크의 IP 범위를 정의한다.
CIDR Advanced Zone에서 네트워크 정의 시 네트워크에 할당되는 IP 주소 범위이다. 가상 라우터는 DHCP 서버로 동작하며 CIDR을 기반으로 게스트 가상머신에 IP 주소를 할당한다.
Source NAT 가상 라우터에 자동으로 구성되어 모든 게스트 가상머신의 아웃바운드 트래픽을 전달한다.
기본 네트워크 (Default Network) 각 가상머신에 하나씩 존재하는 기본 네트워크이다. 가상 라우터의 DHCP 응답이 기본 네트워크의 게이트웨이를 게스트의 기본 게이트웨이로 설정한다.
