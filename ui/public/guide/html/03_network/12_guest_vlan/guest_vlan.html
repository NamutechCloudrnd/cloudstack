게스트 VLAN

게스트 VLAN은 가상머신들이 통신하는 가상 네트워크에 사용되는 VLAN 목록 정보를 제공한다. 이 메뉴에서 게스트 VLAN이 사용된 물리 네트워크 및 가상머신용 네트워크 정보를 한눈에 확인할 수 있다.

namuVirt는 Advanced Zone에서 게스트 트래픽의 격리를 위해 VLAN을 활용한다. 관리자가 사전에 지정한 VLAN 풀에서 각 계정 및 게스트 네트워크에 VLAN이 자동으로 할당된다.

게스트 VLAN의 주요 특성은 다음과 같다.

  • 자동 할당: 게스트 네트워크가 생성될 때 namuVirt가 VLAN 풀에서 자동으로 VLAN ID를 선택하여 할당한다.

  • 계정 격리: 하나의 계정에 할당된 VLAN은 다른 계정과 공유되지 않으며, 해당 계정의 가상머신만 해당 VLAN을 사용한다.

  • 전용 VLAN (Dedicated VLAN): 관리자는 특정 계정에 VLAN 범위를 전용으로 예약할 수 있다. 전용으로 지정된 VLAN은 해당 계정에서만 사용된다.

범위(Scope) 설정: 게스트 VLAN은 특정 계정, 프로젝트, 도메인, 또는 전체 계정을 대상으로 범위를 지정할 수 있다.

  • 할당 해제: 게스트 네트워크에서 마지막 가상머신이 삭제되면 VLAN ID가 해제되어 VLAN 풀로 반환된다.

참고: 계정에 전용으로 할당된 VLAN을 모두 소진한 경우, 해당 계정은 시스템 VLAN 풀에서 추가 VLAN을 할당받을 수 있다. 관리자는 글로벌 설정 파라미터 use.system.guest.vlans를 통해 이 동작을 제어할 수 있다. 게스트 VLAN 관리는 루트 관리자(ROOT admin)만 수행할 수 있다.

목록 조회

게스트 VLAN 목록을 확인하는 화면이다. 사용 가능하거나 사용 중인 게스트 VLAN 목록을 확인할 수 있다.

목록에서 확인할 수 있는 정보는 다음과 같다.

항목 설명
VLAN/VNI 해당 게스트 네트워크에 할당된 VLAN ID 또는 VXLAN VNI 값이다.
상태 VLAN의 현재 사용 상태이다. 사용 가능(Free) 또는 사용 중(Allocated) 상태를 나타낸다.
물리 네트워크 해당 VLAN이 속한 물리 네트워크 이름이다.
Zone 해당 VLAN이 속한 Zone 정보이다.

상세 탭

게스트 VLAN에 대한 상세 정보를 조회하는 화면이다. 해당 게스트 VLAN의 아래 정보를 확인할 수 있다.

항목 설명
VLAN/VNI 할당된 VLAN ID 또는 VNI 값이다.
할당 VLAN의 할당 대상 정보이다. 전용 VLAN인 경우 배정된 계정이 표시된다.
상태 VLAN의 사용 상태이다. (Free / Allocated)
물리 네트워크 이름 해당 VLAN이 연결된 물리 네트워크의 이름이다.
Taken VLAN이 실제로 사용 중인지 여부를 나타낸다.
계정 해당 VLAN을 사용 중인 계정 정보이다.
도메인 해당 계정이 속한 도메인 정보이다.
전용 특정 계정에 전용으로 예약된 VLAN인지 여부를 나타낸다. 전용 VLAN은 지정된 계정만 사용할 수 있다.
Zone 해당 VLAN이 속한 Zone 정보이다.

가상머신용 네트워크 탭

해당 게스트 VLAN에 연결된 가상머신용 네트워크 정보를 확인하는 화면이다.

게스트 VLAN은 하나 이상의 가상머신용 네트워크(게스트 네트워크)와 연결될 수 있다. 이 탭에서는 해당 VLAN을 사용하는 게스트 네트워크의 목록과 각 네트워크의 상세 정보를 확인할 수 있다.

항목 설명
이름 게스트 네트워크의 이름이다.
유형 네트워크 유형이다. (Isolated, L2, Shared 등)
상태 게스트 네트워크의 현재 상태이다.
브로드캐스트 네트워크의 브로드캐스트 도메인 정보이다. VLAN ID 또는 VNI 값이 표시된다.
도메인 해당 네트워크가 속한 도메인이다.
계정 해당 네트워크를 소유한 계정이다.
프로젝트 해당 네트워크가 속한 프로젝트이다. (프로젝트에 속한 경우 표시)
VPC 해당 네트워크가 VPC에 속한 경우 연결된 VPC 이름이 표시된다.

용어사전

용어 설명
VLAN (Virtual LAN) 물리적 네트워크 장치의 구성과 무관하게 논리적으로 분리된 네트워크 세그먼트이다. namuVirt는 Advanced Zone에서 게스트 트래픽의 계정 간 격리를 위해 VLAN을 사용한다.
VNI (VXLAN Network Identifier) VXLAN(Virtual Extensible LAN)에서 사용하는 개념으로, 물리적 네트워크를 넘어 여러 데이터센터나 네트워크 구간을 가상화할 때 사용된다.
게스트 VLAN (Guest VLAN) 가상머신 간 통신에 사용되는 VLAN이다. namuVirt는 사전에 구성된 VLAN 풀에서 게스트 네트워크 생성 시 자동으로 VLAN ID를 선택하여 할당한다.
전용 VLAN (Dedicated VLAN) 관리자가 특정 계정 전용으로 예약한 VLAN 범위이다. 전용 VLAN은 지정된 계정에서만 사용할 수 있으며 다른 계정과 공유되지 않는다.
VLAN 풀 (VLAN Pool) namuVirt가 게스트 네트워크에 자동 할당하기 위해 사전에 관리자가 구성한 VLAN ID 범위이다.
Taken VLAN이 현재 실제로 사용 중인 상태를 나타낸다. Allocated 상태이더라도 아직 VM이 배포되지 않아 실제로 사용되지 않을 수 있다.
