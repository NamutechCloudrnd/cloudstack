Public IP 주소

Public IP 주소는 namuVirt 인프라에서 외부와의 통신을 가능하게 하는 고유한 IP 주소이다. 이를 통해 외부에서 namuVirt 인프라 내 가상머신이나 서비스에 접근할 수 있다. 웹 서버나 애플리케이션 서버 등 외부 연결이 필요한 자원에 할당되어, 외부 사용자가 해당 자원에 접속할 수 있도록 한다.

Public IP 주소는 다음과 같은 용도로 사용된다.

  • Static NAT: Public IP와 가상머신의 Private IP를 1:1로 매핑하여 인터넷 트래픽을 허용한다.

  • 포트 포워딩(Port Forwarding): Public IP의 특정 포트로 수신된 트래픽을 가상머신의 내부 포트로 전달한다.

  • 로드 밸런싱(Load Balancing): Public IP로 수신된 트래픽을 여러 가상머신에 분산한다.

  • 방화벽 규칙(Firewall Rules): Public IP에 대한 인바운드/아웃바운드 트래픽을 제어한다.

기본적으로 Public IP 주소로 들어오는 모든 트래픽은 차단된다. 외부 트래픽을 허용하려면 방화벽 규칙 또는 포트 포워딩 규칙을 설정해야 한다.

목록 조회

Public IP 주소의 목록을 확인하는 화면이다. Zone별 Public IP 주소의 할당 상태, 연결된 네트워크, 사용 중인 가상머신 등의 정보를 확인할 수 있다.

목록에서 IP 주소를 클릭하면 해당 Public IP 주소의 상세 화면으로 이동한다.

Static NAT

Static NAT 규칙은 Public IP 주소를 가상머신의 Private IP 주소에 1:1로 매핑하여 인터넷 트래픽이 해당 가상머신에 도달할 수 있도록 한다. Public IP 주소는 항상 동일하게 유지되기 때문에 "Static" NAT라고 한다.

참고:

  • 이미 포트 포워딩 규칙이 적용된 IP 주소에는 Static NAT를 활성화할 수 없다.

  • 가상머신이 두 개 이상의 네트워크에 속한 경우, Static NAT 규칙은 기본 네트워크(Default Network)에서만 동작한다.

  • Static NAT 규칙은 언제든지 비활성화할 수 있다. 비활성화하면 풀에서 새 Public IP가 할당되며, 이전에 할당된 IP와 동일하지 않을 수 있다.

Static NAT 활성화/비활성화

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 작업할 게스트 네트워크의 이름을 클릭한다.

  4. Public IP 주소 탭에서 작업할 IP 주소를 클릭한다.

  5. Static NAT 버튼을 클릭한다. 버튼이 활성화/비활성화 사이를 토글한다.

  6. Static NAT를 활성화하는 경우 연결할 가상머신을 선택하고 적용을 클릭한다.

상세 탭

해당 Public IP 주소의 IP, 상태, 연결된 네트워크, Zone, 계정, 도메인 등의 정보를 확인할 수 있다.

방화벽 탭

Public IP 주소에 대한 인바운드 방화벽 규칙을 조회 및 관리한다.

기본적으로 Public IP 주소로 들어오는 모든 트래픽은 방화벽에 의해 차단된다. 외부 트래픽을 허용하려면 방화벽 규칙을 추가하여 포트를 개방해야 한다.

방화벽 규칙 추가

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 작업할 네트워크의 이름을 클릭한다.

  4. Public IP 주소 탭을 클릭한다.

  5. 작업할 IP 주소를 클릭한다.

  6. 방화벽 탭을 클릭하고 아래 항목을 입력한다.

항목 설명
Source CIDR (선택) 특정 IP 주소 범위에서만 트래픽을 허용하려면 CIDR 또는 쉼표로 구분된 CIDR 목록을 입력한다. 예: 192.168.0.0/22. 비워두면 모든 CIDR에서 허용된다.
프로토콜 개방할 포트에서 사용하는 통신 프로토콜을 선택한다. (TCP, UDP, ICMP 등)
시작 포트 / 종료 포트 방화벽에서 개방할 포트 범위를 입력한다. 단일 포트를 개방할 경우 시작 포트와 종료 포트에 동일한 번호를 입력한다.
ICMP 유형 / ICMP 코드 프로토콜이 ICMP인 경우에만 입력한다. ICMP 헤더를 채우기 위해 필요한 유형과 코드를 입력한다.
  1. 추가 버튼을 클릭한다.

참고: Elastic IP(탄력적 IP)에는 방화벽 규칙을 사용하여 포트를 개방할 수 없다. Elastic IP 사용 시 외부 접근은 보안 그룹(Security Group)을 통해 제어한다.

방화벽 규칙 삭제

방화벽 탭에서 삭제할 규칙의 삭제 버튼을 클릭한다.

포트 포워딩 탭

Public IP의 특정 포트로 수신된 트래픽을 가상머신의 내부 포트로 전달하는 포트 포워딩 규칙을 조회 및 관리한다.

포트 포워딩 서비스는 포트 포워딩 규칙의 집합으로 정책을 정의한다. 가상머신은 여러 포트 포워딩 서비스에 속할 수 있다. 가상머신이 두 개 이상의 네트워크에 속한 경우, 포트 포워딩 규칙은 기본 네트워크에서만 동작한다.

포트 포워딩 규칙 추가

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. 작업할 게스트 네트워크의 이름을 클릭한다.

  4. 기존 IP 주소를 선택하거나 새 IP 주소를 가져온다.

  5. 해당 IP 주소를 클릭한다.

  6. 포트 포워딩 탭을 클릭하고 아래 항목을 입력한다.

항목 설명
Public 포트 앞서 가져온 IP 주소에서 수신할 Public 포트를 입력한다.
Private 포트 포워딩된 Public 트래픽을 수신할 가상머신의 포트를 입력한다.
프로토콜 두 포트 사이에서 사용되는 통신 프로토콜을 선택한다.
  1. 추가 버튼을 클릭한다.

참고: Elastic IP에는 포트 포워딩을 사용하여 포트를 개방할 수 없다. Elastic IP 사용 시 외부 접근은 보안 그룹을 통해 제어한다.

포트 포워딩 규칙 삭제

포트 포워딩 탭에서 삭제할 규칙의 삭제 버튼을 클릭한다.

부하 분산 탭

Public IP 주소로 수신되는 트래픽을 여러 가상머신에 분산하는 로드 밸런싱 규칙을 조회 및 관리한다.

  1. Public IP 주소 탭에서 작업할 IP 주소를 클릭한다.

  2. 부하 분산 탭을 클릭한다.

  3. 아래 항목을 입력한다.

항목 설명
이름 로드 밸런서 규칙의 이름을 입력한다.
Public 포트 인바운드 트래픽을 수신할 포트를 입력한다.
Private 포트 가상머신에서 트래픽을 수신할 포트를 입력한다.
소스 CIDR 목록 로드 밸런싱 대상이 될 CIDR이다.
알고리즘 로드 밸런싱 알고리즘을 선택한다. namuVirt는 다양한 알고리즘을 지원한다.
  1. 추가 버튼을 클릭한다.

가상 사설망(VPN)

해당 공용 IP에 대한 가상 사설망을 관리한다.

VPN 활성화

VPN 활성화 버튼을 클릭하고 VPN을 활성화한다.

VPN 비활성화

VPN 비활성화 버튼을 클릭하고 VPN을 비활성화한다.

이벤트 탭

해당 Public IP 주소에 관련된 이벤트 정보를 확인하는 화면이다. IP에서 발생한 다양한 액션과 변경 사항을 확인할 수 있다.

코멘트 탭

Public Ip 주소에 관련된 코멘트 정보를 확인하는 화면이다. 각 사용자별로 해당 VPC에 대한 코멘트 정보를 조회 및 관리할 수 있다.

용어사전

용어 설명
Public IP 외부 접근 허용 목적으로 VM이나 로드 밸런서, 방화벽 등 외부에서 접근해야 하는 리소스에 할당된다. 클라우드 내의 VM이 외부 인터넷과 통신할 수 있게 하기 위해 사용된다.
Static NAT Public IP 주소를 가상머신의 Private IP 주소에 1:1로 매핑한다. Public IP 주소는 항상 동일하게 유지된다. 포트 포워딩 규칙이 이미 설정된 IP에는 활성화할 수 없다.
Elastic IP (EIP) 계정에 연결된 IP 주소로, 정적 IP 주소처럼 동작한다. 계정 소유자는 EIP를 원하는 인스턴스에 할당하거나 다른 인스턴스로 재할당할 수 있다. Elastic IP는 StaticNAT를 통해 연결된 Private IP 주소에 매핑된다.
포트 포워딩 (Port Forwarding) Public IP의 특정 포트로 수신된 트래픽을 가상머신의 내부 포트로 전달하는 규칙이다.
방화벽 규칙 (Firewall Rule) Public IP 주소에 대한 인바운드 트래픽을 허용하거나 차단하는 보안 규칙이다. 기본적으로 모든 인바운드 트래픽은 차단된다.
Source CIDR 방화벽 규칙에서 트래픽을 허용할 출발지 네트워크의 IP 범위를 정의한다.
