보안 그룹

보안그룹은 가상머신으로 유입되는 트래픽을 격리할 수 있는 방법을 제공합니다. 보안그룹은 수신 및 송신 규칙(Ingress 및 Egress 규칙)에 따라 트래픽을 필터링하는 가상머신의 논리적 그룹입니다. 이 규칙들은 가상머신과 통신하려는 IP 주소에 따라 네트워크 트래픽을 필터링합니다.

보안그룹의 주요 특성은 다음과 같습니다.

  • 기본 보안그룹: 모든 계정에는 모든 인바운드 트래픽을 차단하고 모든 아웃바운드 트래픽을 허용하는 기본 보안그룹이 제공됩니다. 기본 보안그룹은 수정할 수 있으며, 이후 생성되는 모든 가상머신은 별도로 지정하지 않으면 이 기본 보안그룹에 자동으로 할당됩니다.

  • 다중 보안그룹 적용: 가상머신은 여러 보안그룹에 동시에 속할 수 있습니다.

  • 규칙 즉시 적용: 보안그룹의 수신/송신 규칙을 추가하거나 삭제하면 해당 그룹에 속한 모든 가상머신(실행 중 또는 중지 상태)에 즉시 적용됩니다.

  • 보안그룹 변경 제한: 가상머신이 속한 보안그룹은 가상머신이 중지된 상태에서만 변경할 수 있습니다.

  • 수신 규칙 미설정 시 동작: 수신 규칙이 지정되지 않은 경우, 송신 규칙을 통해 허용된 트래픽에 대한 응답 트래픽을 제외하고 모든 인바운드 트래픽이 차단됩니다.

  • 송신 규칙 미설정 시 동작: 송신 규칙이 지정되지 않은 경우, 모든 아웃바운드 트래픽이 허용됩니다. 송신 규칙이 하나라도 지정되면 송신 규칙에서 허용된 트래픽, DNS/DHCP 서버 쿼리, 수신 규칙을 통해 허용된 트래픽에 대한 응답만 허용됩니다.

참고: Advanced Zone의 경우, 보안그룹 기능은 Zone 생성 당시 설정에서 활성화된 경우에만 사용할 수 있습니다. 생성된 이후에는 해당 설정을 변경할 수 없으니 유의하시기 바랍니다.

목록 조회

보안그룹 목록을 확인하는 화면입니다. 생성된 보안그룹 목록을 확인하거나 보안그룹 추가 버튼을 클릭하여 새 보안그룹을 생성할 수 있습니다.

보안그룹 추가

새 보안그룹을 생성합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 보안그룹을 선택합니다.

  3. 보안그룹 추가 버튼을 클릭합니다.

  4. 아래 항목을 입력합니다.

항목 설명
이름 보안그룹의 이름을 입력합니다.
설명 보안그룹에 대한 설명을 입력합니다.
  1. 확인 버튼을 클릭하여 보안그룹을 생성합니다.

참고: 새로 생성된 보안그룹은 수신/송신 규칙이 없는 빈 상태입니다. 보안그룹이 유효하게 동작하려면 수신 규칙 탭 또는 송신 규칙 탭에서 규칙을 추가해야 합니다.

편집

보안그룹의 이름 및 설명 정보를 수정합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 보안그룹을 선택합니다.

  3. 수정할 보안그룹을 선택합니다.

  4. 편집 버튼을 클릭합니다.

  5. 수정할 항목을 입력합니다.

  1. 확인 버튼을 클릭하여 보안그룹 정보를 업데이트합니다.

보안그룹 삭제

보안그룹을 삭제합니다.

주의: 가상머신이 속한 보안그룹은 삭제할 수 없습니다. 삭제하기 전에 해당 보안그룹에서 모든 가상머신을 제거해야 합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 보안그룹을 선택합니다.

  3. 삭제할 보안그룹을 선택합니다.

  4. 보안그룹 삭제 버튼을 클릭합니다.

  5. 확인 버튼을 클릭하여 삭제합니다.

  1. 상세 탭

보안그룹에 대한 상세 정보를 조회하는 화면입니다. 해당 보안그룹의 아래 정보를 확인할 수 있습니다.

항목 설명
이름 보안그룹의 이름입니다.
ID 보안그룹의 고유 식별자입니다.
설명 보안그룹에 대한 설명입니다.
계정 해당 보안그룹을 소유한 계정입니다.
도메인 해당 계정이 속한 도메인입니다.

수신 규칙 탭

보안그룹에 대한 수신(Ingress) 규칙을 조회 및 관리하는 화면입니다. 해당 보안그룹의 프로토콜, 시작 포트, 종료 포트, ICMP 유형, ICMP 코드, CIDR 등의 정보를 확인할 수 있습니다.

수신 규칙은 보안그룹에 속한 가상머신으로 들어오는 트래픽을 제어합니다. 수신 규칙이 지정되지 않은 경우, 모든 인바운드 트래픽이 차단됩니다. (허용된 송신에 대한 응답까지는 차단하지 않습니다.)

수신 규칙 추가

보안그룹에 수신 규칙을 추가합니다.

항목 설명
추가 방식 CIDR 또는 계정(Account) 중 트래픽 출발지를 정의하는 방식을 선택합니다. CIDR은 IP 주소 범위로 출발지를 지정하며, 계정은 다른 보안그룹으로 출발지를 지정합니다.
프로토콜 수신 규칙이 적용되는 네트워크 프로토콜을 선택합니다. TCP, UDP, ICMP 또는 모두(All) 중에서 선택합니다. TCP와 UDP는 일반적으로 데이터 교환 및 사용자 통신에 사용되고, ICMP는 오류 메시지 또는 네트워크 모니터링 데이터 전송에 사용됩니다.
시작 포트 (TCP, UDP 전용) 허용할 포트 범위의 시작 포트를 입력합니다. 단일 포트를 허용할 경우 종료 포트와 동일한 값을 입력합니다.
종료 포트 (TCP, UDP 전용) 허용할 포트 범위의 종료 포트를 입력합니다.
ICMP 유형 (ICMP 전용) 허용할 ICMP 메시지 유형을 입력합니다.
ICMP 코드 (ICMP 전용) 허용할 ICMP 메시지 코드를 입력합니다.
CIDR (CIDR 방식 전용) 트래픽을 허용할 출발지 IP 주소 범위를 CIDR 형식으로 입력합니다. 쉼표로 구분하여 여러 CIDR을 입력할 수 있습니다. 모든 주소에서 허용하려면 0.0.0.0/0(IPv4) 또는 ::/0(IPv6)으로 설정합니다.
계정, 보안그룹 (계정 방식 전용) 특정 보안그룹의 가상머신에서 오는 트래픽만 허용하려면 해당 보안그룹이 속한 계정과 보안그룹 이름을 입력합니다. 현재 편집 중인 보안그룹 내 가상머신 간 트래픽을 허용하려면 현재 보안그룹 이름을 입력합니다.

추가 버튼을 클릭하여 수신 규칙을 추가합니다.

수신 규칙 삭제

수신 규칙 탭에서 삭제할 규칙의 삭제 버튼을 클릭하고, 예 버튼을 클릭하여 수신 규칙을 삭제합니다.

송신 규칙 탭

보안그룹에 대한 송신(Egress) 규칙을 조회 및 관리하는 화면입니다. 해당 보안그룹의 프로토콜, 시작 포트, 종료 포트, ICMP 유형, ICMP 코드, CIDR 등의 정보를 확인할 수 있습니다.

송신 규칙은 보안그룹에 속한 가상머신에서 나가는 트래픽을 제어합니다. 송신 규칙이 지정되지 않은 경우, 모든 아웃바운드 트래픽이 허용됩니다. 송신 규칙이 하나라도 지정되면 규칙에서 허용된 트래픽, DNS/DHCP 서버 쿼리, 수신 규칙을 통해 허용된 트래픽에 대한 응답만 허용됩니다.

송신 규칙 추가

보안그룹에 송신 규칙을 추가합니다.

항목 설명
추가 방식 CIDR 또는 계정(Account) 중 트래픽 목적지를 정의하는 방식을 선택합니다. CIDR은 IP 주소 범위로 목적지를 지정하며, 계정은 다른 보안그룹으로 목적지를 지정합니다.
프로토콜 송신 규칙이 적용되는 네트워크 프로토콜을 선택합니다. TCP, UDP, ICMP 또는 모두(All) 중에서 선택합니다.
시작 포트 (TCP, UDP 전용) 허용할 포트 범위의 시작 포트를 입력합니다. 단일 포트를 허용할 경우 종료 포트와 동일한 값을 입력합니다.
종료 포트 (TCP, UDP 전용) 허용할 포트 범위의 종료 포트를 입력합니다.
ICMP 유형 (ICMP 전용) 허용할 ICMP 메시지 유형을 입력합니다.
ICMP 코드 (ICMP 전용) 허용할 ICMP 메시지 코드를 입력합니다.
CIDR (CIDR 방식 전용) 트래픽을 허용할 목적지 IP 주소 범위를 CIDR 형식으로 입력합니다. 쉼표로 구분하여 여러 CIDR을 입력할 수 있습니다. 모든 주소로 허용하려면 0.0.0.0/0(IPv4) 또는 ::/0(IPv6)으로 설정합니다.
계정, 보안그룹 (계정 방식 전용) 특정 보안그룹의 가상머신으로 나가는 트래픽을 허용하려면 해당 보안그룹이 속한 계정과 보안그룹 이름을 입력합니다.

추가 버튼을 클릭하여 송신 규칙을 추가합니다.

송신 규칙 삭제

송신 규칙 탭에서 삭제할 규칙의 삭제 버튼을 클릭하고, 예 버튼을 클릭하여 송신 규칙을 삭제합니다.

용어사전

용어 설명
보안그룹 (Security Group) 수신 및 송신 규칙에 따라 네트워크 트래픽을 필터링하는 가상머신의 논리적 그룹입니다. 가상머신은 여러 보안그룹에 동시에 속할 수 있습니다.
기본 보안그룹 (Default Security Group) 모든 계정에 기본으로 제공되는 보안그룹입니다. 모든 인바운드 트래픽을 차단하고 모든 아웃바운드 트래픽을 허용하며, 별도로 지정하지 않으면 새 가상머신은 이 보안그룹에 자동으로 할당됩니다.
수신 규칙 (Ingress Rule) 보안그룹에 속한 가상머신으로 들어오는 인바운드 트래픽을 허용하는 규칙입니다. 수신 규칙이 없으면 응답 트래픽을 제외한 모든 인바운드 트래픽이 차단됩니다.
송신 규칙 (Egress Rule) 보안그룹에 속한 가상머신에서 나가는 아웃바운드 트래픽을 허용하는 규칙입니다. 송신 규칙이 없으면 모든 아웃바운드 트래픽이 허용됩니다.
CIDR IP 주소와 서브넷 마스크를 함께 표기하는 방식입니다. 수신/송신 규칙에서 트래픽을 허용할 출발지 또는 목적지 IP 주소 범위를 정의하는 데 사용됩니다.
추가 방식 (Add by CIDR/Account) 수신/송신 규칙에서 트래픽 출발지 또는 목적지를 IP 주소 범위(CIDR) 또는 다른 보안그룹(계정)으로 지정하는 방식입니다.
