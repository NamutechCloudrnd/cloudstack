VPN 고객 게이트웨이

VPN 고객 게이트웨이는 Site-to-Site VPN 연결의 원격(고객) 측 엔드포인트 정보를 namuVirt에 등록한 것이다. 원격 게이트웨이의 IP 주소, 원격 서브넷 CIDR, IPsec 사전 공유 키, IKE/ESP 암호화 설정 등을 포함한다.

참고: VPN 고객 게이트웨이 하나는 한 번에 하나의 VPN 게이트웨이에만 연결할 수 있다.

목록 조회

등록된 VPN 고객 게이트웨이 목록을 확인하는 화면이다. 고객 게이트웨이의 이름, 게이트웨이 IP, CIDR, IKE 정책, ESP 정책 등의 정보를 확인할 수 있다.

VPN 고객 게이트웨이 추가

원격 데이터센터의 VPN 엔드포인트 정보를 등록한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. VPN 고객 게이트웨이 탭을 선택한다.

  4. VPN 고객 게이트웨이 추가 버튼을 클릭한다.

  5. 아래 항목을 입력한다.

항목 설명
이름 VPN 고객 게이트웨이의 고유 이름을 입력한다.
게이트웨이 원격 게이트웨이의 IP 주소를 입력한다.
CIDR 목록 원격 서브넷의 게스트 CIDR 목록을 입력한다. CIDR 또는 쉼표로 구분된 CIDR 목록을 입력한다. VPC의 CIDR 또는 다른 게스트 CIDR과 겹치지 않아야 하며, RFC1918 규격을 준수해야 한다.
IPsec 사전 공유 키 VPN 엔드포인트 간에 공유하는 비밀 키이다. 이 키는 고객 게이트웨이와 VPC VPN 게이트웨이 간의 상호 인증에 사용된다. 줄바꿈 문자 또는 큰따옴표를 포함할 수 없다.
IKE 암호화 IKE Phase-1에서 사용할 암호화 알고리즘을 선택한다. AES128, AES192, AES256, 3DES를 지원한다.
IKE 해시 IKE Phase-1에서 사용할 해시 알고리즘을 선택한다. SHA1, SHA256, SHA384, SHA512, MD5를 지원한다.
IKE 버전 사용할 IKE 버전을 선택한다. ike(자동 선택), ikev1, ikev2 중에서 선택한다. ike로 설정 시 연결 시작 시 ikev2를 사용하며, 응답 시에는 모든 버전을 수락한다. 기본값은 ike이다.
IKE DH Diffie-Hellman 그룹을 선택한다. IKE 내에서 세션 키를 교환하는 데 사용된다. Group-2(1024비트), Group-5(1536비트), Group-14(2048비트), Group-15(3072비트), Group-16(4096비트), Group-17(6144비트), Group-18(8192비트)을 지원한다.
ESP 암호화 IKE Phase-2의 ESP(Encapsulating Security Payload) 암호화 알고리즘을 선택한다. AES128, AES192, AES256, 3DES를 지원한다.
ESP 해시 IKE Phase-2의 ESP 해시 알고리즘을 선택한다. SHA1, SHA256, SHA384, SHA512, MD5를 지원한다.
Perfect Forward Secrecy PFS(완전 순방향 비밀성)를 위한 DH 그룹을 선택한다. PFS는 새로운 Phase-2 SA 협상마다 새로운 Phase-1 키 세트를 생성하도록 강제하여 보안을 강화한다. None, Group-2 ~ Group-18을 지원한다.
IKE 수명(초) Phase-1 보안 연결의 수명(초)이다. 기본값은 86400초(1일)이며, 시간이 만료되면 새로운 Phase-1 교환이 수행된다.
ESP 수명(초) Phase-2 보안 연결의 수명(초)이다. 기본값은 3600초(1시간)이며, 값이 초과되면 새로운 IPsec 암호화 및 인증 세션 키 제공을 위해 재키잉(re-key)이 시작된다.
Dead Peer Detection IKE 피어의 가용성을 주기적으로 확인하는 방법이다. 이 옵션을 활성화하면 가상 라우터가 IKE 피어의 활성 상태를 주기적으로 확인한다. VPN 연결 양쪽에 동일하게 설정하는 것을 권장한다.
ESP 패킷의 UDP 캡슐화 강제 NAT 통과를 위한 강제 캡슐화를 설정한다.
  1. 확인 버튼을 클릭한다.

VPN 고객 게이트웨이 편집

VPN 고객 게이트웨이의 설정을 수정한다.

참고: VPN 연결이 없는 상태이거나 연결 오류 상태인 경우에만 고객 게이트웨이를 업데이트할 수 있다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. VPN 고객 게이트웨이 탭을 선택한다.

  4. 수정할 VPN 고객 게이트웨이를 선택한다.

  5. VPN 고객 게이트웨이 편집 버튼을 클릭한다.

  6. 수정할 항목을 입력한다.

  1. 확인 버튼을 클릭한다.

VPN 고객 게이트웨이 삭제

VPN 고객 게이트웨이를 삭제한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크를 선택한다.

  3. VPN 고객 게이트웨이 탭을 선택한다.

  4. 삭제할 VPN 고객 게이트웨이를 선택한다.

  5. VPN 고객 게이트웨이 삭제 버튼을 클릭한다.

  6. 확인 버튼을 클릭한다.
