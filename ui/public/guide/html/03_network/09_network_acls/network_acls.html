Network ACLs

Network ACL(네트워크 액세스 제어 목록)은 VPC의 Network Tier에서 인바운드(Ingress) 및 아웃바운드(Egress) 트래픽을 허용하거나 차단하는 보안 규칙의 집합입니다. Network ACL은 여러 개의 ACL 규칙으로 구성되며, 규칙은 번호 순서대로 평가됩니다.

Network ACL의 주요 특성은 다음과 같습니다.

  • 규칙 평가 순서: ACL 규칙은 번호가 낮은 것부터 순서대로 평가되며, 트래픽이 최초로 일치하는 규칙의 액션(허용/차단)이 적용됩니다.

  • VPC 단위 관리: 각 Network ACL은 특정 VPC에 소속되며, 해당 VPC 내의 여러 Network Tier에 할당할 수 있습니다.

  • Tier 단위 적용: 각 Network Tier에는 반드시 하나의 ACL이 연결되어야 하며, 동시에 둘 이상의 ACL을 연결할 수 없습니다.

  • 기본 ACL: namuVirt는 두 개의 기본 ACL을 제공합니다. default_allow는 모든 인바운드·아웃바운드 트래픽을 허용하며, default_deny는 모든 트래픽을 차단합니다. 커스텀 ACL이 없는 경우 기본 ACL이 사용됩니다.

목록 조회

Network ACL 목록을 확인하는 화면입니다. VPC에 생성된 Network ACL 목록을 확인하거나 Network ACL 추가 버튼을 클릭하여 새 ACL을 생성할 수 있습니다.

목록에서 ACL의 이름, 설명, 소속 VPC 등의 정보를 확인할 수 있습니다.

Network ACL 추가

VPC에 커스텀 Network ACL을 생성합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 네트워크 ACL 목록을 선택합니다.

  3. ACL 목록 추가 버튼을 클릭합니다.

  4. 아래 항목을 입력합니다.

항목 설명
ACL 이름 Network ACL의 이름을 입력합니다.
설명 Network ACL에 대한 설명을 입력합니다. 사용자에게 표시됩니다.
VPC ACL을 적용할 VPC
  1. 확인 버튼을 클릭하여 Network ACL을 생성합니다.

참고: 생성된 Network ACL은 ACL 규칙이 없는 빈 상태입니다. 이후 ACL 규칙 탭에서 규칙을 추가해야 합니다.

Network ACL 삭제

Network ACL을 삭제합니다.

주의: Network ACL을 삭제하기 전에 해당 ACL이 적용된 모든 Network Tier에서 먼저 ACL을 해제해야 합니다. default_allow 및 default_deny 기본 ACL은 삭제할 수 없습니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 네트워크 ACL 목록을 선택합니다.

  3. 삭제할 Network ACL을 선택합니다.

  4. Network ACL 삭제 버튼을 클릭합니다.

  5. 확인 버튼을 클릭하여 삭제합니다.

상세 탭

Network ACL의 기본 정보를 조회하는 화면입니다. 해당 ACL의 이름, 아이디, 설명, 소속 VPC 등의 정보를 확인할 수 있습니다.

ACL 규칙 탭

Network ACL에 구성된 ACL 규칙 목록을 조회하고 관리하는 화면입니다. 규칙 번호, CIDR, 프로토콜, 트래픽 유형, 액션 등의 정보를 확인할 수 있습니다.

ACL 규칙 추가

Network ACL에 트래픽 허용 또는 차단 규칙을 추가합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > 네트워크 ACL 목록을 선택합니다.

  3. 규칙을 추가할 ACL을 선택합니다.

  4. ACL 규칙 탭을 클릭합니다.

  5. 규칙 추가 버튼을 클릭합니다.

  6. 아래 항목을 입력합니다.

항목 설명
규칙 번호 규칙이 평가되는 순서를 나타내는 번호입니다. 번호가 낮을수록 먼저 평가됩니다.
CIDR Ingress 규칙의 경우 출발지 CIDR, Egress 규칙의 경우 목적지 CIDR로 사용됩니다. 특정 IP 범위에서 오는 트래픽만 허용하거나 차단하려면 CIDR 또는 쉼표로 구분된 CIDR 목록을 입력합니다. 모든 CIDR을 허용하려면 0.0.0.0/0으로 설정합니다.
액션 해당 규칙 조건에 일치하는 트래픽에 적용할 동작을 선택합니다. Allow(허용) 또는 Deny(차단) 중에서 선택합니다.
프로토콜 규칙이 적용되는 네트워크 프로토콜을 선택합니다. TCP, UDP, ICMP, 모두(All), 프로토콜 수 중에서 선택할 수 있습니다.
트래픽 유형 규칙이 적용되는 트래픽 방향을 선택합니다. Ingress(인바운드) 또는 Egress(아웃바운드)를 선택합니다.
시작 포트 (TCP, UDP 전용) 포트 범위의 시작 포트를 입력합니다.
종료 포트 (TCP, UDP 전용) 포트 범위의 종료 포트를 입력합니다. 단일 포트의 경우 시작 포트와 동일한 값을 입력합니다.
ICMP 유형 (ICMP 전용) ICMP 메시지 유형을 입력합니다.
ICMP 코드 (ICMP 전용) ICMP 메시지 코드를 입력합니다.
  1. 추가 버튼을 클릭합니다.

ACL 규칙 편집

ACL 규칙 탭에서 편집할 규칙의 편집 버튼을 클릭합니다.

ACL 규칙 삭제

ACL 규칙 탭에서 삭제할 규칙의 삭제 버튼을 클릭합니다.

Network ACL 적용

커스텀 ACL을 적용하여 Tier 생성

VPC 내 Network Tier를 생성할 때 커스텀 ACL을 지정합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > VPC를 선택합니다.

  3. 작업할 VPC를 선택합니다.

  4. 네트워크 탭을 클릭합니다.

  5. 새 서브넷 추가 버튼을 클릭합니다.

  6. ACL 항목에서 원하는 커스텀 ACL을 선택합니다.

  7. 확인 버튼을 클릭합니다.

기존 Tier에 커스텀 ACL 할당

이미 생성된 Network Tier에 적용된 ACL을 다른 ACL로 교체합니다.

  1. 관리자 또는 일반 사용자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > VPC를 선택합니다.

  3. 작업할 VPC를 선택합니다.

  4. 네트워크 탭을 클릭합니다.

  5. 수정할 서브넷을 선택합니다.

  6. ACL 교체 아이콘을 클릭합니다.

  7. ACL 교체 대화 상자에서 적용할 ACL을 선택합니다.

  1. 확인 버튼을 클릭합니다.

참고: ACL 교체 후 잠시 기다리면 상세 화면에 새 ACL 규칙이 적용된 것을 확인할 수 있습니다.

  1. 용어사전
용어 설명
Network ACL (네트워크 액세스 제어 목록) VPC의 Network Tier에서 인바운드 및 아웃바운드 트래픽을 제어하는 보안 규칙의 집합입니다. 각 ACL은 하나 이상의 ACL 규칙으로 구성됩니다.
ACL 규칙 (ACL Rule) Network ACL을 구성하는 개별 보안 규칙입니다. 규칙 번호, CIDR, 프로토콜, 트래픽 유형, 액션으로 정의됩니다.
규칙 번호 (Rule Number) ACL 규칙이 평가되는 순서를 나타냅니다. 번호가 낮은 규칙부터 순서대로 평가되며, 트래픽이 첫 번째로 일치하는 규칙의 액션이 적용됩니다.
Ingress (인바운드) Network Tier로 들어오는 트래픽 방향입니다. Ingress 규칙의 CIDR은 출발지 주소 범위를 의미합니다.
Egress (아웃바운드) Network Tier에서 나가는 트래픽 방향입니다. Egress 규칙의 CIDR은 목적지 주소 범위를 의미합니다.
default_allow 모든 인바운드 및 아웃바운드 트래픽을 허용하는 namuVirt 기본 ACL입니다.
default_deny 모든 인바운드 및 아웃바운드 트래픽을 차단하는 namuVirt 기본 ACL입니다.
ACL 교체 (Replace ACL) 이미 Network Tier에 적용된 ACL을 다른 ACL로 변경하는 기능입니다.
