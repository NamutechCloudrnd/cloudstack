VPN 사용자

VPN 사용자는 원격 접근 VPN(Remote Access VPN)을 통해 namuVirt 클라우드 환경에 접속하는 사용자 계정이다. 관리자는 VPN 접속을 허용할 사용자 계정을 생성하고, 계정 및 도메인 단위로 관리할 수 있다.

목록 조회

VPN 사용자 목록을 확인하는 화면이다. 생성된 VPN 사용자 목록을 확인하거나 VPN 사용자 추가 버튼을 클릭하여 새 VPN 사용자를 추가할 수 있다.

VPN 사용자 추가

VPN 접속을 허용할 사용자 계정을 생성한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > VPN 사용자를 선택한다.

  3. VPN 사용자 추가 버튼을 클릭한다.

  4. 아래 항목을 입력한다.

항목 설명
사용자 이름 VPN 접속에 사용할 사용자 이름을 입력한다.
비밀번호 VPN 접속에 사용할 비밀번호를 입력한다.
도메인 해당 VPN 사용자가 속할 도메인을 선택한다.
계정 해당 VPN 사용자가 속할 계정을 선택한다.
  1. 확인 버튼을 클릭하여 VPN 사용자를 생성한다.

상세

VPN 사용자에 대한 상세 정보를 조회하는 화면이다. 해당 VPN 사용자의 아래 정보를 확인할 수 있다.

항목 설명
이름 VPN 사용자의 사용자 이름이다.
상태 VPN 사용자의 현재 상태이다.
계정 해당 VPN 사용자가 속한 계정이다.
도메인 해당 계정이 속한 도메인이다.

VPN 사용자 삭제

VPN 사용자를 삭제한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > VPN 사용자를 선택한다.

  3. 삭제할 VPN 사용자를 선택한다.

  4. VPN 사용자 삭제 버튼을 클릭한다.

  5. 확인 버튼을 클릭하여 삭제한다.

용어사전

용어 설명
VPN 사용자 (VPN User) 원격 접근 VPN을 통해 namuVirt 클라우드 환경에 접속하는 사용자 계정이다. 사용자 이름과 비밀번호를 통해 인증한다.
원격 접근 VPN (Remote Access VPN) 개별 사용자가 VPN 클라이언트 소프트웨어를 통해 namuVirt 클라우드 네트워크에 접속하는 방식이다. 전체 네트워크를 연결하는 Site-to-Site VPN과 달리, 개별 사용자 단위의 접근을 제공한다.
