IPv4 서브넷

IPv4 서브넷 기능은 ROUTED 모드 네트워크에서 사용할 IP 주소 공간을 Zone 단위로 사전에 정의하고 관리하는 기능입니다. 관리자는 특정 IP 대역을 서브넷으로 나누어 관리할 수 있으며, 이를 통해 네트워크의 IP 주소 공간을 효율적으로 분배하고 관리할 수 있습니다.

정의된 IPv4 서브넷은 ROUTED 모드로 생성된 Isolated 네트워크 또는 VPC의 게스트 네트워크에 자동으로 할당됩니다.

참고: IPv4 서브넷 관리는 루트 관리자(ROOT admin)만 수행할 수 있습니다.

목록 조회

IPv4 서브넷 목록을 확인하는 화면입니다. 등록된 IPv4 서브넷 목록을 확인하거나 IPv4 서브넷 추가 버튼을 클릭하여 새 IPv4 서브넷을 생성할 수 있습니다.

목록에서 서브넷, Zone, 상위 서브넷, 연결된 네트워크 이름, 상태 등의 정보를 확인할 수 있습니다.

IPv4 서브넷 추가

라우트 네트워크에서 사용할 IPv4 서브넷을 Zone에 등록합니다.

  1. 루트 관리자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > IPv4 서브넷을 선택합니다.

  3. 라우팅된 네트워크용 IPv4 서브넷 추가 버튼을 클릭합니다.

  4. 아래 항목을 입력합니다.

항목 설명
Zone IPv4 서브넷을 등록할 Zone을 선택합니다.
상위 서브넷 하위 서브넷을 생성하는 경우 상위 서브넷을 선택합니다. 최상위 서브넷을 생성하는 경우에는 선택하지 않습니다.
서브넷 등록할 IPv4 서브넷을 CIDR 형식으로 입력합니다. (예: 10.0.0.0/16)
CIDR 크기 CIDR 크기를 입력합니다.
  1. 확인 버튼을 클릭하여 IPv4 서브넷을 생성합니다.

참고: 하위 서브넷의 CIDR은 반드시 선택한 상위 서브넷의 CIDR 범위 안에 속해야 합니다.

상세

IPv4 서브넷에 대한 상세 정보를 조회하는 화면입니다. 해당 서브넷의 아래 정보를 확인할 수 있습니다.

항목 설명
서브넷 등록된 IPv4 서브넷의 CIDR 값입니다.
Zone 해당 서브넷이 속한 Zone 정보입니다. 이름과 ID가 조회됩니다.
상위 서브넷 해당 서브넷의 상위 서브넷 정보입니다. 최상위 서브넷인 경우 표시되지 않습니다.
네트워크 이름 해당 서브넷이 할당된 게스트 네트워크 또는 VPC의 이름입니다. 할당되지 않은 경우 표시되지 않습니다.
생성일 해당 서브넷이 등록된 날짜입니다.
상태 서브넷의 현재 할당 상태입니다. 사용 가능(Free) 또는 사용 중(Allocated) 상태를 나타냅니다.

IPv4 서브넷 삭제

등록된 IPv4 서브넷을 삭제합니다.

주의: IPv4 서브넷을 삭제하기 전에 해당 서브넷이 할당된 모든 네트워크를 먼저 제거해야 합니다. 하위 서브넷이 존재하는 경우 하위 서브넷을 먼저 삭제해야 합니다.

  1. 루트 관리자로 로그인합니다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > IPv4 서브넷을 선택합니다.

  3. 삭제할 IPv4 서브넷을 선택합니다.

  4. IPv4 서브넷 삭제 버튼을 클릭합니다.

  5. 확인 버튼을 클릭하여 삭제합니다.

용어사전

용어 설명
IPv4 서브넷 더 큰 IP 네트워크를 논리적으로 분할한 하위 네트워크입니다. CIDR 표기법으로 나타내며, namuVirt에서는 ROUTED 모드 네트워크에 할당할 IP 주소 범위를 Zone 단위로 사전에 등록합니다.
CIDR (Classless Inter-Domain Routing) IP 주소와 서브넷 마스크를 함께 표기하는 방식입니다. 예를 들어 10.0.0.0/24는 10.0.0.0~10.0.0.255 범위의 256개 IP 주소를 나타냅니다.
상위 서브넷 (Parent Subnet) 계층적 서브넷 구조에서 하위 서브넷을 포함하는 더 큰 범위의 서브넷입니다. 하위 서브넷의 CIDR은 반드시 상위 서브넷의 CIDR 범위 안에 속해야 합니다.
ROUTED 모드 가상 라우터가 Source NAT 없이 동작하는 네트워크 모드입니다. IPv4 서브넷은 이 모드에서 게스트 네트워크에 할당될 IP 주소 범위를 사전에 정의하는 데 사용됩니다.
