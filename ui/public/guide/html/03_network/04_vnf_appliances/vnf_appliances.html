VNF 어플라이언스

VNF(Virtualized Network Function, 가상화 네트워크 기능)는 라우터, 방화벽, 로드 밸런서 등의 네트워크 서비스를 제공하는 가상화 소프트웨어 애플리케이션이다. namuVirt에서는 VNF 템플릿을 등록하고 이를 기반으로 VNF 어플라이언스를 배포하여 네트워크 서비스를 가상머신 형태로 운영할 수 있다.

VNF는 다음 두 가지 개념으로 구성된다.

  • VNF 템플릿: VNF 어플라이언스 배포의 기반이 되는 이미지이다. NIC 구성, 접근 방식, 인증 정보 등 VNF 전용 설정을 포함한다.

  • VNF 어플라이언스: VNF 템플릿을 기반으로 배포된 가상머신이다. 네트워크에 연결되어 실제 네트워크 서비스를 제공한다.

VNF 템플릿

VNF 템플릿은 VNF 어플라이언스를 배포하기 위한 전용 이미지 템플릿이다. 일반 VM 템플릿과 달리 VNF NIC 구성 및 접근 방법(Access Method) 등의 VNF 전용 설정을 포함한다.

VNF 템플릿은 다음 두 가지 방법으로 등록할 수 있다.

  • URL에서 신규 등록: 원격 HTTP 서버의 URL을 통해 템플릿 유형을 VNF로 지정하여 직접 등록한다.

  • 기존 VM 템플릿 변환: 이미 등록된 일반 VM 템플릿의 유형을 VNF로 변경하여 전환한다.

URL에서 VNF 템플릿 등록

원격 HTTP 서버에 위치한 이미지를 VNF 템플릿으로 등록한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 이미지 > 템플릿을 선택한다.

  3. URL에서 템플릿 등록 버튼을 클릭한다.

  4. 아래 항목을 입력한다.

항목 설명
이름 템플릿 이름을 입력한다.
설명 템플릿에 대한 설명을 입력한다.
URL 이미지 파일이 위치한 원격 HTTP 서버의 URL을 입력한다.
Zone 템플릿을 등록할 Zone을 선택한다.
하이퍼바이저 사용할 하이퍼바이저 유형을 선택한다.
포맷 이미지 포맷(QCOW2, OVA 등)을 선택한다.
템플릿 유형 VNF를 선택한다. 이 항목을 VNF로 지정해야 VNF 템플릿으로 등록된다.
게스트 OS 템플릿의 게스트 운영체제 유형을 선택한다.

  1. 확인 버튼을 클릭한다.

  2. 등록이 완료되면 동일 페이지 또는 네트워크 > VNF 템플릿 메뉴에서 해당 템플릿을 확인할 수 있다.

VM 템플릿을 VNF 템플릿으로 변환

기존에 등록된 일반 VM 템플릿을 VNF 템플릿으로 변환한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 이미지 > 템플릿을 선택한다.

  3. 변환할 VM 템플릿을 선택한다.

  4. 시스템 환경설정 > 네트워크 탭으로 이동한다.

  5. 템플릿 유형을 VNF로 변경한다.

  6. 확인 버튼을 클릭한다.

VNF 어플라이언스

VNF 어플라이언스는 VNF 템플릿을 기반으로 배포된 가상머신으로, 라우터·방화벽·로드 밸런서 등의 네트워크 서비스를 제공한다. 일반 가상머신 생성과 동일한 절차를 따르되, VNF NIC 구성 단계가 추가된다.

배포 시 관리 인터페이스가 지정된 NIC의 네트워크 유형에 따라 네트워크 규칙이 자동으로 적용된다.

  • 관리 네트워크가 Isolated 네트워크인 경우: Public IP를 자동으로 할당하고, VNF 템플릿의 ACCESS_METHODS에 정의된 SSH·HTTP·HTTPS 포트에 대한 Static NAT 및 방화벽 규칙을 자동으로 생성한다.

  • 관리 네트워크가 보안 그룹이 있는 Shared 네트워크인 경우: ACCESS_METHODS에 정의된 포트를 허용하는 새 보안 그룹을 자동으로 생성하고 VNF 어플라이언스에 할당한다.

  • 관리 네트워크가 L2 네트워크, VPC Tier, 또는 보안 그룹이 없는 Shared 네트워크인 경우: 네트워크 규칙이 자동으로 구성되지 않는다.

목록 조회

VNF 어플라이언스 목록을 확인하는 화면이다. 배포된 VNF 어플라이언스의 이름, 상태, 템플릿, IP 주소, Zone 등의 정보를 확인할 수 있다. 항목을 클릭하면 상세 화면으로 이동한다.

VNF 어플라이언스 추가

VNF 템플릿을 기반으로 VNF 어플라이언스를 배포한다.

  1. 관리자 또는 일반 사용자로 로그인한다.

  2. 왼쪽 탐색 메뉴에서 네트워크 > VNF 어플라이언스를 선택한다.

  3. VNF 어플라이언스 추가 버튼을 클릭한다.

  4. 일반 가상머신 생성과 동일하게 아래 항목을 입력한다.

항목 설명
이름 VNF 어플라이언스의 이름을 입력한다.
Zone 배포할 Zone을 선택한다.
템플릿 VNF 템플릿을 선택한다.
컴퓨트 오퍼링 사용할 컴퓨트 오퍼링을 선택한다.
데이터 디스크 필요한 경우 데이터 디스크를 선택한다.

  1. VNF NIC 단계에서 VNF 템플릿에 정의된 각 NIC가 사용할 네트워크를 선택한다.

  2. 관리 인터페이스 네트워크가 Isolated 또는 보안 그룹이 있는 Shared 네트워크인 경우, 아래 추가 항목을 설정한다.

항목 설명
관리 인터페이스 규칙 구성 관리 인터페이스에 대한 네트워크 규칙 자동 구성 여부를 설정한다. 기본값은 False이다.
Source CIDR 관리 인터페이스로 트래픽을 허용할 출발지 CIDR 목록이다. 여러 항목은 쉼표(,)로 구분한다. 기본값은 0.0.0.0/0이다.

  1. VNF 어플라이언스 시작 버튼을 클릭한다.

  2. 배포가 완료되면 VNF 어플라이언스 목록 페이지에서 해당 어플라이언스를 확인할 수 있다.

상세 탭

VNF 어플라이언스의 기본 정보를 조회하는 화면이다. 이름, 아이디, 상태, 템플릿, OS Display 명, 하이퍼바이저, Zone, 호스트, IP 주소, 계정, 도메인 등의 정보를 확인할 수 있다.

NIC 탭

VNF 어플라이언스에 연결된 NIC 목록을 조회하는 화면이다. 각 NIC의 ID, 네트워크 이름, 유형, IP 주소, 게이트웨이, 넷마스크, 기본 여부 등의 정보를 확인할 수 있다.

이벤트 탭

VNF 어플라이언스에 관련된 이벤트 정보를 확인하는 화면이다. 어플라이언스에서 발생한 다양한 액션과 변경 사항을 확인할 수 있다.

코멘트 탭

VNF 어플라이언스에 관련된 코멘트 정보를 조회 및 관리하는 화면이다. 각 사용자별로 해당 어플라이언스에 대한 코멘트를 작성하고 관리할 수 있다.

용어사전

용어 설명
VNF (Virtualized Network Function) 라우터, 방화벽, 로드 밸런서 등의 네트워크 서비스를 가상화 소프트웨어 형태로 제공하는 애플리케이션이다.
VNF 템플릿 VNF 어플라이언스 배포의 기반이 되는 이미지 템플릿이다. 일반 VM 템플릿과 달리 VNF NIC 구성 및 접근 방법 등의 VNF 전용 설정을 포함한다.
VNF 어플라이언스 VNF 템플릿을 기반으로 배포된 가상머신이다. 실제 네트워크에 연결되어 네트워크 서비스를 제공한다.
VNF NIC VNF 어플라이언스의 네트워크 인터페이스 정의이다. Device ID, 이름, 필수 여부, 관리 인터페이스 여부 등의 속성을 가진다. Device ID는 0부터 시작하는 연속된 정수여야 한다.
관리 인터페이스 (Management Interface) VNF 어플라이언스의 SSH, HTTP, HTTPS 등 관리 접근에 사용되는 NIC이다. 배포 시 관리 네트워크 유형에 따라 방화벽 규칙 또는 보안 그룹이 자동으로 구성된다.
ACCESS_METHODS VNF 템플릿 상세 정보 중 접근 방법을 정의하는 항목이다. console, http, https, ssh-key, ssh-password 값을 지원한다.
Source CIDR VNF 어플라이언스의 관리 인터페이스로 트래픽을 허용할 출발지 네트워크의 IP 범위이다.
