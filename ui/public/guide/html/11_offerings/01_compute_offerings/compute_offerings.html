컴퓨트 오퍼링

가상머신에 사용할 가상 하드웨어 사양(CPU, Memory, GPU 지원 등)을 정의하는 기능이다. 가상머신 생성 시 등록된 컴퓨트 오퍼링을 선택하여 원하는 성능을 적용한다. 이를 통해 VM 성능 정책을 표준화하고 리소스 과다 사용을 방지할 수 있다.

또한, 참조 무결성을 유지하기 위해 namuVIRT에서 오퍼링의 삭제는 불가능하다.

추가 버튼을 클릭하여 컴퓨트 오퍼링을 생성할 수 있으며, 필요한 정보들은 다음과 같다.

  • 이름: 컴퓨트 오퍼링 이름

  • 설명: 컴퓨트 오퍼링에 대한 설명

  • 컴퓨트 오퍼링 유형: 오퍼링 제한, 커스텀 제한, 커스텀 제한 없음

  • CPU 코어: CPU 코어 수

  • CPU: CPU 속도 (MHz)

  • 메모리: 메모리 크기 (MB)

  • 호스트 태그: 해당 태그가 설정된 호스트에만 가상머신 배치

  • 네트워크 속도: 데이터 전송 속도

  • HA 제공: 고가용성 제공 여부

  • 동적 스케일링 활성화: CPU, 메모리에 대한 동적 스케일링 사용 여부

  • CPU 제한: CPU 사용량 제한 여부

  • 휘발성 여부: 가상머신 재시작 시 기존 루트 디스크 분리 및 삭제하고 새로운 루트 디스크를 생성하는 휘발성 여부

  • 배포 플래너: 가상머신 배포 시 사용할 정책 (가상머신을 어느 위치에 배치할지 결정)

  • GPU 카드: 등록된 GPU 카드 유형에서 선택

  • 공개: 퍼블릭 여부

  • Zone: 해당 Zone에만 가상머신 배치 (퍼블릭 오퍼링의 경우 null)

  • 리소스 삭제: 가상머신 삭제 시 연결된 리소스 정보를 데이터베이스에서 함께 제거

  • 컴퓨트 전용 디스크 오퍼링: 기존의 디스크 오퍼링을 선택하거나 해당 컴퓨트 오퍼링용 디스크 오퍼링 지정

    • 스토리지 유형: 어떤 종류의 스토리지에 생성할지 선택

    • 프로비저닝 유형: 디스크 공간 할당 방식

    • Write-cache 유형: 디스크 캐시 모드 설정

    • QoS 유형: 디스크 성능 제어 방식

    • Root 디스크 크기: Root 디스크 크기 지정 (GB)

    • 스토리지 태그: 해당 태그가 설정된 스토리지에만 디스크 할당

    • 암호화: 디스크 암호화 여부

    • 디스크 오퍼링 엄격성: 가상머신 생성 후 Root 디스크의 오퍼링 변경 허용 여부 (true일 경우 불가)

  • 외부 세부 정보: 하이퍼바이저에 추가로 전달할 사용자 정의 설정값 (Key-Value)

상세 페이지에서 컴퓨트 오퍼링을 수정하고 활성화 및 비활성화할 수 있다. 또한 해당 오퍼링을 사용중인 가상머신 목록으로 이동할 수 있다.
