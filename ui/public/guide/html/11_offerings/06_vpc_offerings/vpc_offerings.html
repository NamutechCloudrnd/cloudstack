VPC 오퍼링

VPC 네트워크 환경을 생성할 때 적용되는 기본 네트워크 설정을 정의하는 기능이다. 여러 네트워크가 포함된 VPC 전체 구조의 동작 방식을 결정하는 상위 레벨 정책으로 복잡한 서비스 아키텍처에 사용된다.

namuVIRT에서 기본으로 제공하는 VPC 오퍼링 목록이 있으며, 삭제 시 시스템 운영에 문제가 발생할 수 있다.

추가 버튼을 클릭하여 VPC 오퍼링을 생성할 수 있으며, 필요한 정보들은 다음과 같다.

  • 이름: VPC 오퍼링 이름

  • 설명: VPC 오퍼링에 대한 설명

  • 제공자: 네트워크 서비스 제공자

  • 네트워크 모드: 네트워크 동작 방식 선택

    • NATTED: NAT (Network Address Translation) 기반 동작

    • ROUTED: 라우팅 기반 동작

  • 지원되는 서비스: 지원할 네트워크 기능

  • 컴퓨트 오퍼링: Virtual Router 사양에 적용할 컴퓨트 오퍼링

  • 공개: 퍼블릭 여부

  • VPC 오퍼링 활성화: 오퍼링 생성 중 활성화 여부
