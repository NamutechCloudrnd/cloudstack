디스크 오퍼링

데이터 디스크의 저장소 정책 및 용량을 정의하는 기능이다. 가상머신에 추가 디스크를 할당하거나 볼륨을 생성할 때 디스크 오퍼링을 선택하여 사양을 지정할 수 있다.

목록 페이지에서 디스크 오퍼링을 선택하여, 활성화 및 비활성화를 지정할 수 있다. 참조 무결성을 유지하기 위해 오퍼링의 삭제는 불가능하다.

추가 버튼을 클릭하여 디스크 오퍼링을 생성할 수 있으며 필요한 정보들은 다음과 같다.

  • 이름: 디스크 오퍼링 이름

  • 설명: 디스크 오퍼링에 대한 설명

  • 스토리지 유형: 어떤 종류의 스토리지에 생성할지 선택

  • 프로비저닝 유형: 디스크 공간 할당 방식

    • Thin 프로비저닝: 실제 사용한 만큼 디스크 공간 할당

    • Sparse 프로비저닝: 디스크 공간을 미리 할당하고 필요한 시점에 블록 초기화

    • Fat 프로비저닝: 디스크 생성 시 전체 공간 즉시 할당 및 초기화

  • 암호화: 디스크 암호화 여부

  • 디스크 크기 엄격성: 디스크 크기 변경 허용 여부 (true일 경우 불가)

  • 커스텀 디스크 크기: 해당 오퍼링 사용 시 디스크 크기 직접 지정

  • QoS 유형: 디스크 성능 제어 방식

  • Write-cache 유형: 디스크 캐시 모드 설정

    • Write-back: 데이터를 캐시에 먼저 기록한 뒤 이후에 디스크에 반영

    • Write-through: 데이터를 캐시와 디스크 동시에 기록

  • 스토리지 태그: 해당 태그가 설정된 스토리지에만 디스크 할당

  • 공개: 퍼블릭 여부

  • Zone: 해당 Zone에만 디스크 할당 (퍼블릭 오퍼링의 경우 null)

상세 페이지에서 해당 디스크 오퍼링을 수정하고 활성화 및 비활성화할 수 있다.
