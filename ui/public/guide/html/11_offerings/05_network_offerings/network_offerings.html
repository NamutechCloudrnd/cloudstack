네트워크 오퍼링

네트워크 생성 시 사용할 네트워크 기능 및 서비스를 정의하는 기능이다. 네트워크 구성을 표준화하여 동일한 정책을 재사용하고 운영 환경의 일관성을 유지할 수 있다.

namuVIRT에서 기본으로 제공하는 네트워크 오퍼링 목록이 있으며, 삭제 시 시스템 운영에 문제가 발생할 수 있다.

추가 버튼을 클릭하여 네트워크 오퍼링을 생성할 수 있으며, 필요한 정보들은 다음과 같다.

  • 이름: 네트워크 오퍼링 이름

  • 설명: 네트워크 오퍼링에 대한 설명

  • 네트워크 속도: 데이터 전송 속도 (Mb/s)

  • 게스트 유형: 게스트 네트워크 유형

  • VLAN 지정: VLAN 지원 여부

  • 영구적: 영구 네트워크 지원 여부

  • VPC: VPC 환경에서 사용 가능 여부

  • 제공자: 네트워크 서비스 제공자

  • 네트워크 모드: 네트워크 동작 방식 선택

    • NATTED: NAT (Network Address Translation) 기반 동작

    • ROUTED: 라우팅 기반 동작

  • 비규칙 모드: 가상머신이 자신의 MAC 주소와 무관한 모든 패킷 수신 여부

    • 없음: 글로벌 설정값 사용

    • 승인: 모든 패킷을 허용하며 필터링 미적용

    • 거부: 자신의 MAC 주소로 들어오는 패킷만 수신

  • Mac 변조 전송: 가상머신의 MAC 주소 변경 패킷 허용 여부

    • 없음: 글로벌 설정값 사용

    • 승인: 모든 패킷을 허용하며 필터링 미적용

    • 거부: .vmx 설정 파일의 MAC 주소와 다른 출발지 MAC 주소의 패킷을 차단

  • Mac 주소 변경: 가상머신 내부에서 MAC 주소 변경 허용 여부

    • 없음: 글로벌 설정값 사용

    • 승인: 가상머신 내부에서 MAC 주소 변경 가능

    • 거부: MAC 주소 변경 차단

  • Mac 학습: 가상머신에서 발생하는 트래픽 기반 MAC 주소 학습 및 테이블 등록 여부

    • 없음: 글로벌 설정값 사용

    • 승인: MAC 주소를 학습하여 스위칭 테이블에 반영

    • 거부: MAC 학습 비활성화

  • 지원되는 서비스: 지원할 네트워크 기능

  • 컴퓨트 오퍼링: Virtual Router 사양에 적용할 컴퓨트 오퍼링

  • 절약 모드: 네트워크 자원 사용 최적화 여부

  • 태그: 오퍼링에 설정할 태그

  • 공개: 퍼블릭 여부

  • Zone: 오퍼링이 적용될 수 있는 Zone

  • 네트워크 오퍼링 활성화: 오퍼링 생성 중 활성화 여부

상세 페이지에서 네트워크 오퍼링을 수정하고 삭제할 수 있다.
