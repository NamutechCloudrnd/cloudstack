백업 오퍼링

리소스 백업 수행 시 사용되는 백업 정책 단위를 정의하는 기능이다. 오퍼링을 통해 동일한 백업 정책을 여러 가상머신에 공통으로 적용하여 운영 정책을 표준화할 수 있다.

추가 버튼을 클릭하여 백업 오퍼링을 생성할 수 있으며, 필요한 정보들은 다음과 같다.

  • 이름: 백업 오퍼링 이름

  • 설명: 백업 오퍼링에 대한 설명

  • Zone: 백업 오퍼링을 사용할 수 있는 Zone

  • 외부 ID: 사용할 외부 백업 시스템 정책

  • 사용자 기반 백업 허용: 사용자의 수동 백업(adhoc 백업) 및 백업 스케줄 생성 허용 여부

상세 페이지에서 백업 오퍼링을 수정하고 삭제할 수 있으며, 해당 오퍼링을 사용중인 가상머신 목록으로 이동할 수 있다.
