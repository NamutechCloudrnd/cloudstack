Backup Repository

Backup Repository는 Backup 데이터를 저장하는 저장소이다. 주소, 유형, Zone 접근성, 마운트 옵션을 확인한 뒤 등록한다.

백업 저장소 목록 화면

  • 화면 위치: Infrastructure > Backup Repository
  • 설명: 등록된 백업 저장소 목록과 추가 버튼을 확인하는 화면이다.

백업 저장소 목록 화면에서는 백업 데이터를 저장할 Repository의 이름, Provider, Type, Address, Zone 정보를 확인할 수 있다. 화면 예시에서는 아직 등록된 백업 저장소가 없어 데이터 없음 상태로 표시된다. 상단의 Add Backup Repository 버튼을 통해 신규 백업 저장소를 추가할 수 있으며, 검색 입력창을 사용해 등록된 항목을 조회할 수 있다.

백업 저장소 추가 입력 화면

  • 화면 위치: Infrastructure > Backup Repository > Add Backup Repository
  • 설명: 백업 데이터를 저장할 Repository의 이름, 주소, 유형, 마운트 옵션, Zone을 입력하는 화면이다.

백업 저장소 추가 화면에서는 Repository 이름, 저장소 주소, 저장소 유형, 마운트 옵션, Zone, Cross-Zone Instance Creation 사용 여부를 입력한다. 화면 예시에서는 이름이 Test-Backup-Repository로 입력되어 있고, Address는 10.10.14.5:/export/backup, Type은 nfs, Zone은 namu_zone으로 설정되어 있다. Mount options는 비어 있으며, Cross-Zone Instance Creation 옵션은 비활성화되어 있다.

생성된 백업 저장소 목록 화면

  • 화면 위치: Infrastructure > Backup Repository
  • 설명: 신규 백업 저장소 생성 후 목록에 등록 정보가 표시되는 화면이다.

백업 저장소를 추가하면 목록에 신규 Repository가 표시된다. 화면 예시에서는 Test-Backup-Repository 항목이 표시되며, Provider는 nas, Type은 nfs, Address는 10.10.14.5:/export/backup, Zone은 namu_zone으로 표시된다. 사용자는 이 목록에서 등록된 백업 저장소의 연결 위치와 저장소 유형을 확인할 수 있다.

백업 저장소 상세 정보 화면

  • 화면 위치: Infrastructure > Backup Repository > Backup Repository Detail
  • 설명: 선택한 백업 저장소의 이름, 유형, 주소, Zone 정보를 확인하는 화면이다.

백업 저장소 상세 화면에서는 선택한 저장소의 이름, 유형, 주소, Zone 정보를 확인할 수 있다. 사용자는 등록 후 이 화면에서 백업 저장소 연결 정보를 다시 점검할 수 있다.

주요 작업

Backup Repository 추가

  1. Infrastructure > Backup Repository로 이동한다.
  2. Add Backup Repository를 선택한다.
  3. 이름, Address, Type, Mount options, Zone을 입력한다.
  4. 필요하면 Cross-Zone Instance Creation 옵션을 확인한다.
  5. 저장 후 목록에서 신규 Repository가 표시되는지 확인한다.

Backup Repository 상세 조회

  1. 목록에서 대상 Repository를 선택한다.
  2. 이름, 유형, 주소, Zone이 의도한 구성과 일치하는지 확인한다.
  3. 등록 후 실제 Backup 생성과 복원 테스트로 접근 가능 여부를 검증한다.

입력 항목

백업 저장소 추가 입력 화면

항목 설명
Name 백업 저장소를 식별할 이름을 입력한다.
Address 백업 저장소의 접근 주소를 입력한다. NFS는 <서버 IP>:/<export 경로> 형식을 사용한다.
Type 백업 저장소 유형을 선택한다. 화면 예시에서는 nfs가 선택되어 있다.
Mount options 하이퍼바이저 호스트에서 백업 저장소를 마운트할 때 사용할 옵션을 입력한다.
Zone 백업 저장소를 연결할 Zone을 선택한다.
Cross-Zone Instance Creation 백업 저장소를 사용해 다른 Zone에서 인스턴스 생성 또는 복구 흐름을 사용할지 선택한다.

상태 및 제약 조건

  • 목록에서는 Provider, Type, Address, Zone 정보를 기준으로 등록 상태를 확인한다.
  • 지원되는 저장소 유형은 Backup Provider 구성에 따라 달라질 수 있다.
  • Cross-Zone Instance Creation은 Backup 자체를 복제하는 기능이 아니라, 다른 Zone에서 해당 Backup을 사용한 Instance 생성 가능성을 넓히는 옵션이다.
  • Repository 등록만으로 안정성이 보장되지는 않으며, 실제 Backup과 복원 테스트가 필요하다.

주의사항

  • 입력한 Address는 백업과 복구 작업을 수행하는 호스트에서 접근 및 마운트 가능해야 한다.
  • Cross-Zone Instance Creation을 사용하는 경우 다른 Zone의 호스트에서도 동일한 백업 저장소에 접근할 수 있어야 한다.
  • Mount options에 잘못된 값을 입력하면 백업 저장소 마운트 실패가 발생할 수 있다.
  • 백업 저장소 등록 후에는 실제 백업 생성과 복구 테스트를 통해 저장소 접근 가능 여부를 검증해야 한다.
  • 백업 저장소 상세 정보를 확인할 때는 대상 Zone과 접근 주소가 의도한 구성과 일치하는지 함께 점검해야 한다.
