Secondary Storage

개요

Secondary Storage는 Template, ISO, Snapshot과 같은 보조 리소스를 보관하는 스토리지이다. Zone 단위 등록과 마운트 가능 여부가 중요하다.

화면 구성

보조 스토리지 목록 화면

  • 화면 위치: Infrastructure > Secondary Storage
  • 설명: 등록된 보조 스토리지의 URL, 프로토콜, 범위, Zone, 접근 권한을 확인하는 화면이다.

보조 스토리지 목록 화면에서는 템플릿, ISO, 볼륨 스냅샷 등 이미지성 데이터를 저장하는 보조 저장소 정보를 확인할 수 있다. 화면 예시에서는 Secondary-Storage가 등록되어 있으며, URL은 nfs://10.10.14.129/export/secondary, Protocol은 nfs, Scope는 ZONE, Zone은 namu_zone, Access는 ReadWrite로 표시된다. 상단의 Add Secondary Storage 버튼을 통해 신규 보조 스토리지를 추가할 수 있다.

보조 스토리지 추가 입력 화면

  • 화면 위치: Infrastructure > Secondary Storage > Add Secondary Storage
  • 설명: NFS 기반 보조 스토리지를 추가하기 위해 이름, Provider, Zone, 서버, 경로를 입력하는 화면이다.

보조 스토리지 추가 화면에서는 저장소 이름, Provider, Zone, 서버 주소, 경로를 입력한다. 화면 예시에서는 이름이 Test-Secondary-Storage, Provider는 NFS, Zone은 namu_zone, Server는 10.10.14.129, Path는 /export/secondary로 입력되어 있다. 입력한 서버와 경로는 관리 서버 및 하이퍼바이저 호스트에서 접근 가능해야 하며, 보조 스토리지 등록 후 템플릿, ISO, 스냅샷 관련 작업에 사용된다.

보조 스토리지 목록 반영 화면

  • 화면 위치: Infrastructure > Secondary Storage
  • 설명: 신규 보조 스토리지 추가 후 목록에 ReadWrite 상태로 표시되는 화면이다.

보조 스토리지를 추가하면 목록에 신규 저장소가 표시된다. 화면 예시에서는 기존 Secondary-Storage와 신규 Test-Secondary-Storage가 함께 표시되며, 두 항목 모두 Protocol은 nfs, Scope는 ZONE, Zone은 namu_zone, Access는 ReadWrite로 표시된다. URL에는 각각 nfs://10.10.14.5/export/secondary와 nfs://10.10.14.129/export/secondary가 표시되어 저장소 서버와 경로를 구분할 수 있다.

보조 스토리지 상세 정보 화면

  • 화면 위치: Infrastructure > Secondary Storage > Secondary-Storage > Details
  • 설명: 선택한 보조 스토리지의 URL, 프로토콜, 범위, Zone, 읽기 전용 여부를 확인하는 화면이다.

보조 스토리지 상세 화면에서는 저장소 이름, ID, URL, Protocol, Scope, Zone, Read-Only 여부를 확인할 수 있다. 왼쪽 요약 영역에는 Zone 정보와 함께 View Templates, View ISOs, View Volume Snapshots 버튼이 표시되어 보조 스토리지에 연관된 템플릿, ISO, 볼륨 스냅샷 화면으로 이동할 수 있다. 화면 예시의 저장소는 nfs://10.10.14.5/export/secondary URL을 사용하며, Read-Only는 false로 표시된다.

보조 스토리지 설정 화면

  • 화면 위치: Infrastructure > Secondary Storage > Secondary-Storage > Settings
  • 설명: 선택한 보조 스토리지에 적용되는 NFS 마운트 버전 설정을 확인하는 화면이다.

Settings 탭에서는 보조 스토리지에 적용되는 설정값을 확인하거나 수정할 수 있다. 화면 예시에서는 secstorage nfs version 설정이 표시되며, 보조 스토리지 마운트 시 특정 NFS 버전을 강제하는 용도로 설명되어 있다. 입력값이 비어 있는 경우 기본 선택 방식이 적용될 수 있다.

보조 스토리지 브라우저 화면

  • 화면 위치: Infrastructure > Secondary Storage > Secondary-Storage > Browser
  • 설명: 보조 스토리지 내부 경로와 저장된 템플릿 파일을 확인하는 화면이다.

Browser 탭에서는 보조 스토리지 내부의 디렉터리와 파일을 탐색할 수 있다. 화면 예시에서는 template/tmpl/2/204 경로가 표시되며, QCOW2 템플릿 파일과 template.properties 파일이 목록에 표시된다. 각 항목의 크기, 마지막 갱신 시각, 연결된 리소스를 확인할 수 있으며, 템플릿 파일은 Rocky Linux 8 리소스와 연결되어 있다.

보조 스토리지 이벤트 탭 화면

  • 화면 위치: Infrastructure > Secondary Storage > Secondary-Storage > Events
  • 설명: 보조 스토리지 상세 화면의 이벤트 탭을 확인하는 화면이다.

보조 스토리지 상세 화면의 Events 탭에서는 해당 저장소와 관련된 작업 이력과 이벤트 기록을 확인할 수 있다. 화면 예시에는 데이터 없음 상태가 표시되며, 상세 화면에는 Details, Settings, Browser, Events, Comments 탭이 함께 표시된다.

주요 작업

Secondary Storage 추가

  1. Infrastructure > Secondary Storage로 이동한다.
  2. Add Secondary Storage를 선택한다.
  3. Name, Provider, Zone, Server, Path를 입력한다.
  4. 저장 후 목록에서 신규 Storage와 접근 권한이 의도대로 표시되는지 확인한다.

설정 및 Browser 조회

  1. 대상 Secondary Storage를 선택한다.
  2. Settings 탭에서 NFS 버전 설정을 확인한다.
  3. Browser 탭에서 Template·ISO·Snapshot 파일이 의도한 경로에 있는지 조회한다.
  4. 이상 징후가 있으면 Events 탭으로 작업 이력을 확인한다.

입력 항목

보조 스토리지 추가 입력 화면

항목 설명
Name 보조 스토리지를 식별할 이름을 입력한다.
Provider 보조 스토리지 Provider를 선택한다. 화면 예시에서는 NFS가 선택되어 있다.
Zone 보조 스토리지를 사용할 Zone을 선택한다.
Server 보조 스토리지 서버의 IP 주소 또는 호스트명을 입력한다.
Path 서버에서 export 또는 공유된 보조 스토리지 경로를 입력한다.

보조 스토리지 설정 화면

항목 설명
Secstorage nfs version 보조 스토리지 마운트 시 사용할 NFS 버전을 지정한다. 비어 있으면 기본 선택 방식이 적용될 수 있다.

상태 및 제약 조건

  • ReadWrite 상태의 Secondary Storage는 Template, ISO, Snapshot 쓰기 작업에 사용된다.
  • 읽기 전용 상태에서는 새 데이터를 저장하는 작업이 제한될 수 있다.
  • Scope가 ZONE이면 해당 Zone 안에서만 사용된다.
  • 하나의 Zone에 여러 Secondary Storage를 둘 경우 데이터 배치와 이동 방식은 운영 구성에 따라 달라질 수 있다.

주의사항

  • 입력한 서버와 경로가 실제로 마운트 가능하지 않으면 템플릿, ISO, 스냅샷 관련 작업이 실패할 수 있다.
  • 보조 스토리지 경로를 중복 등록하거나 잘못된 경로로 등록하지 않도록 기존 목록을 확인해야 한다.
  • 하나의 Zone에 여러 보조 스토리지를 구성하는 경우 템플릿, ISO, 스냅샷 데이터의 위치와 동기화 상태를 확인해야 한다.
  • 보조 스토리지가 읽기 전용으로 전환되거나 접근 불가 상태가 되면 템플릿, ISO, 스냅샷 등록 및 복사 작업에 영향을 줄 수 있다.
  • NFS 버전 설정이 실제 서버에서 지원하지 않는 값으로 지정되면 보조 스토리지 마운트 실패가 발생할 수 있다.
  • 보조 스토리지 Browser에 표시되는 파일은 템플릿, ISO, 스냅샷 등 리소스와 연결될 수 있으므로 임의 삭제나 변경을 수행해서는 안 된다.

이벤트 및 이력 확인

Events 탭에서는 Secondary Storage와 관련된 작업 이력을 확인한다. Template·ISO·Snapshot 등록 실패가 있을 때는 접근 권한, 설정값, 이벤트를 함께 점검한다.
