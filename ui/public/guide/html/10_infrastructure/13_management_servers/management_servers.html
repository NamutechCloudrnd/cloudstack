관리 서버

관리 서버(Management Server)는 클라우드 배포에서 자원을 오케스트레이션하고 할당하는 역할을 한다.

관리 서버가 수행하는 역할:

  • 관리자 및 최종 사용자 모두를 위한 웹 인터페이스를 제공한다.

  • namuVirt API 및 EC2 인터페이스를 위한 API 인터페이스를 제공한다.

  • 게스트 인스턴스를 특정 컴퓨트 자원에 배정하는 것을 관리한다.

  • 공용 및 사설 IP 주소의 배정을 관리한다.

  • VM 인스턴스화 과정에서 스토리지를 할당한다.

  • 스냅샷, 디스크 이미지(템플릿), ISO 이미지를 관리한다.

  • 클라우드를 위한 단일 구성 지점을 제공한다.

목록 조회

관리 서버 목록을 확인하는 화면이다.

유지보수 준비

관리 서버 서비스를 유지보수 상태로 변환하기 위한 준비단계를 수행한다.

유지보수 준비 버튼을 클릭하여 유지보수 준비 화면을 호출한 뒤 확인 버튼을 클릭한다.

종료 준비

관리 서버 서비스를 안전하게 정지하기 위한 준비 단계를 수행한다.

종료 준비 버튼을 클릭하여 종료 준비 화면을 호출한 뒤 확인 버튼을 클릭한다.

참고: 관리 서버의 유지보수나 중단이 발생하더라도 클라우드에서 실행 중인 인스턴스에는 영향을 주지 않는다.

안전 종료 트리거

관리 서버의 서비스를 정지한다.

주의: 이 작업을 수행하면 관리 서버 서비스가 종료된다. 재시작은 시스템에 접속하여 관리 서버 서비스를 직접 시작하거나, systemctl start 명령을 통해 수행할 수 있다.

안전 종료 트리거 버튼을 클릭하여 안전 종료 트리거 화면을 호출한 뒤 확인 버튼을 클릭한다.

피어 탭

관리 서버 피어 정보를 조회하는 화면이다.

관리 서버는 서버가 로드 밸런싱되는 다중 노드 설치 형태로 배포될 수 있다. 다중 노드 관리 서버 구성에서 각 관리 서버는 서로 피어(Peer) 관계를 이루어 데이터를 공유하고 부하를 분산하여 처리한다. 한 관리 서버에 문제가 발생하면 다른 관리 서버가 처리를 이어받아 클라우드 서비스의 안정성을 유지한다.

데이터베이스 손실 시 장애 조치(Failover)를 위해 MySQL 복제(Replication)를 구성할 수 있다.
