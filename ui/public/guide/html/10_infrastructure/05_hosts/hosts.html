Hosts

Hosts는 인프라에서 Instance를 실행하는 물리 서버 또는 Hypervisor 노드를 관리하는 기능이다. Host는 Zone, Pod, Cluster에 속하며 CPU, Memory, Network, GPU, Storage 접근성, Agent 연결 상태를 기반으로 Instance 배치 후보가 된다. 운영자는 Host의 State와 Resource state를 구분해 확인하고, 추가·유지보수·보안 키 배포·이벤트 조회 작업을 수행한다.

호스트 목록 화면

  • 화면 위치: Infrastructure > Hosts
  • 설명: 등록된 Host의 상태, 리소스 상태, IP, 아키텍처, Hypervisor, 버전, Cluster, Zone, Management Server 정보를 확인하는 화면이다.

호스트 목록 화면에서는 등록된 Host를 표 형태로 조회한다. 화면에는 Name, State, Resource state, IP Address, Arch, Hypervisor, System VMs, Version, Cluster name, Zone, Management server 컬럼이 표시된다. 예시 화면에서는 KVM 기반 x86_64 Host 1대가 표시되며, Resource state는 Enabled로 표시된다. 상단의 Add Host 버튼을 통해 신규 Host 추가 작업을 시작할 수 있다.

호스트 추가 입력 화면

  • 화면 위치: Infrastructure > Hosts > Add Host
  • 설명: Zone, Pod, Cluster, Host 주소, 사용자명, 인증 방식, Host Tag, Dedicated 여부를 입력하여 신규 Host를 추가하는 화면이다.

호스트 추가 화면에서는 신규 Host가 속할 Zone, Pod, Cluster를 선택하고 Host name 또는 관리 IP, username, 인증 방식을 입력한다. 화면 예시에서는 Password 인증 방식이 선택되어 있으며, System SSH Key 방식도 선택할 수 있다. Host tags 입력란을 통해 Host Tag를 지정할 수 있고, Dedicated 옵션을 통해 Host를 특정 계정 또는 도메인 전용 리소스로 사용할 수 있다.

호스트 상세 정보 화면

  • 화면 위치: Infrastructure > Hosts > Host Detail > Details
  • 설명: 선택한 Host의 상태, 리소스 상태, IP, Hypervisor, 아키텍처, 유형, Cluster, Pod, Zone, Management Server 정보를 확인하는 화면이다.

호스트 상세 정보 화면에서는 선택한 Host의 기본 속성과 리소스 사용량을 확인한다. 왼쪽 요약 영역에는 Status, Resource state, ID, IP address, CPU, Memory, Network, Cluster 정보가 표시되며, 오른쪽 Details 탭에는 Name, ID, Resource state, IP Address, Hypervisor, Arch, Type, Cluster name, Pod name, Zone, Management server 등의 항목이 표시된다. Host Type이 Routing으로 표시되면 일반 Instance 실행 리소스로 사용하는 Host임을 확인할 수 있다.

호스트 GPU 탭 화면

  • 화면 위치: Infrastructure > Hosts > Host Detail > GPU
  • 설명: Host에서 GPU 장치를 검색하거나 등록하고, GPU 자원 요약과 장치 목록을 확인하는 화면이다.

GPU 탭에서는 Host에 연결된 GPU 장치를 검색하고 자원으로 등록할 수 있다. 화면에는 Discover GPU devices 버튼과 Add GPU Device 버튼이 표시되며, Summary와 GPU Devices 하위 탭이 제공된다. Summary 표에는 GPU 이름, 전체 수량, 할당 수량, 사용 가능 수량, 연결된 Instance 수를 표시할 수 있다. 예시 화면에서는 GPU 데이터가 없는 상태로 표시된다.

호스트 이벤트 탭 화면

  • 화면 위치: Infrastructure > Hosts > Host Detail > Events
  • 설명: Host와 관련된 이벤트 수준, 유형, 상태, 사용자, 계정, 도메인, 생성 시각을 조회하는 화면이다.

Events 탭에서는 선택한 Host와 관련된 작업 이력과 이벤트를 조회한다. 화면에는 Level, Type, State, Username, Account, Domain, Created 컬럼이 표시된다. Host 추가, 활성화/비활성화, 유지보수 전환, 보안 키 배포, GPU 검색, 삭제 등의 작업 이후 이 탭에서 관련 이벤트 발생 여부를 확인할 수 있다.

호스트 댓글 탭과 보안 키 배포 작업 버튼

  • 화면 위치: Infrastructure > Hosts > Host Detail > Comments / Action Icons
  • 설명: Host 운영 메모를 등록하고, 상단 작업 버튼에서 Host security key 배포 기능을 확인하는 화면이다.

Comments 탭에서는 Host에 대한 운영 메모를 등록할 수 있다. 화면에는 댓글 입력란, Only visible to administrators 체크박스, Submit 버튼이 표시된다. 우측 상단 작업 버튼 영역에는 Host 제어와 관련된 여러 아이콘이 있으며, 화면 예시에서는 provision host security key 버튼의 툴팁이 표시된다. 이 작업은 Host 보안 키를 배포하거나 갱신하는 기능과 관련되므로 실행 전 Host 상태와 Agent 연결 상태를 확인해야 한다.

주요 작업

Host 목록 조회

  1. Infrastructure > Hosts로 이동한다.
  2. 목록에서 Name, State, Resource state, IP Address, Arch, Hypervisor, Cluster name, Zone을 확인한다.
  3. 특정 Host의 상태를 자세히 확인하려면 대상 Host 이름을 선택한다.
  4. 신규 Instance 배치나 장애 분석 전에는 State와 Resource state를 함께 확인한다.

Host 추가

  1. Infrastructure > Hosts로 이동한다.
  2. Add Host를 선택한다.
  3. Zone, Pod, Cluster를 선택한다.
  4. host name 또는 관리 IP와 username을 입력한다.
  5. Authentication Method에서 Password 또는 System SSH Key를 선택한다.
  6. Password 방식을 사용할 경우 비밀번호를 입력한다.
  7. 필요한 경우 Host tags와 Dedicated 옵션을 설정한다.
  8. OK를 선택한 뒤 목록에서 신규 Host가 표시되는지 확인한다.

Host 상세 조회

  1. Host 목록에서 대상 Host를 선택한다.
  2. Details 탭에서 Status, Resource state, IP Address, Hypervisor, Arch, Type, Cluster, Pod, Zone을 확인한다.
  3. CPU, Memory, Network 사용량을 확인한다.
  4. Host가 배치 후보에서 제외된 경우 State와 Resource state, Cluster 상태, 리소스 여유량을 함께 확인한다.

GPU 장치 조회 및 등록

  1. 대상 Host 상세 화면에서 GPU 탭을 선택한다.
  2. Summary 탭에서 GPU 자원 요약 정보를 확인한다.
  3. 필요한 경우 Discover GPU devices를 선택해 Host에 연결된 GPU 장치를 검색한다.
  4. 수동 등록이 필요한 경우 Add GPU Device를 선택한다.
  5. 등록 후 GPU Devices 목록과 할당 가능 수량을 확인한다.

댓글, 보안 키, 이벤트 확인

  1. Comments 탭에서 Host 관련 운영 메모를 확인하거나 등록한다.
  2. 메모 등록 시 민감정보를 입력하지 않는다.
  3. Host State가 보안 키와 관련된 상태로 표시되면 우측 상단 작업 버튼에서 provision host security key 툴팁을 확인한다.
  4. 보안 키 배포 작업 전에는 Host Agent 상태와 연결 상태를 확인한다.
  5. Events 탭에서 Host 추가, 유지보수, 보안 키 배포, GPU 검색, 삭제 등 작업 이력을 확인한다.

상태 및 제약 조건

  • State는 Host의 연결 또는 보안 상태를 나타내며, Resource state는 Host를 리소스 배치 대상으로 사용할 수 있는지 나타낸다.
  • Resource state가 Enabled인 Host라도 CPU, Memory, Storage 접근성, Host Tag, Cluster 상태에 따라 Instance 배치 대상에서 제외될 수 있다.
  • Host 추가 시 선택한 Cluster의 Hypervisor, Arch, 네트워크, Primary Storage 접근 조건과 Host 구성이 일치해야 한다.
  • Password 인증 방식 사용 시 화면 캡처와 문서 공유 과정에서 계정명과 비밀번호가 노출되지 않도록 관리해야 한다.
  • GPU 기능은 Host 장치 구성, 드라이버, 장치 패스스루, 운영 정책에 영향을 받으므로 화면 표시만으로 사용 가능 여부를 단정하지 않는다.
  • GPU 장치를 Instance에 할당하는 경우 Host 유지보수, VM 배치, live migration 가능성에 제약이 생길 수 있다.
  • Host security key 배포는 Host와 관리 시스템 간 보안 연결 상태에 영향을 줄 수 있으므로 실행 전 Agent 상태를 확인해야 한다.

주의사항

  • Host 이름, IP 주소, Management Server 이름, ID는 환경 고유 정보이므로 외부 배포 문서에서는 일반화하거나 마스킹해야 한다.
  • Host 추가 전 관리 서버에서 Host 관리 IP로 접속 가능한지 확인해야 한다.
  • Host의 Hypervisor, Agent, 네트워크 브리지, NFS 접근 조건이 맞지 않으면 등록에 실패할 수 있다.
  • CPU와 Memory 사용률은 수집 시점의 값이므로 장애 판단 시 단일 화면만 보지 말고 이벤트와 운영 로그를 함께 확인해야 한다.
  • Comments에는 비밀번호, SSH 키, 접속 정보, 고객사 식별 정보 등 민감정보를 입력하지 않아야 한다.
  • 작업 아이콘은 툴팁 또는 실행 확인 창 기준으로 문서화해야 하며, 아이콘 모양만으로 기능을 단정하지 않아야 한다.

이벤트 및 이력 확인

Events 탭에서는 Host 추가, 활성화/비활성화, 유지보수 전환, 보안 키 배포, GPU 검색, 삭제와 관련된 이벤트 이력을 확인한다. 이벤트에는 Level, Type, State, Username, Account, Domain, Created 정보가 표시될 수 있다. Host 장애 분석 시에는 이벤트 시각, Host State, Resource state, Cluster 상태, Agent 연결 상태를 함께 비교한다.
