알림

시스템은 클라우드 관리를 돕기 위해 알림(Alert)과 이벤트(Event)를 제공한다.

**알림(Alert)**은 클라우드에서 오류가 발생했음을 관리자에게 통지하는 메시지로, 일반적으로 이메일을 통해 전달된다. 알림 동작은 구성 가능한다.

**이벤트(Event)**는 클라우드에서 발생하는 모든 사용자 및 관리자 작업을 추적한다. 예를 들어 게스트 인스턴스가 시작될 때마다 관련 이벤트가 생성된다. 이벤트는 관리 서버의 데이터베이스에 저장된다.

다음 상황에서 관리자에게 이메일 알림이 전송된다.

  • 관리 서버 클러스터의 CPU, 메모리, 또는 스토리지 자원이 부족한 경우

  • 관리 서버가 호스트로부터 3분 이상 하트비트(Heartbeat)를 받지 못한 경우

  • 호스트 클러스터의 CPU, 메모리, 또는 스토리지 자원이 부족한 경우

이메일 알림 SMTP 설정

알림 이메일 발송을 위한 전역 설정 파라미터는 다음과 같다.

전역 설정 기본값 설명
alert.smtp.host null 이메일 알림 발송에 사용할 SMTP 호스트명
alert.smtp.port 465 SMTP 서버 리스닝 포트
alert.smtp.useAuth false true로 설정 시 이메일 발송 시 SMTP 인증을 사용
alert.smtp.username null SMTP 인증용 사용자명 (alert.smtp.useAuth가 true인 경우에만 적용)
alert.smtp.password null SMTP 인증용 비밀번호 (alert.smtp.useAuth가 true인 경우에만 적용)
alert.smtp.useStartTLS false true로 설정하고 alert.smtp.useAuth를 통해 보안을 활성화하면 StartTLS로 연결을 보호
alert.smtp.enabledSecurityProtocols null 공백으로 구분된 보안 프로토콜 목록 (예: "TLSv1 TLSv1.1"). 지원 프로토콜: SSLv2Hello, SSLv3, TLSv1, TLSv1.1, TLSv1.2
alert.smtp.connectiontimeout 30000 소켓 연결 타임아웃(밀리초). -1은 무한 대기
alert.smtp.timeout 30000 소켓 I/O 타임아웃(밀리초). -1은 무한 대기
alert.email.addresses null 알림 이메일을 수신할 이메일 주소 목록 (쉼표로 구분)
alert.email.sender null 알림 이메일의 발신자 주소 (이메일의 From 헤더에 표시)

알림 유형 목록

다음은 namuVirt에서 발생할 수 있는 알림 유형 목록이다. listAlerts API 명령으로 최신 목록을 조회할 수 있다.

유형 번호 이름 설명
0 MEMORY 사용 가능한 메모리가 설정된 임계값 이하
1 CPU 할당되지 않은 CPU가 설정된 임계값 이하
2 STORAGE 사용 가능한 스토리지가 설정된 임계값 이하
3 STORAGE_ALLOCATED 남은 미할당 스토리지가 설정된 임계값 이하
4 PUBLIC_IP 할당되지 않은 가상 네트워크 공용 IP 수가 설정된 임계값 이하
5 PRIVATE_IP 할당되지 않은 사설 IP 수가 설정된 임계값 이하
6 SECONDARY_STORAGE 가용 Zone의 사용 가능한 2차 스토리지가 설정된 임계값 이하
7 HOST 호스트 연결 끊김 등 호스트 관련 알림
8 USERVM 사용자 인스턴스가 예기치 않게 중지됨
9 DOMAIN_ROUTER 도메인 라우터 VM이 예기치 않게 중지됨
10 CONSOLE_PROXY Console Proxy VM이 예기치 않게 중지됨
11 ROUTING 기본 경로(게이트웨이)로의 연결이 끊어짐
12 STORAGE_MISC 시스템 VM에서 스토리지 문제 발생
13 USAGE_SERVER 사용 서버 프로세스가 실행 중이지 않음
14 MANAGEMENT_NODE 관리 네트워크 CIDR이 초기에 설정되지 않음
15 DOMAIN_ROUTER_MIGRATE 도메인 라우터 VM 마이그레이션 실패
16 CONSOLE_PROXY_MIGRATE Console Proxy VM 마이그레이션 실패
17 USERVM_MIGRATE 사용자 인스턴스 마이그레이션 실패
18 VLAN 가용 Zone에서 할당되지 않은 VLAN 수가 설정된 임계값 이하
19 SSVM SSVM(Secondary Storage VM)이 예기치 않게 중지됨
20 USAGE_SERVER_RESULT 사용량 집계 작업 실패
21 STORAGE_DELETE 스토리지 풀 삭제 실패
22 UPDATE_RESOURCE_COUNT 자원 사용량 카운트 업데이트 실패
23 USAGE_SANITY_RESULT 사용량 정합성 검사 실패
24 DIRECT_ATTACHED_PUBLIC_IP 가용 Zone에서 할당되지 않은 공유 네트워크 IP 수가 부족
25 LOCAL_STORAGE 남은 미할당 로컬 스토리지가 설정된 임계값 이하
26 RESOURCE_LIMIT_EXCEEDED 자원 한도 초과 (현재 반복 스냅샷에만 사용)

목록 조회

알림 목록을 확인하는 화면이다. namuVirt 대시보드 UI에서 관리자 알림을 확인할 수 있으며, 이메일을 통해서도 동일한 알림을 받을 수 있다.

알림 아카이브

선택한 알림을 보관(Archive)하는 기능이다.

알림 아카이브 버튼을 클릭하여 알림 아카이브 화면을 호출한 뒤 확인 버튼을 클릭한다.

알림 삭제

선택한 알림을 삭제하는 기능이다.

알림 삭제 버튼을 클릭하여 알림 삭제 화면을 호출한 뒤 확인 버튼을 클릭한다.

상세

알림에 대한 상세 정보를 조회하는 화면이다. 해당 알림의 이름, 아이디, 유형, 일자, 설명 등의 정보를 확인할 수 있다.
