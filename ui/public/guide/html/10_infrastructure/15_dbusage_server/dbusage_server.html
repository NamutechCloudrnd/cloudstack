DB/Usage Server

namuVirt 서비스에 사용되는 **데이터베이스 서버(DB Server)**와 **사용 서버(Usage Server)**의 통계 정보를 확인할 수 있는 화면이다.

데이터베이스 서버(DB Server)

관리 서버는 영속성(Persistence)을 위해 MySQL 데이터베이스가 필요한다. 관리 서버는 데이터베이스 구성 정보(호스트명, 포트, 자격증명 등)를 /etc/cloudstack/management/db.properties 파일에 저장한다.

사용 서버(Usage Server)

사용 서버는 namuVIRT에서 별도로 설치되는 선택적 구성 요소로, 클라우드 자원 사용량에 대한 집계된 사용 기록(Usage Records)을 생성한다. 사용 서버는 이벤트 로그에서 데이터를 가져와 listUsageRecords API 호출을 통해 접근할 수 있는 요약 사용 기록을 생성한다. 사용 기록에는 게스트 인스턴스가 소비한 VM 실행 시간, 템플릿 스토리지 공간 등의 자원 사용량이 포함된다.

사용 서버는 하루에 최소 한 번 실행되며, 하루에 여러 번 실행되도록 구성할 수도 있다. 이 정보는 namuVIRT기반 클라우드의 과금(Billing) 연동에 활용할 수 있다.
