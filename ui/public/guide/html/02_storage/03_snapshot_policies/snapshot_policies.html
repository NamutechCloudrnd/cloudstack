Snapshot Policy

Snapshot Policy는 Volume에 대해 정기 Snapshot을 자동 생성하는 규칙이다. 주기, 실행 시각, 보존 개수, Zone 복사 조건을 관리한다.

  • 화면 위치: Storage > Snapshot policies
  • 설명: 등록된 정기 스냅샷 정책 목록을 확인하는 화면이다.

스냅샷 정책 목록 화면에서는 정기 스냅샷 정책의 주기, 최대 보존 개수, 실행 일정, 시간대, 대상 볼륨 이름을 확인할 수 있다. 화면 예시에서는 아직 생성된 정책이 없어 데이터 없음 상태로 표시된다. 상단의 Create Recurring Snapshot 버튼을 통해 새 정기 스냅샷 정책을 생성할 수 있다.

  • 화면 위치: Storage > Snapshot policies > Create Recurring Snapshot
  • 설명: 볼륨에 대해 정기 스냅샷 생성 주기와 보존 정책을 설정하는 화면이다.

정기 스냅샷 정책 생성 화면에서는 스냅샷 생성 주기, 실행 시각, 보존 개수, 시간대, Zone 복사 대상, 기본 스토리지 복제 사용 여부, 태그를 설정할 수 있다. 화면 예시에서는 Daily 주기가 선택되어 있고, 실행 시각은 3:30 PM, 보존 개수는 8, 시간대는 Asia/Seoul로 입력되어 있다. 안내 영역에는 스냅샷이 기본 Zone에 항상 생성되며, 필요한 경우 추가 Zone을 선택해 생성 시점에 복사할 수 있다는 내용이 표시된다.

  • 화면 위치: Storage > Snapshot policies
  • 설명: 생성된 정기 스냅샷 정책이 목록에 반영된 화면이다.

정기 스냅샷 정책을 생성하면 목록에 정책 정보가 표시된다. 화면 예시에서는 DAILY 주기의 정책이 생성되었고, 최대 보존 개수는 8, 실행 일정은 15:30, 시간대는 Asia/Seoul, 대상 볼륨은 ROOT-5로 표시된다. 이 목록을 통해 현재 등록된 정책의 실행 주기와 대상 볼륨을 확인할 수 있다.

주요 작업

정기 Snapshot Policy 생성

  1. 상단 메뉴에서 Storage > Snapshot policies로 이동한다.
  2. Create Recurring Snapshot 버튼을 선택한다.
  3. 실행 주기, 실행 시각, 보존 개수, Timezone을 입력한다.
  4. 필요하면 추가 복사 대상 Zone과 기본 스토리지 복제 옵션을 설정한다.
  5. 입력을 완료한 뒤 확인 버튼을 선택한다.
  6. 목록에서 대상 Volume과 실행 주기가 의도대로 반영되었는지 확인한다.

입력 항목

정기 스냅샷 정책 생성 화면

항목 설명
Interval type 스냅샷을 생성할 주기를 선택한다. 화면에서는 Hourly, Daily, Weekly, Monthly 옵션이 표시된다.
Time 스냅샷이 실행될 시간을 입력한다.
Keep 정기 스냅샷으로 보존할 최대 개수를 입력한다.
Timezone 스냅샷 실행 기준 시간대를 선택한다.
Zones 스냅샷 생성 시 추가로 복사할 Zone을 선택한다.
Use primary storage replication 지원되는 환경에서 기본 스토리지 복제를 사용할지 선택한다.
Tags 정책에 태그를 추가한다.

상태 및 제약 조건

  • Snapshot Policy는 특정 Volume을 대상으로 적용된다.
  • 정책이 활성화되면 설정한 주기와 시각에 따라 Snapshot이 자동 생성된다.
  • Snapshot은 기본 Zone에 생성되며, 추가 Zone을 선택한 경우 생성 시점에 복사될 수 있다.
  • Keep 값이 작으면 오래된 Snapshot이 삭제 대상이 될 수 있으므로 필요한 복구 지점 수와 함께 결정한다.

주의사항

  • 보존 개수를 작게 설정하면 기존 정기 스냅샷이 자동 삭제될 수 있으므로 필요한 복구 지점 수를 확인해야 한다.
  • 추가 Zone 복사를 사용하는 경우 대상 Zone과 저장소 상태를 확인해야 한다.
  • 정기 스냅샷 정책은 대상 볼륨에 지속적으로 스냅샷을 생성하므로, 보존 개수와 저장소 사용량을 함께 점검해야 한다.
