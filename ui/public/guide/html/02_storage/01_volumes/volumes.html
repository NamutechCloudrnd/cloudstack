Volume

Volume은 Instance에 연결하여 사용하는 블록 스토리지이다. Root Volume과 Data Volume으로 구분되며, 생성 후 연결·분리·크기 변경·마이그레이션과 같은 후속 작업을 수행할 수 있다.


  • 화면 위치: Storage > Volumes
  • 설명: 생성된 볼륨 목록과 상태, 크기, 연결된 인스턴스 정보를 확인하는 화면이다.

볼륨 목록 화면에서는 루트 볼륨과 데이터 볼륨의 이름, 상태, 크기, 유형, 연결된 인스턴스, 스토리지, 계정, Zone 정보를 확인할 수 있다. 상단의 Create Volume 버튼을 통해 신규 데이터 볼륨을 생성할 수 있으며, 검색과 필터를 사용해 필요한 볼륨을 찾을 수 있다. 목록에서 볼륨 이름을 선택하면 해당 볼륨의 상세 화면으로 이동한다.

  • 화면 위치: Storage > Volumes > Create Volume
  • 설명: 신규 데이터 볼륨을 생성하기 위해 소유자, Zone, 디스크 오퍼링 등을 입력하는 화면이다.

볼륨 생성 화면에서는 볼륨의 소유자 범위, 도메인, 계정, 이름, Zone, 디스크 오퍼링을 입력한다. 화면 예시에서는 Account 소유자 유형, ROOT 도메인, admin 계정, namu_zone, Small Disk, 5 GB 디스크 오퍼링이 선택되어 있다. Attach to Instance 옵션을 활성화하면 생성과 동시에 인스턴스 연결 흐름을 함께 진행할 수 있다.

  • 화면 위치: Storage > Volumes
  • 설명: 신규 볼륨 생성 후 목록에 Allocated 상태로 표시되는 화면이다.

볼륨 생성이 완료되면 목록에 신규 볼륨이 추가된다. 화면 예시에서는 TESTVOLUME이라는 데이터 볼륨이 5.00 GiB 크기로 생성되었고, 상태는 Allocated로 표시된다. Allocated 상태의 볼륨은 아직 인스턴스에 연결되지 않은 볼륨으로 볼 수 있으며, 이후 상세 화면에서 연결 또는 삭제 등의 후속 작업을 수행할 수 있다.

  • 화면 위치: Storage > Volumes > TESTVOLUME
  • 설명: 선택한 볼륨의 상세 정보와 작업 버튼을 확인하는 화면이다.

볼륨 상세 화면에서는 선택한 볼륨의 이름, ID, 유형, 스토리지 유형, 디스크 오퍼링, 크기, 프로비저닝 유형, 삭제 보호 여부를 확인할 수 있다. 화면 예시의 TESTVOLUME은 DATADISK 유형이며, 상태는 Allocated이다. 상단 작업 버튼을 통해 볼륨 연결, 편집, 크기 변경, 삭제 등 상태에 따라 가능한 작업을 수행할 수 있다.

  • 화면 위치: Storage > Volumes > sharedfs-ROOT-10
  • 설명: 인스턴스에 연결된 Ready 상태 루트 볼륨의 상세 정보를 확인하는 화면이다.

이 화면에서는 인스턴스에 연결된 루트 볼륨의 상세 정보를 확인할 수 있다. 왼쪽 요약 영역에는 상태, ID, 디스크 크기, 인스턴스 이름, 템플릿, 컴퓨트 오퍼링, 스토리지 풀, Cluster, Pod 정보가 표시된다. 오른쪽 상세 탭에는 이름, ID, 유형, 스토리지 유형, 디바이스 ID, 크기, 물리 크기, 프로비저닝 유형, 사용률, 디스크 읽기/쓰기 지표가 표시된다. Ready 상태의 볼륨은 스냅샷 생성, 마이그레이션, 크기 변경 등 추가 작업 대상이 될 수 있다.

  • 화면 위치: Storage > Volumes > sharedfs-ROOT-10 > Events
  • 설명: 선택한 볼륨과 관련된 이벤트 이력을 확인하는 화면이다.

볼륨 상세 화면의 Events 탭에서는 해당 볼륨과 관련된 작업 이력을 확인할 수 있다. 화면 예시에서는 volume.create 유형의 이벤트가 INFO 레벨로 기록되어 있으며, 상태, 사용자명, 계정, 도메인, 생성 시각이 함께 표시된다. 이벤트 정보는 볼륨 생성, 변경, 오류 분석, 작업 이력 확인에 활용할 수 있다.

주요 작업

볼륨 생성

신규 Data Volume을 생성하는 절차이다.

  1. 상단 메뉴에서 Storage > Volumes로 이동한다.
  2. 화면 상단의 Create Volume 버튼을 선택한다.
  3. 소유자, Domain, Account, 이름, Zone, Disk Offering을 입력한다.
  4. 생성과 동시에 Instance에 연결해야 하면 Attach to Instance 옵션을 함께 확인한다.
  5. 입력을 완료한 뒤 확인 버튼을 선택한다.
  6. 목록 화면에서 신규 Volume이 Allocated 상태로 추가되었는지 확인한다.

볼륨 상세 조회

  1. Storage > Volumes 목록에서 확인할 Volume 이름을 선택한다.
  2. 상세 화면에서 유형, 크기, Disk Offering, 연결 상태를 확인한다.
  3. Ready 상태 Volume은 연결된 Instance와 스토리지 풀 정보를 함께 점검한다.

볼륨 이벤트 조회

  1. Volume 상세 화면에서 Events 탭을 선택한다.
  2. 이벤트 유형, 상태, 사용자, 생성 시각을 기준으로 최근 작업 이력을 확인한다.

입력 항목

볼륨 생성 입력 화면

항목 설명
Owner type 볼륨 소유자 유형을 선택한다. 화면 예시에서는 Account가 선택되어 있다.
Domain 볼륨을 생성할 도메인을 선택한다.
Account 볼륨을 소유할 계정을 선택한다.
Name 생성할 볼륨 이름을 입력한다.
Zone 볼륨을 생성할 Zone을 선택한다.
Disk Offering 볼륨에 적용할 디스크 오퍼링을 선택한다.
Attach to Instance 생성한 볼륨을 인스턴스에 바로 연결할지 여부를 선택한다.

상태 및 제약 조건

  • Allocated 상태는 생성되었지만 아직 Instance에 연결되지 않은 Volume을 의미한다.
  • Ready 상태 Volume은 Instance 연결, Snapshot 생성, 마이그레이션, 크기 변경 등 후속 작업의 대상이 될 수 있다.
  • Root Volume과 Data Volume은 용도와 허용 작업 범위가 다를 수 있으므로 작업 전 유형을 먼저 확인한다.
  • 고정 크기 Disk Offering을 선택한 경우 별도 크기 입력 항목이 표시되지 않을 수 있다.

주의사항

  • 삭제 작업은 볼륨 데이터 제거와 연결될 수 있으므로 실행 전에 대상 볼륨과 연결 상태를 확인해야 한다.
  • 루트 볼륨에 대한 크기 변경, 마이그레이션, 스냅샷, 삭제 계열 작업은 인스턴스 상태와 서비스 영향 범위를 확인한 뒤 수행해야 한다.

이벤트 및 이력 확인

Events 탭에서는 Volume 생성·변경과 관련된 이력을 확인할 수 있다. 이벤트 목록에는 이벤트 유형, 레벨, 상태, 사용자명, Account, Domain, 생성 시각이 표시되며, 작업 추적과 장애 분석에 활용할 수 있다.
