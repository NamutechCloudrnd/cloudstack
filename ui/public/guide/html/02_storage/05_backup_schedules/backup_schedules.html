Backup Schedule

개요

Backup Schedule은 Instance Backup을 정기적으로 생성하는 예약 규칙이다. 주기와 보존 개수를 관리해 반복 백업을 자동화한다.

화면 구성

백업 스케줄 목록 화면

  • 화면 위치: Storage > Backup Schedules
  • 설명: 등록된 백업 스케줄 목록과 생성 버튼을 확인하는 화면이다.

백업 스케줄 목록 화면에서는 정기 백업 정책의 주기, 최대 보존 개수, 실행 일정, 시간대, 대상 인스턴스 이름을 확인할 수 있다. 화면 예시에서는 아직 등록된 백업 스케줄이 없어 데이터 없음 상태로 표시된다. 상단의 Create Backup Schedule 버튼을 통해 신규 백업 스케줄을 생성할 수 있다.

백업 스케줄 생성 화면

  • 화면 위치: Storage > Backup Schedules > Create Backup Schedule
  • 설명: 인스턴스 백업을 주기적으로 생성하기 위한 스케줄 조건을 입력하는 화면이다.

백업 스케줄 생성 화면에서는 백업 주기, 실행 시각, 보존할 백업 개수, 시간대를 설정한다. 화면 예시에서는 Daily 주기가 선택되어 있고, 실행 시각은 4:00 PM, 보존 개수는 8, 시간대는 Asia/Seoul로 입력되어 있다. 백업 스케줄은 백업 오퍼링이 할당된 인스턴스에 대해 주기적인 백업 생성을 자동화하는 데 사용된다.

생성된 백업 스케줄 목록 화면

  • 화면 위치: Storage > Backup Schedules
  • 설명: 생성된 백업 스케줄이 목록에 반영된 화면이다.

백업 스케줄을 생성하면 목록에 정책 정보가 표시된다. 화면 예시에서는 DAILY 주기의 스케줄이 생성되었고, 최대 보존 개수는 8, 실행 일정은 16:00, 시간대는 Asia/Seoul, 대상 인스턴스는 VM-1d8ba6a8-0b47-4217-a8c3-33ba53556766으로 표시된다. 이 목록을 통해 현재 등록된 백업 스케줄의 실행 조건과 대상 인스턴스를 확인할 수 있다.

스케줄 기반 백업 목록 화면

  • 화면 위치: Storage > Backups
  • 설명: 백업 스케줄에 의해 생성된 백업본이 백업 목록에 표시되는 화면이다.

백업 목록 화면에서는 수동 백업과 스케줄 기반 백업을 함께 확인할 수 있다. 화면 예시에서는 DAILY 주기의 백업 항목 두 개가 강조되어 있으며, 각 백업은 BackedUp 상태와 FULL 유형으로 표시된다. 사용자는 생성 시각, 크기, 대상 인스턴스, 백업 오퍼링 이름을 확인하여 스케줄이 정상적으로 백업본을 생성했는지 검증할 수 있다.

주요 작업

Backup Schedule 생성

  1. 상단 메뉴에서 Storage > Backup Schedules로 이동한다.
  2. Create Backup Schedule 버튼을 선택한다.
  3. 대상 Instance, 실행 주기, 실행 시각, 보존 개수, Timezone을 입력한다.
  4. 설정을 저장한다.
  5. 목록에서 신규 Schedule이 생성되었는지 확인한다.

스케줄 기반 Backup 결과 확인

  1. 실행 예정 시각 이후 Storage > Backups로 이동한다.
  2. Interval type과 대상 Instance를 기준으로 스케줄 생성 Backup을 찾는다.
  3. 상태와 생성 시각이 설정한 Schedule과 일치하는지 확인한다.

입력 항목

백업 스케줄 생성 화면

항목 설명
Interval type 백업을 생성할 주기를 선택한다. 화면에서는 Hourly, Daily, Weekly, Monthly 옵션이 표시된다.
Time 백업이 실행될 시간을 입력한다.
Keep 보존할 최대 백업 개수를 입력한다.
Timezone 백업 실행 기준 시간대를 선택한다.

상태 및 제약 조건

  • Backup Schedule은 Backup Offering이 할당된 Instance에 적용된다.
  • 스케줄 실행 결과는 Backup Repository와 Backup Provider 상태에 영향을 받는다.
  • 보존 개수를 초과한 오래된 Backup은 정책에 따라 정리될 수 있다.
  • 스케줄 기반 Backup은 Backup 목록에서 Interval type 값으로 구분된다.

주의사항

  • 보존 개수를 작게 설정하면 오래된 백업본이 정책에 따라 정리될 수 있으므로 필요한 복구 지점 수를 확인해야 한다.
  • 백업 스케줄은 백업 저장소와 백업 제공자 상태에 의존하므로 운영 환경에서는 저장소 용량과 백업 성공 여부를 주기적으로 확인해야 한다.
  • 백업 스케줄은 대상 인스턴스에 반복적으로 백업을 생성하므로, 보존 개수와 백업 저장소 사용량을 함께 점검해야 한다.
