Volume Snapshot

Volume Snapshot은 Volume의 특정 시점 데이터를 보관하는 복사본이다. 복구 지점 확인, Template 생성, Zone별 보관 상태 점검에 사용한다.


  • 화면 위치: Storage > Volume Snapshots > Snapshot Detail
  • 설명: 선택한 볼륨 스냅샷의 상세 정보와 상단 작업 버튼을 확인하는 화면이다.

스냅샷 상세 화면에서는 선택한 볼륨 스냅샷의 상태, ID, 원본 볼륨, Zone, 계정, 도메인, 생성 시각을 확인할 수 있다. 화면 오른쪽 상단에는 스냅샷을 기반으로 수행할 수 있는 작업 버튼이 표시된다. 예시 화면에서는 Create Template 버튼이 강조되어 있으며, 스냅샷을 기반으로 템플릿을 생성하는 작업으로 연결된다.

  • 화면 위치: Storage > Volume Snapshots
  • 설명: 생성된 볼륨 스냅샷 목록과 상태, 원본 볼륨, 생성 시각을 확인하는 화면이다.

볼륨 스냅샷 목록 화면에서는 생성된 스냅샷의 이름, 상태, 원본 볼륨 이름, 생성 주기, 물리 크기, 생성 시각, 계정, 도메인, Zone 정보를 확인할 수 있다. 화면 예시에서는 ROOT-5, DATA-5, ROOT-6 볼륨에서 생성된 스냅샷이 BackedUp 상태로 표시된다. 목록에서 스냅샷 이름을 선택하면 해당 스냅샷의 상세 화면으로 이동할 수 있다.

  • 화면 위치: Storage > Volume Snapshots > Snapshot Detail > Details
  • 설명: 선택한 볼륨 스냅샷의 기본 속성과 크기 정보를 확인하는 화면이다.

스냅샷 상세 화면의 Details 탭에서는 스냅샷 이름, ID, 원본 볼륨 이름, 볼륨 유형, 생성 주기, 물리 크기, 가상 크기, 계정, 도메인, 생성 시각을 확인할 수 있다. 왼쪽 요약 영역에는 상태, ID, 원본 볼륨, Zone, 계정, 도메인 정보가 함께 표시된다. 이 정보는 스냅샷 복원, 템플릿 생성, Zone 복사 또는 삭제 작업 전 대상 스냅샷을 확인하는 데 사용된다.

  • 화면 위치: Storage > Volume Snapshots > Snapshot Detail > Zones
  • 설명: 선택한 스냅샷이 등록된 Zone과 준비 상태를 확인하는 화면이다.

Zones 탭에서는 선택한 스냅샷이 어느 Zone에 존재하는지와 해당 Zone에서 사용할 준비가 되었는지 확인할 수 있다. 화면 예시에서는 namu_zone에 스냅샷이 존재하며, Status는 BackedUp, Ready는 Yes로 표시된다. 다중 Zone 환경에서는 이 정보를 통해 스냅샷 복사, Zone별 삭제, 재해 복구용 복제 상태를 확인할 수 있다.

  • 화면 위치: Storage > Volume Snapshots > Snapshot Detail > Events
  • 설명: 선택한 스냅샷과 관련된 이벤트 이력을 확인하는 화면이다.

Events 탭에서는 선택한 스냅샷과 관련된 작업 이력을 확인할 수 있다. 화면 예시에서는 SNAPSHOT.CREATE 유형의 이벤트가 INFO 레벨로 기록되어 있으며, 상태, 사용자명, 계정, 도메인, 생성 시각이 함께 표시된다. 이벤트 정보는 스냅샷 생성 이력 확인, 작업 추적, 장애 분석에 활용할 수 있다.

주요 작업

Volume Snapshot 목록 조회

  1. 상단 메뉴에서 Storage > Volume Snapshots로 이동한다.
  2. 목록에서 이름, 상태, 원본 Volume, 생성 주기, 생성 시각을 확인한다.
  3. 상세 확인이 필요한 Snapshot 이름을 선택한다.

Snapshot 기반 Template 생성

  1. 대상 Snapshot의 상세 화면으로 이동한다.
  2. 원본 Volume과 생성 시점을 다시 확인한다.
  3. 상단 작업 버튼에서 Create Template 작업을 선택한다.
  4. 생성 후 Template 목록에서 결과를 확인한다.

Zone별 Snapshot 상태 확인

  1. Snapshot 상세 화면에서 Zones 탭을 선택한다.
  2. 각 Zone의 상태와 Ready 값을 확인한다.
  3. 복사본 삭제나 재해 복구 판단이 필요한 경우 대상 Zone을 먼저 확인한다.

상태 및 제약 조건

  • BackedUp 상태는 Snapshot이 생성되어 보관된 상태를 나타낸다.
  • Volume Snapshot은 디스크 데이터의 특정 시점 복사본이며, 메모리와 CPU 상태는 포함하지 않는다.
  • Snapshot은 Zone별로 준비 상태가 다를 수 있으므로 다중 Zone 환경에서는 Zones 탭을 함께 확인한다.
  • 정책 기반 Snapshot과 수동 Snapshot은 생성 주기 표기와 운영 목적이 다를 수 있다.

주의사항

  • 스냅샷 기반 템플릿 생성은 이후 인스턴스 배포에 사용될 수 있으므로, 원본 볼륨과 스냅샷 시점을 확인한 뒤 수행해야 한다.
  • Zone별 스냅샷 삭제는 해당 Zone의 스냅샷 복사본 사용 가능 여부에 영향을 줄 수 있으므로 삭제 대상 Zone을 확인해야 한다.

이벤트 및 이력 확인

Events 탭에서는 Snapshot 생성 이력을 확인할 수 있다. 이벤트 유형, 레벨, 상태, 사용자명, Account, Domain, 생성 시각을 함께 보아 대상 Snapshot이 의도한 시점에 생성되었는지 점검한다.
