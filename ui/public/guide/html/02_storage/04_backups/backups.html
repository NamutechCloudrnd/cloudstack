Backup

개요

Backup은 Instance 단위 데이터를 보관하고 필요 시 복원하는 기능이다. 사용 전 프레임워크 활성화와 제공자 설정을 확인해야 한다.

화면 구성

백업 프레임워크 활성화 설정 화면

  • 화면 위치: Configuration > Global Settings
  • 설명: 백업 기능 사용 여부를 설정하는 글로벌 설정 화면이다.

Global Settings 화면에서 backup 키워드로 설정 항목을 검색한 상태이다. 화면에는 백업 볼륨 연결/분리 허용 설정, 백업 프레임워크 활성화 여부, 백업 제공자 플러그인, 동기화 주기 등 백업 기능과 관련된 설정이 표시된다. 예시에서는 Backup framework enabled 항목이 활성화되어 있으며, 백업 기능을 사용하기 위한 기본 설정 상태를 확인할 수 있다.

인스턴스 목록에서 백업 대상 선택

  • 화면 위치: Compute > Instances
  • 설명: 백업을 생성할 인스턴스를 목록에서 선택하는 화면이다.

인스턴스 목록 화면에서는 실행 중인 인스턴스의 이름, 상태, 내부 이름, IP 주소, 아키텍처, 호스트, 계정, Zone 정보를 확인할 수 있다. 백업을 생성하려면 목록에서 대상 인스턴스를 선택하여 상세 화면으로 이동한다. 화면 예시에서는 첫 번째 인스턴스가 강조되어 있으며, 해당 인스턴스를 대상으로 백업 작업을 진행하는 흐름을 보여줍니다.

인스턴스 상세 화면의 백업 시작 버튼

  • 화면 위치: Compute > Instances > Instance Detail
  • 설명: 인스턴스 상세 화면에서 백업 시작 작업을 실행하는 화면이다.

인스턴스 상세 화면에서는 선택한 인스턴스의 기본 정보와 상태를 확인할 수 있다. 상단 작업 버튼 영역에서 Start Backup 버튼을 선택하면 해당 인스턴스에 대한 백업 생성을 요청할 수 있다. 화면 예시의 인스턴스는 Running 상태이며, 백업 시작 버튼이 강조되어 있다.

백업 목록 화면

  • 화면 위치: Storage > Backups
  • 설명: 생성된 백업 목록과 상태, 크기, 대상 인스턴스를 확인하는 화면이다.

백업 목록 화면에서는 생성된 백업의 이름, 상태, 크기, 가상 크기, 대상 인스턴스 이름, 백업 오퍼링 이름, 생성 방식, 백업 유형, 생성 시각, 계정, 도메인, Zone 정보를 확인할 수 있다. 화면 예시에서는 testBackup 항목이 BackedUp 상태로 표시되어 있다. 목록에서 백업 이름을 선택하면 백업 상세 화면으로 이동할 수 있다.

여러 백업 항목이 표시된 목록 화면

  • 화면 위치: Storage > Backups
  • 설명: 수동 백업과 정기 백업이 함께 표시된 백업 목록 화면이다.

백업 목록에는 수동으로 생성된 백업과 스케줄에 의해 생성된 백업이 함께 표시될 수 있다. 화면 예시에서는 MANUAL 항목 1개와 DAILY 항목 2개가 BackedUp 상태로 표시된다. 사용자는 목록에서 백업별 크기, 가상 크기, 대상 인스턴스, 백업 오퍼링, 백업 유형, 생성 시각을 비교하여 복구에 사용할 백업본을 선택할 수 있다.

백업 상세 화면의 인스턴스 복원 버튼

  • 화면 위치: Storage > Backups > Backup Detail
  • 설명: 선택한 백업본에서 인스턴스 복원 작업을 실행하는 화면이다.

백업 상세 화면에서는 선택한 백업본의 기본 정보와 상단 작업 버튼을 확인할 수 있다. 화면 예시에서는 Restore Instance backup 버튼이 강조되어 있으며, 이 작업은 선택한 백업본을 기준으로 인스턴스를 복원하는 기능이다. 복원 전에는 대상 인스턴스 상태, 백업본 시점, 포함된 볼륨 정보를 확인해야 한다.

백업 상세 정보 화면

  • 화면 위치: Storage > Backups > Backup Detail > Details
  • 설명: 선택한 백업본의 상세 속성과 포함된 볼륨 정보를 확인하는 화면이다.

백업 상세 화면의 Details 탭에서는 백업 이름, 설명, 대상 인스턴스 이름, ID, 생성 방식, 백업 유형, 외부 ID, 크기, 가상 크기, 포함된 볼륨, 백업 오퍼링 이름을 확인할 수 있다. 화면 예시의 백업은 FULL 유형이며, ROOT 볼륨과 DATADISK 볼륨이 함께 포함되어 있다. 백업 복원 또는 볼륨 복원 작업을 수행하기 전에 이 화면에서 백업 대상과 포함 볼륨을 확인한다.

백업의 인스턴스 메타데이터 탭 화면

  • 화면 위치: Storage > Backups > Backup Detail > Instance metadata
  • 설명: 백업 시점의 인스턴스 구성 정보를 확인하는 화면이다.

Instance metadata 탭에서는 백업 대상 인스턴스의 템플릿, OS 유형, 하이퍼바이저, 컴퓨트 오퍼링, 네트워크 정보를 확인할 수 있다. 화면 예시에서는 Ubuntu 24.04 템플릿, Ubuntu 24.04 LTS OS 유형, KVM 하이퍼바이저, Medium Instance 컴퓨트 오퍼링, test-network NIC 정보가 표시된다. 이 정보는 백업 복구 후 인스턴스 구성 검증이나 복구 대상 환경 확인에 활용할 수 있다.

주요 작업

Backup 기능 활성화 확인

  1. 상단 메뉴에서 Configuration > Global Settings로 이동한다.
  2. backup 키워드로 관련 설정을 검색한다.
  3. Backup 프레임워크와 Provider 설정이 운영 환경 값과 일치하는지 확인한다.

Instance Backup 시작

  1. Compute > Instances에서 Backup 대상 Instance를 선택한다.
  2. Instance 상세 화면에서 상태와 Backup Offering 할당 여부를 확인한다.
  3. 상단 작업 버튼에서 Backup 시작 작업을 선택한다.
  4. Storage > Backups 목록에서 새 Backup이 생성되었는지 확인한다.

Instance 복원

  1. Storage > Backups 목록에서 사용할 Backup을 선택한다.
  2. 상세 화면에서 생성 시각과 포함된 Volume을 확인한다.
  3. 복원 대상 Instance의 현재 상태를 확인한다.
  4. 상단의 복원 작업을 선택하고 복원 결과를 검증한다.

입력 항목

백업 프레임워크 활성화 설정 화면

항목 설명
Backup framework enabled 백업 및 복구 프레임워크를 사용할지 여부를 설정한다.
Backup framework provider plugin 백업 기능에서 사용할 제공자 플러그인을 지정한다.
Backup framework sync interval 백업 관련 백그라운드 동기화 작업의 실행 주기를 초 단위로 설정한다.
Backup enable attach detach of volumes 백업에서 복원한 볼륨을 인스턴스에 연결하거나 분리하는 기능을 허용할지 설정한다.

상태 및 제약 조건

  • 정상 완료된 Backup은 목록에서 BackedUp 상태로 표시된다.
  • Backup 생성 가능 여부는 Instance 상태, Backup Offering, Backup Provider 설정에 따라 달라질 수 있다.
  • Interval type은 수동 생성 시 MANUAL, 스케줄 생성 시 DAILY 등으로 표시될 수 있다.
  • 실행 중인 Instance의 Backup 지원 범위와 일관성 수준은 Provider와 게스트 구성에 따라 달라질 수 있다.
  • Instance 복원은 대상 상태와 Backup 포함 Volume을 먼저 확인한 뒤 수행해야 한다.

주의사항

  • 백업 프레임워크가 비활성화되어 있으면 백업 생성, 복구, 백업 스케줄 관련 기능을 사용할 수 없다.
  • 백업 제공자 플러그인 값은 실제 환경에 구성된 백업 제공자와 일치해야 한다.
  • 백업 생성 전 대상 인스턴스에 백업 오퍼링이 할당되어 있는지 확인해야 한다.
  • 백업 생성 중에는 백업 제공자, 저장소, 네트워크 상태에 따라 작업 시간이 길어질 수 있다.
  • 인스턴스 복원 작업은 기존 인스턴스 상태와 디스크 데이터에 영향을 줄 수 있으므로 복원 대상과 백업 시점을 반드시 확인해야 한다.
  • 인스턴스 복원은 인스턴스 정지 상태가 필요할 수 있으므로 실행 전 상태 조건을 확인해야 한다.
  • 백업에 포함된 볼륨을 확인하지 않고 복원하면 의도하지 않은 디스크 상태로 되돌아갈 수 있다.

이벤트 및 이력 확인

Backup 기능은 목록의 상태, 생성 방식, Backup 유형, 생성 시각을 함께 보아 이력을 확인한다. 복원 전에는 Backup 상세의 Instance metadata와 포함 Volume을 확인해 복원 기준점을 분명히 해야 한다.
